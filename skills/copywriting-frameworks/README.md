# 📝 文案框架库（Copywriting Frameworks）

> **你盯着空白页面，不知道第一句该怎么写——不是因为没想法，而是缺一个帮你"起手"的框架。**

写作最难的不是写，是启动。你有一堆想说的卖点，但不知道怎么组织成一段让读者停下来的文字。AIDA、PAS、BAB——这些缩写你不是没听过，但在实际写的时候，你忘了它们的存在。你需要的是一套在你卡住时，能直接告诉你"现在用哪个框架、按什么顺序写、每段该塞什么"的作战地图。

---

## 🚧 边界：我们能做什么，不做什么

| ✅ 能做的 | ❌ 不做的 |
|-----------|-----------|
| 提供 7+ 种经典文案框架及适配场景 | 不替你决定"哪个框架一定对" |
| 每种框架附完整写作模板 | 不写空洞的"抓住用户注意力"建议 |
| 含标题公式 + CTA 最佳实践 | 不推荐已被验证无效的 CTA 措辞 |

---

## ⚡ 核心能力

1. **框架选择指南** —— 按场景（广告/落地页/邮件/销售页/产品描述/外拓/CTA）直接推荐最佳框架
2. **七大核心框架** —— AIDA（注意→兴趣→欲望→行动）、PAS（问题→激化→解决）、BAB（前→后→桥）、4Ps（承诺→画面→证明→推动）、QUEST、FAB（功能→优势→利益）、StoryBrand 七步叙事
3. **标题公式库** —— How-to / 数字 / 提问 / 否定 / 社会证明 / 好奇心缺口 / 直接利益 / 对比，8 种模板即拿即用
4. **CTA 最佳实践** —— 5 种有效按钮公式 + 5 个永远别用的反例（"提交""点击这里"……）
5. **完整写作示例** —— 每个框架都附带 SaaS/DTC 真实场景的逐段写作示范

---

## 👤 谁在用

- **文案写手**：接到任何写作任务，先查框架选择表
- **广告投放团队**：用 PAS 写搜索广告，用 BAB 写冷外拓邮件
- **产品营销**：用 FAB 写产品描述页，用 StoryBrand 写品牌故事
- **创始人**：不会写文案但有东西要卖——框架就是你的"写作拐杖"

---

## 🔗 配合使用

- 写出初稿后 → 调用 `copy-editing` 用七扫法打磨到可发布
- 需要匹配品牌语气 → 先跑 `brand-dna` 提取品牌基因
- 需要 SEO 优化 → 配合 `seo-content-writer` 在框架基础上植入关键词
- 需要页面级 CRO → 调用 `cro-auditor` 评估文案转化潜力

**输入**：写作场景 + 产品信息 + 目标受众
**输出**：按框架组织的文案初稿 + 标题备选 + CTA 措辞
