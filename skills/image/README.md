# 🖼️ Image — 从博客头图到品牌资产，AI 生成 + 工程化产出

> **你的文章写好了，但配图拖了三天。或者你觉得 Unsplash 上的图已经被 200 个竞品用过了。**

营销内容需要图片。博客头图、社交媒体卡片、产品 Mockup、目录列表 Banner、OG 预览图——每个场景都有一套自己的尺寸、风格和优化规则。这个技能不是\"帮你画一张图\"，而是**从选型到输出到优化的全链路视觉生产线**：什么时候用 AI 生成（Gemini/Flux/Ideogram），什么时候用设计工具（Canva/Figma），什么时候直接截屏加标注——以及图片如何压缩到不影响页面速度。

## ⚡ 核心能力

### 🎨 四象限生成选型

| 需求 | 工具 | 为什么 |
|------|------|--------|
| 需要图中含文字标题 | Ideogram（最强）→ Gemini / GPT Image（可用） | 大多数 AI 模型文字渲染是灾难级的 |
| 需要产品/品牌跨图一致性 | Flux（多图参考功能） | 保持风格统一的批量产出 |
| 需要编辑已有图片 | Gemini（原生编辑）→ Flux Flex | 去背景、调风格、做变体 |
| 追求最高视觉品质 | Flux Pro / Midjourney | 但 API 和成本不同 |
| 大批量低成本 | Flux Klein / Gemini Flash | 速度优先 |

### 📐 全场景尺寸速查

- **博客头图/OG**：1200×630（16:9 等效 1200×675 也常见）
- **Twitter/X 大图卡片**：1200×675
- **LinkedIn 信息流**：1200×627
- **Instagram 帖子**：1080×1080（1:1）或 1080×1350（4:5）
- **Product Hunt 画廊**：1270×760
- **GitHub 社交预览**：1280×640
- **App Store 截图**：按设备，详见 aso-audit

### ⚡ 性能优化清单

- WebP 优先（96% 浏览器支持），AVIF 更优但兼容性略低
- 不要在 800px 容器里放 4000px 的图——先裁到显示尺寸
- `loading="lazy"` 处理首屏以下所有图片
- `width` / `height` 属性防止 CLS 布局偏移
- CDN 自动优化（Cloudflare / Vercel / Imgix / Cloudinary）

## 🔗 配合使用

- 视频封面 → `video` 生成视频缩略图
- SEO → `seo-audit` 检查 alt 文本和图片文件名
- 转化优化 → `page-cro` 评估图片在落地页的位置和效果
- 目录提交 → `directory-submissions` 生成 G2/Product Hunt 所需规格图片
- 社交预览 → `social-preview` 专注 GitHub OG 图生成

**输入**：图片用途 + 平台/尺寸 + 品牌资产（可选）
**输出**：工具推荐 + Prompt + 输出规格 + 优化指令
