> UX架构与体验优化。从用户旅程到信息架构，输出可落地的UX设计方案与优化策略。

---

## 快速开始

### 适用场景

- 需要 UX架构与体验优化 的场景
- 需要明确输入输出、交接点、验收标准的交付型任务

### 不适用场景

- 只有宏观目标但没有任何流程/规则/角色/输入输出信息
- 纯闲聊/纯观点，不需要落地执行路径

### 使用方法

```
# 方式一：在 AI 工具中直接使用
请将 ux-architect-optimization/SKILL.md 作为系统提示词，分析以下场景：
[粘贴场景描述]

# 方式二：在 OpenClaw/Trae 中注册
cp ux-architect-optimization/SKILL.md ~/.openclaw/workspace/skills/
```
