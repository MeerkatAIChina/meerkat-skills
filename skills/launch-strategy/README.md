# 🚀 发布策略（Launch Strategy）

> **你花了 9 个月打磨产品，然后用一条推文就"发布"了——结果只有 3 个点赞（两个是同事）。**

每天有几千个新产品上线，99% 都悄无声息地死在了发布日。问题不是产品不够好，是你的"发布"只是一个瞬间——而你真正需要的是一场跨越数月的动量战役。最好的公司不是只发布一次，而是把每一次功能更新、每一项改进都变成一个重新被看到的机会。

---

## 🚧 边界：我们能做什么，不做什么

| ✅ 能做的 | ❌ 不做的 |
|-----------|-----------|
| 制定五阶段发布策略 | 不保证 Product Hunt 排名 |
| 规划自有/租用/借用三渠道联动 | 不替你做实际执行和投放 |
| 输出可对照执行的 Launch Checklist | 不跳过"你有没有基本受众"的诚实评估 |

---

## ⚡ 核心能力

1. **ORB 框架** —— Owned（自有：邮件/博客/社区）+ Rented（租用：社交媒体/应用商店）+ Borrowed（借用：嘉宾/合作/网红），三种渠道各司其职，最终汇聚到自有阵地
2. **五阶段发布法** —— 内部测试 → Alpha → Beta → 抢先体验 → 全量发布，每个阶段有明确的动作和交付标准
3. **Product Hunt 攻略** —— 发布前关系建设、发布日全天运营、发布后流量转化，含 SavvyCal 和 Reform 的真实案例
4. **持续发布矩阵** —— 按更新重要度分"大/中/小"三档，避免"憋大招"式沉默
5. **完整 Checklist** —— 发布前/当日/后共 25+ 条可执行检查项

---

## 👤 谁在用

- **创始人**：首次产品发布，需要从 0 到 1 的完整作战计划
- **产品营销经理**：功能发布和版本迭代的常态化营销
- **增长团队**：每个 feature release 都是一次再增长的机会

---

## 🔗 配合使用

- 创建发布落地页 → 调用 `page-cro` 优化转化率
- 设计上线邮件序列 → 调用 `email-sequence`
- 发布后做对比页 → 调用 `programmatic-seo` 或 `competitor-alternatives`
- 制造稀缺感和 FOMO → 参考 `marketing-psychology` 的心理触发技巧

**输入**：发布对象 + 当前受众规模 + 已有渠道
**输出**：分阶段发布计划 + 渠道联动策略 + Launch Checklist + Product Hunt 操作指南
