# 🏗️ Tech Diagram：技术架构图一键生成，让你的 B2B 营销内容「看得懂」

> **一句话定位**：告别拖拽对齐的痛苦——用代码生成技术架构图、管道图、系统堆栈图，直接出 HTML 文件，粘贴即用的营销素材。

---

## 你的痛点

做 B2B 营销最怕什么？**客户看不懂你的产品在技术栈里到底坐在哪**。

你用 Figma/Visio/draw.io 画架构图：对齐框框耗半小时，改个组件名又要重新排，传给开发确认——「这个箭头不应该指向那里」。最后PPT里的图和官网上的架构图还不一样，因为不同人画的。

这个 Skill 用代码生成图：**架构是代码，CSS 是设计系统，SVG 是图形**。改一个组件名 → 全局自动更新。营销提案、技术博客、投资人 Deck——同一套逻辑出不同场景的图。

---

## ✅ 能做什么 | ❌ 不做什么

| ✅ 能做什么 | ❌ 不做什么 |
|-----------|-----------|
| 管道流图（数据管道/CI/CD/ETL） | 不做通用流程图或思维导图（去用 Mermaid） |
| 分层/堆栈图（技术栈/OSI模型/基础设施） | 不做 UI 界面设计或产品原型 |
| 组件架构图（微服务/系统架构） | 不做 3D 渲染或立体效果图 |
| 前后对比图（迁移前 vs 迁移后） | 不做交互式可拖拽图形 |
| 时间线图（Roadmap/迁移阶段/里程碑） | 不做甘特图或项目管理视图 |
| KPI 指标卡片行 | 不做实时数据看板或 BI 仪表盘 |
| 暗色模式默认 + Light 模式打印版 | 不做栅格图像（PNG/JPG）——全 SVG 矢量 |

## 核心能力

| 图表类型 | 适用场景 | 输出特点 |
|---------|---------|---------|
| **管道流图** | 「我们的数据怎么从 A 流到 B」——ETL 工具/数据处理产品演示 | 横向/纵向阶段，箭头连接，每个阶段含图标+标签+说明 |
| **分层堆栈图** | 「我们在技术栈的哪一层」——平台型产品定位 | 垂直堆叠层面，顶层抽象到底层细节 |
| **组件架构图** | 「我们的系统长什么样」——微服务/基础设施 | 网格布局，连接线标明调用关系，含状态标记 |
| **前后对比** | 「用了我们之后有什么变化」——迁移方案演示 | 左右分屏+竖线分隔，一眼看懂差异 |
| **时间线图** | 「我们接下来要干什么」——Roadmap/GTM 节奏 | 横向/纵向里程碑，日期+描述+状态 |
| **KPI 卡片行** | 「关键数字一览」——营销报告/投资人材料 | 大数字+标签+趋势箭头，横向排列 |

**设计系统特性**：
- 暗色模式默认（GitHub 风格 `#0d1117` 底 + 七色强调体系）
- 纯内嵌 HTML——零外部依赖，浏览器直接打开就能截屏/嵌入
- 响应式 800-1400px，PPT 和网页都能用
- 打印友好——`@media print` 自动切亮色背景
