# Paid Ads 付费广告策略大师

> **投放不是「建好广告等转化」——从平台选择到受众定向、出价策略到素材优化，一步错步步错。这是一套覆盖 Google / Meta / LinkedIn / TikTok / X 全平台的投放军规。**

---

## 一、多数人投放失败的根本原因

不是因为预算不够，而是因为：

- 选错了平台（B2B 去投 TikTok，DTC 去投 LinkedIn）
- 账户结构一团乱（30 个 Campaign 抢一个受众池）
- 出价策略和优化目标不匹配（Maximize Clicks 跑电商转化）
- 素材不刷新（同一套素材跑了 3 个月，频率飙到 10+）

`paid-ads` Skill 不是教你「怎么操作某个平台的广告后台」——它教你**怎么做投放决策**。

## 二、平台选择决策矩阵（内置）

| 平台 | 最适合 | 选择条件 |
|------|--------|----------|
| Google Ads | 高意向搜索流量 | 有人在主动搜索你的解决方案 |
| Meta（FB/IG） | 需求激发、视觉产品 | 有强创意素材，希望创造需求 |
| LinkedIn | B2B、决策者触达 | 需要按职位/公司定向，客单价高 |
| TikTok | 年轻用户、病毒式素材 | 18-34 岁受众，有短视频制作能力 |

## 三、核心能力

### 出价策略进阶路径
1. 手动出价或成本上限起步 → 2. 积累 50+ 转化数据 → 3. 切换到自动出价 + 历史数据目标 → 4. 监控并调整

### 素材测试优先级（按影响力排序）
1. **概念/角度**（影响最大）
2. **Hook/标题**
3. **视觉风格**
4. **正文文案**
5. **CTA**

### 预算分配黄金法则
- **测试期（前 2-4 周）**：70% 已验证 + 30% 测试新受众/素材
- **放量期**：预算集中到赢家组合，每次加 20-30%，间隔 3-5 天

## 四、常见错误清单（建立即查）

**策略层面**：无转化追踪就上线 / Campaign 太多预算碎片化 / 不给算法足够学习时间 / 优化错了指标

**定向层面**：受众过窄或过宽 / 不排除现有客户 / 受众重叠互相竞价

**素材层面**：每组只有一个素材 / 从不刷新（疲劳） / 广告和落地页消息不匹配

**预算层面**：跨 Campaign 撒得太薄 / 大改动打断学习期 / 学习期内暂停 Campaign
