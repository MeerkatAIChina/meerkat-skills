# 🧊 Cold Email — B2B冷邮件与跟进序列

> 你的邮件发了100封，回复不到3封。不是你不够努力，是你的邮件读起来像群发模板——而你的客户一眼就能看出来。

---

## 你需要的不是一个更好的模板，而是一种更聪明的写法

**Cold Email** 技能专为B2B冷邮件、SDR外发、潜在客户触达和跟进序列设计。它不教你套用模板，而是帮你写出读起来像人写、而不是机器生成的邮件——那种让对方觉得「这个人真的理解我在做什么」的邮件。

---

## 明确的边界：什么做，什么不做

| ✅ 覆盖范围 | ❌ 不覆盖 |
|---|---|
| B2B冷邮件+多轮跟进序列 | 生命周期/温暖邮件序列（见 `email-sequence`） |
| 邮件主题行、开场、正文、CTA | 落地页文案或社交媒体内容 |
| 个性化体系 + 邮件框架 | HTML设计、图片排版、EDM制作 |

---

## 核心能力

- **像平级同事一样写作**，而不是卖东西
- **4级个性化体系**：从公告信号→领英动态→企业阶段→角色+行业，每一级对应不同深度的研究
- **多种邮件框架**：观察→问题→证明→提问 / 问题→价值→提问 / 触发→洞察→提问 / 故事→桥接→提问
- **短小精悍的主题行**：2-4词，小写，看起来像内部邮件（"reply rates""hiring ops""Q2 forecast"）
- **多轮跟进序列设计**：每封邮件提供新角度，拒绝「just checking in」
- **自检清单**：每封邮件生成后必须通过5项质量检查

---

## 目标用户

- **SDR/销售开发代表**：每天要写几十封个性化拓客邮件
- **创始人/增长负责人**：亲自做冷外联但邮件石沉大海
- **营销运营**：需要建立标准化的冷邮件流程但不牺牲个性化
- 只要你说过「没人回复我的邮件」，这个技能就是为你准备的。

---

## 配合使用建议

| 技能 | 配合方式 |
|---|---|
| `email-sequence` | 冷邮件→热线索后，切换到生命周期邮件序列 |
| `copywriting` | 将冷邮件框架扩展到落地页和网页文案 |
| `social-content` | 冷邮件+LinkedIn联动，多渠道触达 |
| `product-marketing-context` | 自动读取产品定位文件，减少重复提问 |
| `revops` | 邮件回复后的线索打分和管道管理 |

---

## 一句说完

> **冷邮件的敌人不是垃圾邮件过滤器，而是你写出来的东西对方根本不想读。** 两分钟研究 + 一个具体信号 = 不再「冷」。
