# ad-creative — 广告创意生成与迭代

## 定位

面向广告投放从业者和增长团队的专业创意生产工具。基于产品背景、受众洞察和平台最佳实践，批量生成高质量广告文案（标题、描述、正文），并根据真实投放数据持续迭代优化。

## 核心能力

- **跨平台覆盖**：Google Ads、Meta、LinkedIn、TikTok、Twitter/X 以及中国市场主流平台（巨量引擎、腾讯广告、小红书等）
- **双模工作流**：从零生成模式 + 基于数据迭代模式
- **创意角度矩阵**：痛点、成果、社交证明、好奇心、对比、紧迫感、身份认同、逆向思维等8+角度
- **平台规格严格校验**：自动检查字符限制，超标提供裁剪建议
- **批量生产**：支持 CSV 格式输出，支持大规模（100+变体）生产流程
- **广告法合规**：中国市场版内置《广告法》用语检查和替代建议

## 适用场景

- 需要为新活动生成全套广告文案
- 广告疲劳，CTR/CVR 下降，需要新创意
- 有投放数据但不知道如何系统化生成新变体
- 需要适配不同平台的规格差异
- 中国市场广告投放的合规审核和本地化

## 工作流程

```
收集背景信息 → 确定创意角度 → 逐角度生成变体 → 平台规格校验 → 结构化输出 → 数据复盘迭代 → 循环
```

| 步骤 | 说明 |
|------|------|
| 1. 收集背景 | 产品/受众/平台/竞品/品牌规范 |
| 2. 确定角度 | 选择3-5个差异化角度 |
| 3. 生成变体 | 每角度5+变体，变换措辞/具体程度/语气/结构 |
| 4. 规格校验 | 逐条对照平台字符限制 |
| 5. 结构化输出 | 按角度组织+字符标注，支持 CSV 批量 |
| 6. 迭代优化 | 拉取投放数据→分析胜负模式→生成新变体 |

## 使用方法

在对话中提及广告创意相关需求即可激活本 skill，例如：

> "帮我在 Google Ads 上为 SaaS 产品生成15条 RSA 标题"
> "分析这些 Meta 广告投放数据，生成迭代方案"
> "为抖音信息流写10条广告标题，产品是XX，目标用户是XX"

## 示例输出

```
## 角度: [痛点 — 手工报表太慢]

### 标题 (30字以内)
1. "别再做手工报表了" (9)
2. "报表自动化只需5分钟" (10)
3. "告别加班做报表" (8)

### 描述 (90字以内)
1. "市场团队每周节省10+小时。连接数据源，自动生成报表，永久免费试用。" (38)
2. "一次连接，永久自动化。无需代码，5分钟上手。加入10000+团队。" (34)
```

## Skill 配合

- **paid-ads**：广告策略、定向、预算管理
- **copywriting**：落地页文案（广告引流目的地）
- **ab-test-setup**：创意 A/B 测试实验设计
- **copy-editing**：广告文案发布前润色
- **competitor-ads-analyst**：竞品广告情报采集

## 局限性

- 依赖用户提供的产品和受众信息质量
- 不能替代真实 A/B 测试验证
- 中国市场平台规则变化快，需定期更新平台规范
- 合规建议为通用指南，不构成法律意见
