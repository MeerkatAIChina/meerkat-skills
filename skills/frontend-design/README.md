## 🎯 边界说明

| ✅ 能做什么 | ❌ 不做什么 |
|-----------|-----------|
| 确定明确的审美方向（极简/复古未来/编辑风……11 种风格可选） | 不套用组件库的默认样式 |
| 字体搭配：展示字体 + 正文字体 + 免费字体源推荐 | 不使用 Inter/Roboto/Arial 等「默认感」字体做展示 |
| 配色体系：主色→强调色→中性色→语义色，CSS 自定义属性输出 | 不生成紫色渐变+霓虹强调色的「AI 味儿」配色 |
| 动画设计：微交互/环境动画/滚动触发/交错展示，GPU 加速 | 不动画 width/height/margin（会触发重排） |
| 空间构图：非对称布局、网格打破、z-index 叠加 | 不生成 hero→三列→客户案例→CTA 的流水线布局 |
| 输出可直接运行的 HTML/CSS/JS 或 React 代码 | 不引入不必要的外部依赖 |
| 与 `brand-dna` 联动：读取品牌基因文件，自动适配品牌色和字体 | — |

## 🧰 核心能力

### 设计思维四步法

| 步骤 | 内容 |
|------|------|
| **1. 理解场景** | 明确页面目的、目标用户、技术约束、性能要求 |
| **2. 确定审美方向** | 从 11 种风格中选一个（极简/极繁/复古未来/有机自然/奢华精致/趣味玩具/编辑杂志/粗野主义/Art Deco/柔和粉彩/工业实用） |
| **3. 找到记忆点** | 每个页面至少有一个让人记住的元素——意外交互/独特字体/大胆配色/打破常规的布局 |
| **4. 精准执行** | 「极致」是关键词：极简就极简到底，极繁就极繁到底——不活在中间地带 |

### 技术能力

| 领域 | 能力 |
|------|------|
| **字体搭配** | 展示字体（个性）+ 正文字体（可读性），Google Fonts/Fontshare/Fontsource 免费源推荐 |
| **配色系统** | 一主色 + 1-2 强调色 + 中性色阶 + 语义色，全部 CSS 变量化 |
| **动效设计** | CSS transition（微交互）+ @keyframes（环境动画）+ IntersectionObserver（滚动触发）+ 交错延迟 |
| **空间构图** | CSS Grid 复杂布局 + Flexbox 组件对齐 + 非对称打破 + z-index 深度叠加 |
| **代码质量** | 语义化 HTML + ARIA 无障碍 + 响应式 320-1440px + 懒加载 + 零外部依赖 |
| **反模式清单** | 内置一组「不要这样做」的设计禁忌，帮你避开 AI 生成页面的通病 |
