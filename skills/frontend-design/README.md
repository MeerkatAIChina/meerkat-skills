# Frontend Design — 拒绝"AI 味"的前端界面设计引擎

> 紫色渐变 + 毛玻璃 + Inter 字体 + 居中三列布局 = 一眼 AI。Frontend Design 让你的界面有自己的审美 DNA。

## 痛点：AI 生成的前端代码长得都一个样

你让 AI 帮你写个 landing page——它给你一套紫色渐变 + 毛玻璃卡片 + Inter 字体 + hero→三列→testimonials→CTA 的标准模板。好看吗？谈不上。难看吗？也不至于。问题在于：**这种"不丑也不美"的 AI 美学已经在大规模量产，用户看三秒就知道这不是人设计的。**

真正的设计不是从组件库里拼积木。它是关于"这个界面要让人记住什么"的选择——一个大胆的字体、一种不常见的配色、一段有性格的动效、一个打破常规的布局。

## 能力：设计思维驱动的真实代码生成

`frontend-design` 不是 UI 组件库，而是**设计决策引擎**。它在生成代码之前先做四件事：

1. **理解场景** — 这个界面解决什么问题？谁来用？他们在什么情绪状态下到达？
2. **确定美学方向** — 11 种方向可选：极致简约 / 马克西姆主义 / 复古未来 / 有机自然 / 奢侈精致 / 趣味玩具风 / 编辑杂志风 / 野性粗野主义 / 装饰艺术 / 柔和粉彩 / 工业实用主义。选一种，走到极致。
3. **找到"记忆点"** — 每个界面至少有一个让人记住的元素：一次意外的交互、一个独特的排版处理、一个大胆的色彩选择。
4. **承诺执行** — 极繁就做到极繁，极简就做到极简。模糊地带才是设计的敌人。

输出的是**真实的、可运行的 HTML/CSS/JS 或 React 代码**——包含完整的字体搭配（非 Inter/Roboto 默认字体）、CSS 自定义属性构建的调色板、GPU 友好的动效、符合 WCAG AA 标准的可访问性、以及语义化的 HTML 结构。

如果工作目录下有 `brand-profile.json`（来自 `brand-dna` 技能），会自动读取品牌色、字体偏好和美学关键词来构建设计系统。

## 谁在用？

- **前端 / 全栈开发者**：需要一个不像模板的 landing page、产品页或 dashboard。
- **独立创作者 / 创业者**：没有设计师但需要一个有辨识度的产品界面。
- **设计师转前端**：快速将设计意图落地为可交互的代码原型。
- **DevRel / 技术布道师**：为 demo 和 workshop 准备专业视觉。

## 配合其他技能

- **`brand-dna`**：先生成品牌 DNA 配置文件，再让 Frontend Design 自动读取。
- **`html-report-builder`** / **`pro-report-builder`**：如果需要的是报告/文档而不是交互界面，用这两个。
- **`pro-deck-builder`**：如果需要的是 PPT 演示而不是网页，用这个。
