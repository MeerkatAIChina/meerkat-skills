# Wasted Spend Finder 浪费预算猎手

> **一个不为人知的事实：大多数广告账户里，15-30% 的预算被「看不见的浪费」吞噬——不是跑得不好，是根本不该跑。**

---

## 一、你的广告费花到哪去了？

打开你的 Google Ads 搜索词报告，你可能会发现：

- 「免费版 XX 软件」——搜索词，花了 $800，零转化（用户在找免费替代品）
- 「XX 公司招聘」——花了 $450，零转化（求职者点了你的广告）
- 一批 Display Network 的不知名 App 和游戏网站——花了 $1200，零转化
- Meta Audience Network 上的低质量应用——花了 $600，CTR 0.1%

**这些不是「表现差」——这些是「根本不该存在的支出」。**

`wasted-spend-finder` Skill 就是专门干这件事的：**系统化扫描你的 Google Ads 和 Meta 账户，找出每一分不该花的钱。**

---

## 二、它怎么找浪费？

### Google Ads 浪费检测
1. **搜索词浪费** → 零转化 + 超过花费阈值的搜索词
2. **展示位置浪费** → Display Network / YouTube 零转化投放位
3. **关键词浪费** → 低转化率关键词（相对于花费）

### Meta Ads 浪费检测
1. **版位浪费** → Audience Network 低质量应用
2. **受众浪费** → Lookalike / 兴趣定向表现极差
3. **素材浪费** → 高频率 + 零转化 = 素材疲劳

### 科学阈值（不是拍脑袋）

```
浪费阈值 = 平均 CPA × 系数
系数按 Campaign 类型：
- Search（品牌词）：2×CPA
- Search（非品牌）：3×CPA
- Display：3×CPA
- Meta（全部）：2.5×CPA
```

**触发条件**：花费 > 阈值 + 转化 = 0 + 满足最低点击门槛

| 输出文件 | 内容 |

| `negative-keywords.csv` | 否定关键词清单，含匹配类型、Campaign/Ad Group 范围 |

全部 CSV 格式，可直接上传到广告平台批量排除。

## 四、安全原则（不可违反）

1. **只分析，不操作**——永远不自动修改线上账户
2. **所有预测是估算**——明确标注所有节省金额为预估值
3. **检查误杀**——一些高花费零转化的词可能处于用户考虑期
4. **考虑归因**——浏览型转化和辅助转化可能让一些「浪费」是合理的
5. **保留数据**——应用任何排除前先导出当前状态备份

## 五、谁应该用？

- ✅ **SEM 优化师**：接新账户第一件事——扫描浪费
- ✅ **每月账户卫生检查**：固定日程，月月执行
- ✅ **预算优化前**：先砍浪费，再谈优化
- ✅ **代理商**：为客户提供「省了多少钱」的可量化成果
