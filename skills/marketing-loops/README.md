# 🔁 Marketing Loops — 让营销从「想起来才做」变成「按节奏自动跑」

> **排名该看的时候没人看、素材疲劳了没人换、流失信号出现三天后才反应——营销的问题往往不是「不会做」，而是「没人持续做」。这个 SKILL 把一次性的营销动作，变成有触发条件、有自检、有停止线的循环系统。**

---

## 😫 你是否也遇到过这些问题？

- 上周说好每周一看排名和竞品动态，结果连续三周忘了
- 广告素材明明已经跑疲了，但没人盯着，钱继续花
- 流失信号（活跃度下滑、投诉增加）出现了，等发现时客户已经走了
- 知道该做「持续运营」，但每次都是临时想起来才做一次，做完就断
- 已经在用各种营销 SKILL，但每个都要手动喊一遍，没有「自己会跑」的机制

如果这说的就是你——这个 SKILL 就是为你准备的。

## ✅ 能做什么 | ❌ 不做什么

| ✅ 能做 | ❌ 不做 |
|---------|---------|
| 设计完整营销循环：检查节奏 / 触发条件 / 循环体 / 自检 / 停止条件 / 状态去重 | 不替你制定品牌定位、创意方向或战略决策 |
| 提供 43 个现成循环目录（SEO与内容 / 付费 / 自然流量与社媒 / 激活 / 留存 / 营收 / 推荐 / 日常运营） | 不自动发布内容、不自动调整预算（除非明确授权并设定护栏） |
| 按「信号变化速度」匹配节奏——排名按周、素材疲劳按 2–3 天、流失信号按天 | 不提供具体平台后台的自动化脚本 |
| 循环护栏设计：自主执行 vs 人工审批的两级动作模型、预算/发送上限、Kill Switch | 信号量太小的场景不做（如每周 40 访客的转化率循环＝在测噪声） |
| 与定时任务（cron）对接，让循环真正跑起来 | 不做虚荣循环（没人看结果的仪表盘不如没有） |
| 编排调用其他营销 SKILL 组成完整循环体 | 不承诺「全自动营销」这类效果 |

## 🧰 核心能力

| 模块 | 说明 |
|------|------|
| **循环九要素** | 每个循环必须填满：检查节奏、触发条件、目的、调用的 SKILL、循环体步骤、自检、状态/幂等、停止/退出、输出位置。缺一项就是负债而不是资产 |
| **节奏规则** | 一张表告诉你每类信号的真实变化速度——过度频繁的循环是最常见的失败模式，它制造忙碌感、烧预算，还训练你忽略输出 |
| **「什么时候不该做循环」判断** | 策略和创意方向是真正的工作时不做；动作会发布或花钱时不做；信号太稀疏时不做；虚荣循环不做 |
| **43 个循环目录** | 覆盖从 SEO 机会扫描、素材疲劳刷新、流失信号监控到每周营销复盘的完整清单，每个都是可直接改用的完整规格 |
| **循环护栏** | 两级动作模型、花钱/发送上限、CAN-SPAM/GDPR/FTC/平台条款规则、必升级清单、必备 Kill Switch |
| **状态与幂等** | 循环之间记住什么：上次运行标记、去重键、冷却窗口、「已处理」集合——没有它，循环会重复动作、反复骚扰同一批人 |
| **编排与落地顺序** | 多个循环如何组合、按什么顺序上线（先做追踪＋每周复盘，别一次上 43 个） |
| **调度方式** | 循环体与 Agent 无关；调度按环境走——Claude Code 原生 `/loop`、通用 cron、或「每周一手动跑一次」都是合格的循环 |

## 👤 谁应该用

- ✅ 一个人扛全盘营销的操盘手，需要把精力从「记得做」转向「判断做什么」
- ✅ 已经在用各种营销 SKILL、想让它「定期自己跑」的团队
- ✅ 需要向管理层交付「持续运营能力」而不是「一次性项目」的增长负责人
- ✅ 咨询顾问，帮客户建立营销运营节奏和护栏规范
- ✅ 快消 / 消费品品牌的市场负责人，需要常态化的内容刷新与竞品监控机制
