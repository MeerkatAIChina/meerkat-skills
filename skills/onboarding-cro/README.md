# 新用户激活优化（Onboarding CRO）——让注册用户真正「用起来」，而不是看一眼就走

## 😫 痛点

你的注册量在涨，但打开产品后台一看——**60% 的用户注册后就再也没回来过。** 偶尔回来的人也只是点两下就消失了。你花了大量预算在投放上把人拉进来，结果他们像穿过一个旋转门：进来了，马上又出去了。

这不是流量质量的问题。这是**「从注册到第一次感受到价值」之间的路径太长了。** 你的产品也许确实能解决问题，但在用户真正体验到之前，他们已经失去了耐心。

更糟的是：你可能根本不清楚用户的「aha moment」是什么。你不知道那个让用户心里暗叫一声「卧槽这个好用」的关键动作在哪里，于是你的 onboarding 流程只是在机械地引导他们「完善资料」「邀请队友」「探索功能」——而不是直奔那个让他们决定留下来的瞬间。

## 🎯 这个技能能做什么

| ✅ 能做什么 | ❌ 不做什么 |
|:---|:---|
| 帮你定义产品的「aha moment」和激活标准 | 不替你写代码实现 onboarding 流程 |
| 设计从注册后第一秒到激活完成的全链路体验 | 不保证激活率的具体提升数字（一切取决于实验验证） |
| 输出包含流程设计、清单项、空状态文案、邮件触发、指标方案的可执行计划 | 不替代注册页面优化（归 `signup-flow-cro` 管） |
| 诊断用户在哪一步流失最大，给出针对性优化建议 | 不负责激活后的长期留存策略 |

## 🧠 核心能力

| 能力模块 | 说明 |
|:---|:---|
| **Aha Moment 挖掘** | 通过「留存用户做了什么而流失用户没做」的对比分析，找到与长期留存最强相关的那个关键动作 |
| **注册后 30 秒决策** | 产品优先 / 引导设置 / 价值优先——三种首屏策略的选择与利弊分析 |
| **Onboarding Checklist 设计** | 3-7 项按价值排序的任务清单，从快速胜利开始，带进度条和完成庆祝 |
| **空状态设计** | 把「这里什么都没有」变成「这是你可以创造的第一个东西」——空状态是 onboarding 机会，不是死胡同 |
| **多渠道联动** | 欢迎邮件 → 未完成引导（24h/72h 提醒）→ 激活祝贺 → 功能发现（3/7/14 天）的触发式邮件序列 |
| **流失用户挽回** | 定义「停滞」标准 → 邮件序列 → 应用内恢复 → 高价值用户人工触达 |
| **漏斗分析与指标体系** | 注册→步骤1→步骤2→激活→留存，每一步的流失率追踪 + 激活率/激活时长/Day 1-7-30 留存 |
| **按产品类型适配** | B2B SaaS / 交易平台 / 移动应用 / 内容平台——四种产品类型的差异化激活路径 |

## 👤 谁应该用

- ✅ **SaaS 产品经理**：注册量不错但激活率长期低迷，需要系统性诊断和优化 onboarding 流程
- ✅ **增长/转化优化团队**：已优化完注册转化，下一步就是让注册的人真正用起来
- ✅ **创始人/早期团队**：产品早期需要定义核心激活行为，建立增长的基本盘

- 追踪 onboarding 漏斗数据 → 调用 `analytics-tracking`
