# Copywriting Skill — AI 营销文案专家

> 让 AI Agent 具备专业转化文案撰写能力。从首页到落地页，从标题到 CTA，系统化产出高质量营销文案。

---

## 📌 一句话定位

**Copywriting** 是一个面向 AI Agent 的营销文案写作技能。当用户需要撰写或优化网页文案时，Agent 自动加载此 Skill，按照 5 阶段工作流完成：上下文收集 → 语调确认 → 草稿撰写 → 修订迭代 → 最终交付。

---

## 🎯 核心能力

### 1. 结构化文案生产
不是"随便写一段"，而是按页面类型（首页/落地页/定价页/产品页）执行对应框架，覆盖：Above the Fold → 社会证明 → 痛点 → 解决方案 → 工作原理 → 异议处理 → 最终 CTA。

### 2. 多选项输出
每次产出提供 2-3 个标题方案 + 2-3 个 CTA 方案，标注每个方案最适合的受众类型。让人类做选择题而非填空题。

### 3. 中国市场深度适配
内置中国市场（快消品/消费品/电商）专属规则：
- **平台格式**：天猫详情页模块化、抖音小红书 hook 开头、微信朋友圈广告字符限制
- **语言习惯**：四字格、对仗、具体数字的社会证明
- **合规红线**：中国广告法对绝对化用语（最/第一/顶级）的限制

### 4. 4 个用户确认检查点
在每个关键决策点暂停，等用户确认后再继续——避免方向性返工：
- ⏸ 上下文确认
- ⏸ 语调确认
- ⏸ 草稿呈现
- ⏸ 最终审批

### 5. 自检机制
交付前执行 5 类 20+ 项自查清单（清晰度/说服力/结构/语调/技术规范），并提供 8 大常见陷阱警示。

## 📋 适用场景

### ✅ 应该使用
- 撰写新的网站文案（首页、落地页、定价页、产品页、关于页）
- 优化现有文案（"这段文案太弱了，帮我改改"）
- 需要多个标题/CTA 方案做 A/B 测试
- 从英文文案改编为中文市场版本
- 电商详情页/抖音/小红书等平台特定格式文案

### ❌ 不应该使用
- **编辑润色已有文案** → 使用 `copy-editing`（精细逐行审校）
- **撰写邮件序列** → 使用 `email-sequence`
- **弹窗文案** → 使用 `popup-cro`
- **页面结构/转化策略优化**（非纯文案） → 使用 `page-cro`

## 🔄 工作流程

```
用户请求
    │
    ▼
Phase 1: 收集上下文 ──→ ⏸ CHECKPOINT 1: 确认上下文
    │
    ▼
Phase 2: 确定语调 ──→ ⏸ CHECKPOINT 2: 确认语调
    │
    ▼
Phase 3: 撰写草稿 ──→ 应用文案原则 + 页面框架 + 自检清单
    │                    │
    │                    ▼
    │              ⏸ CHECKPOINT 3: 呈现草稿（含标注 + 备选方案）
    │
    ▼
Phase 4: 修订迭代 ──→ 融入用户反馈
    │                    │
    │                    ▼
    │              ⏸ CHECKPOINT 4: 最终审批
    │
    ▼
Phase 5: 交付 ──→ 按规范格式输出 + 提醒可用的配套 Skill
```

```bash
cp -r skills/copywriting ~/.claude/skills/

# Hermes Agent
cp -r skills/copywriting ~/.hermes/skills/

# OpenClaw

```

### 触发方式

Agent 在以下情况会自动激活此 Skill：
- 用户说 "帮我写一段首页文案"
- 用户说 "这个落地页的标题帮我优化一下"
- 用户说 "我需要一个 CTA 按钮的文案"
- 用户说 "write copy for our pricing page"

### 最佳实践

1. **先准备 product-marketing-context.md**：如果有产品营销上下文文档，Skill 会先读取，减少追问
2. **提供具体信息**：页面类型、目标受众、核心差异点、流量来源
3. **善用 CHECKPOINT**：每个确认点认真审核，避免方向性返工
4. **草稿后再精细编辑**：写作阶段先产出，修订阶段再打磨，不要一边写一边改
5. **配合 copy-editing 使用**：最终交付前用 copy-editing 做一遍逐行审校

## ⚠️ 注意事项与局限性

### 局限性
- **不会设计**：产出的是文案文本，不是视觉设计稿
- **不会自动发布**：需要人工将文案部署到网站/TMS
- **依赖输入质量**：上下文越模糊，产出越泛泛
- **品牌语调需校准**：首次使用可能需要 1-2 轮调整才能匹配品牌
- **不适合长文**：博客文章、白皮书、案例研究等长内容请配合其他 Skill

### 中国市场特别注意
- 避免使用"最""第一""顶级"等绝对化用语（违反中国广告法）
- 数字社会证明需要真实可验证
- 各平台有严格的字符限制（微信朋友圈标题 ≤20 字符）
