# Copywriting Skill — AI 转化文案专家

> 让 AI Agent 具备专业转化文案撰写能力。从首页到落地页，从标题到 CTA，系统化产出高质量营销文案——清晰、有力、驱动行动。

---

## 📌 一句话定位

**Copywriting** 是一个面向 AI Agent 的营销文案写作技能。Agent 按 5 阶段工作流完成：上下文收集 → 语调确认 → 草稿撰写 → 修订迭代 → 最终交付，每个阶段设有用户确认检查点，避免方向性返工。

---

## 🎯 核心能力

### 1. 结构化文案生产
按页面类型（首页/落地页/定价页/产品页/关于页）执行对应框架：Above the Fold → 社会证明 → 痛点 → 解决方案 → 工作原理 → 异议处理 → 最终 CTA，覆盖完整转化链路。

### 2. 多方案输出
每次产出提供 2-3 个标题方案 + 2-3 个 CTA 方案，标注每个方案最适合的受众类型。让人类做选择题，而非填空题。

### 3. 中国市场深度适配
内置中国市场专属规则：
- **平台格式**：天猫详情页模块化结构、抖音小红书 hook 式开头、微信朋友圈字符限制
- **语言习惯**：四字格、对仗句式、具体数字的社会证明（\"已服务 50 万家庭\"而非\"广受好评\"）
- **合规红线**：中国广告法对绝对化用语（最/第一/顶级）的限制规避

### 4. 4 个用户确认检查点
- ⏸ 上下文确认
- ⏸ 语调确认
- ⏸ 草稿呈现（含标注 + 备选方案）
- ⏸ 最终审批

### 5. 自检机制
交付前执行 5 大类 20+ 项自查清单：清晰度与可读性、说服力与行动、结构与流程、语调与声音、技术规范。提供 8 大常见陷阱警示。

## 📋 适用场景

### ✅ 应该使用
- 撰写新网站文案（首页、落地页、定价页、产品页、关于页）
- 优化现有文案（\"这段太弱了，帮我改改\"）
- 需要多个标题/CTA 方案做 A/B 测试
- 从英文文案改编为中文市场版本
- 电商详情页、抖音/小红书等平台特定格式文案

### ❌ 不应该使用
- **编辑润色已有文案** → 使用 `copy-editing`（精细逐行审校）
- **撰写邮件序列** → 使用 `email-sequence`
- **弹窗文案** → 使用 `popup-cro`
- **页面转化策略优化**（非纯文案） → 使用 `page-cro`

## 🚀 使用方法

### 安装

```bash
# Claude Code
cp -r skills/copywriting ~/.claude/skills/

# Hermes Agent
cp -r skills/copywriting ~/.hermes/skills/
```

### 触发方式

Agent 在以下情况自动激活此 Skill：
- \"帮我写一段首页文案\"
- \"这个落地页的标题帮我优化一下\"
- \"我需要一个 CTA 按钮的文案\"
- \"write copy for our pricing page\"

### 最佳实践

1. **先准备 product-marketing-context.md**：有产品营销上下文文档时，Skill 会先读取，减少追问
2. **提供具体信息**：页面类型、目标受众、核心差异点、流量来源越清晰，产出越精准
3. **善用 CHECKPOINT**：每个确认点认真审核，避免方向性返工
4. **先产出再打磨**：写作阶段先出内容，修订阶段再精细调整
5. **配合 copy-editing 使用**：最终交付前做一遍逐行审校

## ⚠️ 注意事项与局限性

### 局限性
- **产出文案文本，非视觉设计稿** — 最终需要人工部署
- **依赖输入质量** — 上下文越模糊，产出越泛泛
- **品牌语调需校准** — 首次使用可能需要 1-2 轮调整
- **不适合长文** — 博客、白皮书、案例研究等长内容请配合其他 Skill

### 中国市场特别注意
- 避免使用\"最\"\"第一\"\"顶级\"等绝对化用语（违反中国广告法）
- 数字社会证明需真实可验证
- 各平台有严格字符限制（微信朋友圈标题 ≤20 字符）
