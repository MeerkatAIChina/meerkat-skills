# Social Content 社交媒体内容创作大师

> **一篇博客 = 一条 Twitter Thread + 一个 LinkedIn Carousel + 一个 Instagram Reel + 一个 TikTok 短视频。不是「多平台分发」，是「一次创作，四处开花」。**

---

## 一、核心痛点

- 不知道每个平台该发什么、发多少
- 写了一篇长文不知道怎么拆成社交媒体内容
- 不同平台的格式、语气、最佳发布时间完全没概念
- 内容没有支柱（pillars），东一榔头西一棒子

`social-content` Skill 覆盖 LinkedIn / Twitter(X) / Instagram / TikTok / Facebook 五大平台的完整内容创作体系。

---

## 二、核心能力

| 能力 | 覆盖 |
|------|------|
| **平台适配** | LinkedIn / Twitter / Instagram / TikTok / Facebook |
| **内容支柱框架** | 行业洞察(30%) + 幕后故事(25%) + 教育内容(25%) + 个人(15%) + 推广(5%) |
| **格式转换** | 长文 → Thread / Carousel / Reel / Short |
| **短脚本** | Video Hook + Story + CTA 公式 |
| **内容日历** | 多平台排期 + 内容复用 |

---

## 三、谁应该用？

- ✅ 个人品牌创业者（需要 LinkedIn + X 双平台内容）
- ✅ SaaS 内容团队（用博客文章分裂成社交媒体内容）
- ✅ 社交媒体经理（统一管理多平台）

---

## 四、配合使用

| 配合 Skill | 场景 |
|-----------|------|
| `content-strategy` | 先定内容策略，再做社交分发 |
| `social-media-strategy` | 长期社交媒体策略规划 |
| `brand-voice-guidelines` | 确保跨平台语气一致 |
| `linkedin-authority-builder` | LinkedIn 深度内容系统 |

---

> **不要为每个平台单独写内容——学会「裂变」。一篇好内容应该活在 5 个平台上。**
