# ✂️ 文案精修（Copy Editing）

> **你的文案读起来"还行"，但"还行"在市场上等于"不存在"。**

没有人读完你的落地页后会感慨"这段文案写得真完整"——他们要么被触动、要么划走，没有中间状态。大多数企业文案的问题不在方向，而在执行：句子太长、情绪太淡、证明缺失、模糊词汇一堆。好消息是，你不需要重写，你需要的是一个系统化的精修框架——用 7 次聚焦扫描，把"能用"变成"能打"。

---

## 🚧 边界：我们能做什么，不做什么

| ✅ 能做的 | ❌ 不做的 |
|-----------|-----------|
| 用七扫法系统优化已有文案 | 不改变你的核心信息方向 |
| 每次扫一遍只聚焦一个维度 | 不把"换个词"包装成"优化" |
| 高价值文案启用专家评审团打分 | 不做从零撰写（那是 copywriting 的事） |

---

## ⚡ 核心能力

1. **七扫法（Seven Sweeps）** —— 逐层过 Clarity（清晰度）→ Voice（语气一致）→ So What（利益锚定）→ Prove It（证据支撑）→ Specificity（具体度）→ Emotion（情绪张力）→ Zero Risk（零阻力）
2. **专家评审团** —— 高价值文案（落地页/发布邮件/销售页）启用 3-5 个专家角色模拟评分，单人视角容易遗漏的问题被多人交叉识别
3. **快速编辑清单** —— 低风险场景用"一词一句一段"速查，砍掉弱词、被动语态、名词化
4. **内容刷新** —— 旧页面流量下滑？按刷新/重写决策矩阵判断该修还是该重做
5. **回环验证** —— 每次扫完后强制回溯之前所有维度，确保修 A 不破 B

---

## 👤 谁在用

- **文案团队**：写完初稿后做系统化打磨
- **增长团队**：优化落地页、邮件、广告文案的转化率
- **创始人**：自己写的文案需要第二双专业眼睛

---

## 🔗 配合使用

- 精修前先检查 → `product-marketing-context` 确保品牌语气一致
- 精修后做测试 → 调用 `ab-test-setup` 验证修改效果
- 需要从零写新文案 → 先跑 `copywriting` 或 `copywriting-frameworks`，再回来做编辑
- 需要页面级优化 → 调用 `page-cro` 合并编辑和其他优化维度

**输入**：已有文案
**输出**：逐扫标注 + 修改建议 + 专家评审分 + 修改后版本
