# Marketing Psychology Skill — 营销心理学专家

> 让 AI Agent 运用心理学和行为科学原理，驱动营销决策和转化优化。

---

## 📌 定位

**Marketing Psychology** 将认知偏差、心智模型和行为科学应用于营销实践。帮助理解"消费者为什么买"，并将这些洞察转化为可执行的营销策略。

---

## 🎯 核心能力

1. **心智模型库** — 覆盖锚定效应、损失厌恶、社会认同、稀缺性等 20+ 心理学原理
2. **场景匹配** — 根据营销目标（提升转化/降低跳出/增加复购）推荐适用心理策略
3. **中国市场心理洞察** — 面子消费、从众效应、电商节日稀缺、社交信任机制
4. **A/B 测试假设** — 将心理学原理转化为可验证的测试假设

---

## 📋 适用场景

### ✅ 应该使用
- 想理解某个营销现象背后的心理原因
- 设计高转化落地页的心理策略
- 分析竞品的心理学手法
- 制定中国市场的消费者心理策略

### ❌ 不应该使用
- 具体页面优化 → `page-cro`
- 文案撰写 → `copywriting`
- 弹窗设计 → `popup-cro`

## 🚀 使用方法

```bash
cp -r skills/marketing-psychology ~/.claude/skills/
```

触发："为什么用户不下单""用什么心理策略提升转化""中国消费者心理"

---

## ⚠️ 局限性

- 不替代用户研究和 A/B 测试
- 心理学原理需要结合具体产品和受众
- 中国市场心理洞察基于通用研究，具体行业可能有差异
