# 🧬 品牌基因提取（Brand DNA）

> **你的品牌看起来像 10 个不同的人写的——客户很困惑，但你不知道从哪对齐。**

每次做内容、写邮件、设计页面，团队都在"凭感觉"还原品牌风格。结果呢？推文像 A 公司，落地页像 B 公司，邮件又像 C。品牌一致性不是审美问题——是转化问题。不一致的视觉和语气会让用户对你的专业度产生怀疑，在无声中流失信任。

---

## 🚧 边界：我们能做什么，不做什么

| ✅ 能做的 | ❌ 不做的 |
|-----------|-----------|
| 从网站抓取品牌色彩、字体、语气 | 不替没有网站的品牌凭空捏造基因 |
| 10 维语气评分（正式度、情感度等） | 不猜测——字段缺失就标 null |
| 输出结构化的 brand-profile.json | 不分析 JS 渲染不全的单页应用 |

---

## ⚡ 核心能力

1. **一键提取** —— 输入网址，自动拉取首页 + About + 产品页，抓取 CSS 色彩/字体/语气信号
2. **10 维语气分析** —— 从文案中量化"正式↔随意""理性↔感性""大胆↔含蓄"等维度
3. **结构化输出** —— 生成 `brand-profile.json`，可直接被其他 5+ 个技能消费
4. **零依赖** —— 不调用任何外部 API，纯 WebFetch 工具实现，支持快速模式和深度模式

---

## 👤 谁在用

- **品牌负责人**：接管一个品牌时，快速建立基准档案
- **代理商**：为客户网站做竞品品牌审计
- **内容团队**：拿到 brand-profile.json 后，所有下游输出自动对齐

---

## 🔗 配合使用

生成的 profile 直接喂给 `seo-content-writer`（语气匹配）、`email-composer`（语调校准）、`frontend-design`（视觉一致）、`pro-deck-builder`（品牌色彩/字体）、`cross-platform-audit`（多渠道一致性检查）。一次提取，全栈复用。

**输入**：网站 URL
**输出**：brand-profile.json（色彩、字体、语气评分、价值观、目标人群画像）
