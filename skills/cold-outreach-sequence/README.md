# 🎯 Cold Outreach Sequence — LinkedIn + 邮件双渠道外联序列

> 你花3小时搜了50个潜在客户，然后群发了一条「Hi, I'd love to connect」——结果呢？冷外联之所以「冷」，不是因为对方不认识你，而是你对对方一无所知。

---

## 10分钟研究 + 一个具体信号 = 不再冷

**Cold Outreach Sequence** 教你构建基于研究的、个性化的LinkedIn+邮件双渠道外联序列。从连接请求到第21天告别信，每一步都必须建立在真实信号之上——新闻、融资、领英动态、企业阶段——而不是通用模板。

---

## 明确的边界

| ✅ 覆盖范围 | ❌ 不覆盖 |
|---|---|
| LinkedIn连接请求+DM序列 | 单封冷邮件撰写（见 `cold-email`） |
| 双渠道（LinkedIn + Email）外联 | 社交媒体广告或内容营销 |
| 信号研究、个性化分层、外联追踪 | EDM批量分发或营销自动化 |

---

## 核心能力

- **三种模式按需选择**：`quick`（单次外联）→ `standard`（完整4轮触达序列）→ `deep`（多客户外联系统+A/B测试+追踪框架）
- **强制研究网关**：不完成网络搜索（新闻/融资/LinkedIn动态），不输出任何消息
- **4级信号体系**：新闻事件 > LinkedIn帖子 > 企业阶段数据 > 角色+行业认知
- **3级个性化分层**：Tier 1全定制引用信号、Tier 2模板+个性开场、Tier 3批量模板
- **5轮序列模板**：连接请求(≤300字符) → 第一封消息(24-48h后) → 跟进#1(Day 7) → 跟进#2(Day 14) → 告别信(Day 21)
- **每轮添加新价值**：绝不说「just following up」，必须带新信号、新角度或新洞察
- **自批评检查清单**：每条消息必须通过6项质量审查
- **外联追踪表**：自动输出客户-公司-平台-层级-状态-下一步追踪表
