# 🕵️ 竞品广告提取器 — 不用再猜竞品在投什么广告

> **一句话：直接从 Facebook / LinkedIn 广告库抓取竞品广告，分析他们的文案策略、创意模式、受众定位——把你的广告策略建立在真实数据上，而不是拍脑袋。**

---

## 🤔 你是不是也经历过这些？

你盯着竞品的广告，脑子里全是问号：
- 「他们的广告为什么一直在跑？到底什么文案在起作用？」
- 「我想知道竞品在强调什么痛点、打什么人群、用什么视觉风格……但我只能手动翻广告库，翻到眼花」
- 「竞品换了新广告策略，我过了一个月才发现」

**竞品广告提取器**就是来解决这个的——自动化抓取 + 结构化分析，让你像读财报一样读懂竞品的广告策略。

---

## 🎯 边界说明

| ✅ 能做什么 | ❌ 不做什么 |
|-----------|-----------|
| 从 Facebook Ad Library / LinkedIn 抓取竞品广告 | 不直接复制竞品文案（研究+启发，非抄袭） |
| 分析竞品文案模式、痛点强调、CTAs 策略 | 不获取广告投放数据（花费/展示量/点击率） |
| 截图保存广告素材，建立竞品广告档案库 | 不在未经许可的平台抓取 |
| 对比多个竞品的广告策略差异 | 不替代 A/B 测试——分析完还得自己测 |
| 按主题/受众/格式分类广告 | — |

---

## 🧰 核心能力

| 能力 | 说明 |
|------|------|
| **广告提取** | 从 Facebook Ad Library、LinkedIn 等广告库批量抓取竞品当前投放的广告 |
| **截图保存** | 自动保存所有广告的视觉素材，建立可回溯的竞品广告档案 |
| **文案分析** | 识别竞品在强调什么痛点、什么使用场景、什么价值主张 |
| **广告分类** | 按主题、目标受众、广告格式自动分组 |
| **模式识别** | 找出竞品反复使用的高频模式——什么文案结构、什么视觉风格在持续投放 |
| **策略洞察** | 解释为什么某些广告可能表现好，给出你的广告优化建议 |
| **多竞品对比** | 同时分析 5 个竞品，对比各自的定位差异和文案策略 |
| **趋势追踪** | 按季度对比竞品广告变化，捕捉策略转向 |
| **多格式输出** | 分析报告(Markdown) + 截图 + CSV 数据表 + 可视化演示 |

## 👤 谁应该用

- ✅ 广告投放负责人——需要了解竞品在投什么，避免盲投
- ✅ 品牌策略师——需要研究市场定位和差异化角度
- ✅ 内容营销人——需要从竞品广告中获取文案灵感
- ✅ 产品营销经理——需要了解竞品在强调哪些使用场景
- ✅ 创业公司增长负责人——需要快速了解行业广告打法
- ✅ 代理商/Agency——需要为客户提供竞品广告情报
