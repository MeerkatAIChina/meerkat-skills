# 📰 Public Relations — 公关与免费媒体报道操盘手

> **不花广告费也能上媒体：找对记者、讲对故事、蹭对热点——把「怎么才能被报道」变成一套可执行的流程。**

---

## 😫 你是否也遇到过这些问题？

- 产品明明不错，但除了自己发的公众号/官网，外界没有任何声量
- 想联系记者和媒体，却不知道去哪找人、怎么开口，发出去的稿子石沉大海
- 看到行业热点想借势发声，等写完稿热点已经凉了
- 没有媒体资料页（Press Kit），记者想报道你都找不到素材

如果这说的就是你——这个 SKILL 就是为你准备的。

---

## ✅ 能做什么 | ❌ 不做什么

| ✅ 能做 | ❌ 不做 |
|---------|---------|
| 判断你的公司现阶段值不值得做 PR（内置「何时跳过 PR」判断） | 不能保证媒体一定报道 |
| 记者与媒体清单搭建：按报道领域（beat）找对的人 | 不提供实时记者联系方式数据库 |
| 新闻劫持（Newsjacking）：借势热点的完整工作流 | 不做付费软文投放（那是广告不是 PR） |
| HARO / Qwoted 等记者请求平台的响应策略 | 不处理公关危机的法律层面 |
| Press Page + Media Kit 媒体资料页搭建 | 目录外链提交请用 `directory-submissions` |
| Pitch 质量标准自检：发出前先过质量线 | 冷邮件销售外联请用 `cold-email` |

---

## 🧰 核心能力

| 模块 | 说明 |
|------|------|
| **PR Mix 组合** | Earned / Owned 媒体资产的组合打法，明确每一类的投入产出逻辑 |
| **记者 Pitching** | 附 journalist-pitching 参考库——怎么找人、怎么写 Pitch、怎么跟进而不招人烦 |
| **Newsjacking 工作流** | 「帮我借势这个热点」——从热点判断到角度提炼到快速触达的完整流程 |
| **媒体平台参考库** | media-outlets + press-platforms 两份 references，覆盖主流科技媒体与记者请求平台 |
| **常见工作流封装** | 「找覆盖某领域的记者」「这周有什么值得 Pitch」「回应这条 HARO」「搭建 Press Page」即问即用 |
| **衡量框架** | 用真实的引流、外链、品牌搜索衡量 PR 效果，而非剪报数量 |

---

## 👤 谁应该用

- ✅ 初创公司创始人，产品发布想获得科技媒体报道
- ✅ 快消品 / 消费品牌公关负责人，需要系统化的媒体关系流程
- ✅ 没有专职 PR 但想建立行业声量的市场负责人
- ✅ 想通过行业媒体投稿（Op-ed / 客座文章）建立思想领导力的高管
- ✅ 咨询顾问，为客户设计传播与声誉策略
