# 🔍 客户研究（Customer Research）

> **你以为你懂客户——直到你发现他们用的词跟你写的词完全不一样。**

大多数市场文案失败的原因只有一个：写的人以为客户是这样想的，但客户其实不是。你花了三周打磨的品牌信息，客户看了一眼说"不太像在跟我说话"。这个差距的根源在于——你不知道客户在真实场景下用什么样的语言描述他们的痛苦。而他们的原话，就藏在访谈录音、工单、Reddit 帖子、G2 评论里，等着被挖掘。

---

## 🚧 边界：我们能做什么，不做什么

| ✅ 能做的 | ❌ 不做的 |
|-----------|-----------|
| 分析访谈、问卷、工单、评价 | 不拿低信度数据构建人物画像 |
| 去 Reddit/G2/社区挖掘真实语言 | 不编造"客户可能这么想" |
| 每项洞察标注信度等级 | 不混合不同客群做平均化结论 |

---

## ⚡ 核心能力

1. **双模式研究** —— 模式一：分析你已有的资产（录音/问卷/工单）；模式二：去"线上水坑"帮你挖（Reddit、G2、论坛、评论区）
2. **结构化提取** —— JTBD（功能+情感+社交任务）、痛点、触发事件、期望结果、客户原话
3. **信度分级** —— 每条洞察标注高/中/低信度，附来源数量和采集时间窗
4. **样本偏差意识** —— 自动提醒：Reddit 偏向技术型用户，工单偏向问题用户，评论偏向极端用户

---

## 👤 谁在用

- **文案写手**：拿到客户原话库，直接用他们的词写标题
- **产品经理**：从工单和差评中发现产品缺口
- **增长团队**：理解"客户为何流失"和"什么让他们下单"

---

## 🔗 配合使用

研究产出直接输入 `copywriting`（用客户原话写文案）、`page-cro`（基于 VOC 洞察优化落地页）、`competitor-alternatives`（从竞品评论中找到你的攻击角度）、`churn-prevention`（从流失研究中建立挽回策略）。

**输入**：已有研究素材，或产品/行业关键字去社区挖掘
**输出**：洞察主题报告 / VOC 语录库 / 人物画像 / JTBD 地图 / 竞品情报摘要
