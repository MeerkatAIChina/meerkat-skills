# 📄 Page CRO — 任意营销页面转化率优化

**一句话说清楚**：你把任何一个营销页面的 URL 丢过来 — 首页、着陆页、定价页、功能页、博客文章 — Page CRO 都会按照一整套分析框架，告诉你这个页面在转化上到底哪里出了问题，以及怎么修。

## 不是"改个按钮颜色"那种优化

大多人聊 CRO 时想到的是：改按钮文案、换图片、调颜色。这些都是**战术层**的细枝末节。Page CRO 先带你检查**战略层**的 7 个维度：

### 分析框架（按影响力从高到低）

1. **价值主张清晰度（最高影响力）**：一个陌生访客在 5 秒内能不能说清楚"这网站是干嘛的、对我有什么用"？如果能，那价值主张过关。如果不能，后面所有优化都是白费。
2. **标题有效性**：标题是结果导向还是功能导向？有具体数字和时间框架吗？跟流量来源的信息匹配吗？
3. **CTA 位置、文案和层级**：有一个清晰的主行动吗？不滚动能不能看到？按钮文案传达的是价值还是仅仅是一个动作？
4. **视觉层级与可扫描性**：扫读用户能抓住核心信息吗？最重要的元素视觉上最突出吗？留白够吗？
5. **信任信号与社交证明**：有没有客户 Logo？有没有带真实姓名和照片的评价？有没有硬数据（"帮 5000+ 公司营收增长 34%"）？
6. **异议处理**：价格顾虑、适配焦虑、实施难度、"要是不好用怎么办" — 这些异议有没有被提前回答？
7. **摩擦点**：表单字段太多？下一步不清晰？导航让人困惑？移动端没法用？加载太慢？

## 不同类型的页面，不同的优化策略

同一个"提升转化"的目标，首页和定价页的优化思路完全不同：

- **首页 CRO**：解决冷流量定位、给"马上要买"和"还在研究"两类用户各留一条清晰路径
- **着陆页 CRO**：信息与流量来源匹配、单一 CTA（能去掉导航就去掉）、在一个页面上完成完整的说服
- **定价页 CRO**：清晰的方案对比、推荐方案标识、解决"我该选哪个方案"的焦虑
- **功能页 CRO**：把功能连接到利益、附上使用场景和案例、给一条清晰的试用/购买路径
- **博客文章 CRO**：根据文章主题匹配上下文 CTA、在自然的阅读中断点嵌入行动号召

## 输出什么？

每次分析输出四块内容：
1. **快速赢单（立即执行）**：改动小、见效快的优化
2. **高影响力改动（优先排期）**：需要更多工作量但会显著提升转化
3. **测试想法**：值得 A/B 测试验证的假设（而非直接假定有效）
4. **文案替代方案**：对标题、CTA 等关键元素提供 2-3 个备选文案及选择理由

## 适合谁用？

- 某个关键页面转化率远低于预期的增长负责人
- 刚上线新着陆页、想在上量之前做一次专业审查的广告投放团队
- 手里有页面但"总觉得哪里不对又说不上来"的创业者
- 想用结构化 CRO 方法代替直觉判断的产品经理

> ⚠️ 注意：本技能基于公开的 CRO 方法论框架，所有建议为通用优化原则，不含客户私有数据。
