# Market Research — 市场研究报告生成

> 以顶级咨询公司（麦肯锡、BCG、Gartner）风格生成综合性市场研究报告（50+页），包含专业LaTeX排版、战略分析框架集成与深度研究能力。

---

## 定位

本技能面向需要高质量市场研究报告的场景——无论是战略咨询师、企业战略部门、投资分析师，还是产品经理。它自动化了从数据收集到PDF成稿的完整流程，产出的报告可直接用于董事会汇报、投资决策或客户交付。

## 核心能力

| 分析框架 | 用途 |
|---------|------|
| **Porter's Five Forces（波特五力）** | 竞争强度分析 |
| **PESTLE 分析** | 宏观环境扫描 |
| **SWOT 分析** | 优势、劣势、机会、威胁 |
| **TAM/SAM/SOM** | 市场容量测算 |
| **BCG 矩阵** | 业务组合定位 |
| **价值链分析** | 利润与效率映射 |
| **竞争定位图** | 四象限竞争者映射 |

## 适用场景

- 新市场进入可行性评估
- 投资标的行业尽调（需注明不构成投资建议）
- 年度战略规划的市场输入
- 产品线扩展的竞争力评估
- 企业内部培训材料

## 工作流程

### 阶段一：研究
- 界定市场边界与范围
- 深度网络研究，收集市场规模、增长率、企业营收、融资数据
- 识别5-10家关键竞争者并建立详细画像
- 收集监管与宏观经济数据

### 阶段二：分析
- 对收集的数据逐一应用分析框架
- 跨框架交叉验证发现
- 识别共识主题与矛盾点
- 构建情景模型（基准、乐观、悲观）
- 按吸引力与可行性对机会评分

### 阶段三：可视化生成
- 市场增长图表与 TAM/SAM/SOM 图示
- 竞争定位图（2×2 四象限）
- 波特五力雷达图
- 风险热力图
- 行业生态图

### 阶段四：撰写
- 咨询风格结构化叙述（非要点式）
- 每个论断均附数据来源引用
- 关键洞察高亮框贯穿全文
- Executive Summary 在最后撰写（从发现中提炼）

### 阶段五：编译
- LaTeX 排版（自定义样式包）
- 目录、参考文献、附录
- 通过 LaTeX 编译器生成 PDF

## 注意事项

1. **每项论断必须有来源** — 不允许无出处数据。
2. **时效性优先** — 优先采用近2年数据。
3. **三角验证** — 跨3个以上来源交叉验证市场规模。
4. **承认不确定性** — 使用区间范围，避免虚假精确。
5. **建议可执行** — 每条建议包含：做什么、为什么、怎么做、预期影响。
6. **杜绝填充内容** — 每个段落必须提供信息或洞察。

## 中国市场适配

### 中国数据源
- **艾瑞咨询 (iResearch)** — 互联网及新经济行业研究
- **易观 (Analysys)** — 数字经济与行业数字化分析
- **QuestMobile** — 移动互联网用户行为数据
- **国家统计局** — 宏观经济与行业官方统计数据
- **中国互联网络信息中心 (CNNIC)** — 互联网发展统计报告
- **36氪研究院** — 新兴行业与创业生态研究

### 监管框架
- **网络安全法** — 对在线数据收集与跨境传输的要求
- **数据安全法** — 数据分类分级保护制度
- **个人信息保护法 (PIPL)** — 对市场调研中消费者数据收集的严格限制，需确保合规获取用户数据

### 中国特有分析维度
- **政策环境分析 (Policy)** — 替代 PESTLE 中的 Political，重点关注五年规划、产业政策、双循环战略、反垄断与平台经济监管动态

### 本地化报告格式
- 中国市场研究报告偏好图表密集型呈现
- Executive Summary 需包含政策风险提示
- 市场预测建议提供基准、乐观、悲观三情景分析

### 合规注意事项
- 涉及上市公司的市场分析需注明"不构成投资建议"
- 引用中国数据源必须标注来源机构和发布日期
- 涉及外资准入限制行业需标注相关政策依据
- 地图类可视化需使用审图号合规的中国标准地图
