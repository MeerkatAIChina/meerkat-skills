# AI Discoverability Audit — 在 AI 眼里，你的品牌是什么？

> **你以为 ChatGPT 知道你是谁，结果它把你的创始人安到了竞品头上。你以为 Perplexity 会推荐你，结果它压根不知道你的存在。AI 搜索引擎不了解你——不是你的错，但让它了解你是。**

---

## 一、品牌的可发现性，已经从搜索结果页迁移到了 AI 的训练数据里

传统 SEO 盯着排名。AI 可发现性盯着的是：当用户用自然语言问"谁是最好的 XX"、"XX 值不值得买"、"XX 和 YY 哪个好"——AI 会怎么描述你？会不会描述你？会不会把你说成别人？

`ai-discoverability-audit` 不是另一个 SEO 工具。它是**品牌在 AI 时代的第一方认知档案**：诊断 AI 系统对你的认知状况，定位错误信息和认知盲区，然后制定修复计划。

---

## 二、先搞清楚：这个 Skill 不是什么

| ❌ 不是 | ✅ 正确选择 |
|---------|------------|
| 内容优化工具 | 它是品牌级的 AI 认知审计，内容优化是后续动作 |
| 只管一个 AI 平台 | 要求至少在 2 个平台上跑查询，交叉验证 |
| SEO 排名检查 | 它检查的是 AI 描述、引用的准确性，不是排名位置 |
| 一次性检测 | 自带 30/60/90 天复审计时间表 |
| AI 自动完成全部 | 需要用户配合运行查询并粘贴结果（或 Agent 有 Web 权限） |

## 三、真实场景演示

**场景**：一家名为"Signal"的营销数据分析公司，想知道 AI 对他们的认知。

**`ai-discoverability-audit` 会怎么做？**

```
Phase 1: 预审计分析
→ 实体清晰度检查：「Signal」是常见词，可能与加密通信 App 混淆
→ 基准假设：中小规模公司，大概率 AI 认知模糊
→ 竞争背景：主要竞品有知名媒体曝光，可能占优

Phase 2: 结构化查询（ChatGPT + Perplexity + Claude）
直接品牌查询：
  "What is Signal?" → AI 描述的是加密 App，不是营销公司 ❌ 严重！
  "What does Signal do?" → 同上
  "Is Signal any good?" → AI 讨论加密安全，品牌完全不在对话中

分类查询：
  "Best marketing analytics platforms" → 主竞品 A、B 出现，Signal 未出现

Phase 3: 结构化评分
  识别度 1/5（AI 误认为另一个实体）
  准确性 1/5（完全错误）
  类别存在 0/5
  权威度 0/5
  总分 7/30 → INVISIBLE

Phase 4: 差距分析
  🔴 紧急：品牌名与其他实体混淆 → 修正命名歧义
  🟠 高优：创建可被 AI 解析的"关于我们"页 + 声称 Google Knowledge Panel
  🟡 机会：在 G2/Capterra 积累评论 → 创建分类对比内容

Phase 5: 复审计划
  30天：确认品牌名歧义是否缓解
  60天：分类查询是否出现品牌
  90天：完整对比复审计
```

## 四、核心能力矩阵

| 审计阶段 | 内容 | 产出 |
|---------|------|------|
| **预审计分析** | 实体清晰度 / 基准假设 / 竞争背景 | 预审计假设 |
| **直接品牌查询** | ChatGPT + Perplexity + Claude 上测试 4 组品牌查询 | 认知/准确性/情感/来源记录 |
| **分类查询** | 测试品牌所在品类的推荐查询 | 品牌出现率 / 位置 / 竞品对比 |
| **权威查询** | 测试行业专家/创始人/最佳实践查询 | 内容引用情况 |
| **结构化评分** | 识别度/准确性/情感/类别/权威/竞争 六维度 1-5 评分 | 30 分制总评 |
| **差距分析** | 分类为紧急/高优/机会三级 | 逐项修复建议 |
| **复审计时间表** | 30/60/90 天复审计 + 对比表格 | 趋势追踪框架 |

## 五、谁应该用

- ✅ **品牌负责人**：想知道品牌在 AI 时代的"数字身份"是否准确
- ✅ **CEO/创始人**：个人和公司品牌在 AI 中被如何描述
- ✅ **市场 VP**：竞品在 AI 里被推荐，我们为什么没有
- ✅ **SEO 负责人**：在传统 SEO 之外补上 AI 可发现性盲区

## 六、简单上手步骤

```bash
cp -r skills/ai-discoverability-audit ~/.claude/skills/
```

触发方式：
> "帮我做一次 AI 可发现性审计，了解我的品牌在 ChatGPT/Perplexity 里怎么被描述的"
> "检查 [竞品 A] 和 [竞品 B] 在 AI 搜索中的表现，和我们对比"

三档模式可选：
- **快速扫描**（10-15 分钟）— 只测直接品牌查询
- **标准审计**（30-45 分钟）— 全四阶段 + 评分 + 路线图
- **深度分析**（60-90 分钟）— 加竞品对标 + 90 天计划
