# competitor-ads-analyst — 竞品广告分析师

## 定位

从公开广告库中提取和分析竞争对手的广告投放数据，识别信息传递模式、创意格式趋势、痛点和市场定位空白。为竞争情报收集、营销活动策划和创意灵感提供数据支撑。

## 核心能力

- **多平台覆盖**：Meta Ad Library、Google Ads Transparency Center、TikTok、LinkedIn + 中国市场平台（巨量创意、腾讯广告、小红书等）
- **广告素材分类**：按信息类型（痛点/解决方案/社交证明/促销/教育/品牌）、漏斗阶段（上/中/下部）和创意格式分类
- **痛点频率分析**：统计竞品高频强调的痛点
- **定位地图**：竞品定位维度的对比分析
- **市场空白识别**：发现竞品未覆盖的信息角度
- **文案公式提取**：归纳竞品的标题和文案模式
- **KOL/KOC 投放分析**：中国市场特有的达人投放策略分析

## 适用场景

- 新产品或新活动需要了解竞品广告策略
- 发现自有品牌广告的差异化机会
- 定期竞品情报监控（月度/季度）
- 营销活动前的创意灵感和参考
- 中国市场竞品广告生态调研

## 工作流程

```
确定分析范围 → 采集竞品广告 → 分类标注 → 模式分析 → 输出报告
```

| 步骤 | 说明 |
|------|------|
| 1. 确定范围 | 选择3-5个竞品，确定时间范围和平台 |
| 2. 采集广告 | 从公开广告库提取文案、创意格式、落地页 |
| 3. 分类标注 | 按信息类型、漏斗阶段、创意格式分类 |
| 4. 模式分析 | 痛点频率、信息聚类、格式偏好、定位空白 |
| 5. 输出报告 | 竞品报告 / Swipe File / 信息矩阵 / 创意简报 |

## 使用方法

在对话中提及竞品广告分析需求即可激活：

> "分析我们 Top 3 竞品在 Meta 上的广告策略"
> "查看我司竞品最近30天的抖音广告，找差异化机会"
> "生成一份竞品广告 Swipe File"

## 示例输出

```
## 竞品广告分析摘要
- 分析对象: 竞品A、竞品B、竞品C
- 时间范围: 最近60天
- 分析平台: Meta + Google Ads
- 采集广告数: 47条

### 高频痛点 (Top 3)
1. 数据孤岛/工具分散 (出现在68%的广告中)
2. 手动重复工作耗时 (出现在55%的广告中)
3. 团队协作效率低 (出现在38%的广告中)

### 市场空白
- 无一竞品强调"数据安全合规"角度
- 无人使用"行业定制方案"作为核心信息
```

## Skill 配合

- **ad-creative**：基于竞品分析结果生成广告创意
- **paid-ads**：广告策略和投放规划
- **competitor-profiling**：更广泛的竞品公司分析
- **content-creator**：内容创意灵感

## 局限性

- 依赖公开广告库的覆盖范围和更新时效
- 中国市场缺乏统一公开广告库，需多源人工采集
- 竞品广告投放量≠投放效果
- 仅分析不构成行动建议，需结合自有数据判断
