# 🎬 Remotion Video：用代码批量生产营销视频，告别逐帧手剪

> **一句话定位**：把视频生产从「一帧一帧剪辑」变成「一套代码、批量渲染」——用 Remotion 的程序化视频引擎，让你的 AI Agent 直接出片。

---

## 你的痛点

你做营销视频时是不是这样的：同一个产品，要出 16:9 YouTube 版、9:16 TikTok 版、1:1 Instagram 版；要改个文案，得从 Premiere/剪映里重新调时间轴。每个版本都要手动对齐动画、调整转场、重新渲染——3 分钟的视频折腾 3 小时。

这个 Skill 解决的就是这件事：**把视频当成代码来管理**。一次写好动画逻辑，改文案、换尺寸、调品牌色全自动生效。批量出片，一致性零失控。

---

## ✅ 能做什么 | ❌ 不做什么

| ✅ 能做什么 | ❌ 不做什么 |
|-----------|-----------|
| 弹簧动画（弹性/平滑/干脆/交错）——不依赖 CSS transition | 不替代 Premiere/剪映做手工剪辑 |
| 插值动画（缩放/视差/滚动模拟）——基于帧计算 | 不做 3D 建模或 After Effects 特效 |
| SVG 描边/路径动画——品牌 Logo 出场特效 | 不处理实拍视频素材的调色/修剪 |
| 图表动画（柱状增长/折线绘制/饼图揭示/数字递增） | 不做用户交互式视频或播放器集成 |
| 场景转场（淡入淡出/滑动/自定义过渡） | 不做直播流或实时视频合成 |
| 音频同步集成 + 渲染配置 | 不提供视频托管或 CDN 分发 |

## 核心能力

| 能力模块 | 技术实现 | 营销场景 |
|---------|---------|---------|
| **弹性动画预设** | `spring()` 4 套物理参数 | Logo 弹跳出场、产品卡片依次展示 |
| **插值模式** | `interpolate()` 帧映射 | 产品页面滚动演示、数据看板推拉 |
| **SVG 描边动画** | `strokeDashoffset` 逐帧控制 | 品牌 Logo 描边、流程路径动态绘制 |
| **图表动画** | 柱状/折线/饼图/数字递增 | 数据报告视频、投资人演示、案例成果展示 |
| **场景转场** | `TransitionSeries` + `linearTiming` | 产品介绍 → 功能介绍 → 定价引导的分幕视频 |
| **性能规则** | `React.memo` + `staticFile()` + 帧级控制 | 快速迭代开发，30 秒以内组合件实时预览 |
