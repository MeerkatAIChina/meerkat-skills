# 🤝 Influencer Marketing — 网红与创作者营销全流程操盘手

> **从「找谁投」到「投得值」：选人、谈判、Brief、合规、ROI 衡量，一个 SKILL 管完创作者合作的全生命周期。**

---

## 😫 你是否也遇到过这些问题？

- 想做达人投放，但不知道该找头部、腰部还是素人，报价单看得一头雾水
- 给创作者的 Brief 写得像广告脚本，产出的内容全是「硬广味」，粉丝根本不买账
- 合作发出去了，才发现没约定使用权、没做广告披露，留下合规隐患
- 投了一圈 Instagram / TikTok / YouTube / 播客，最后说不清哪个渠道带来了真实转化

如果这说的就是你——这个 SKILL 就是为你准备的。

---

## ✅ 能做什么 | ❌ 不做什么

| ✅ 能做 | ❌ 不做 |
|---------|---------|
| 合作伙伴的寻找、审核与假粉识别 | 不能替你直接联系或私信达人 |
| 合作报价结构与谈判要点（固定费用/佣金/混合） | 不提供实时的达人报价数据库 |
| 创作者 Brief 撰写（给创作空间但守住品牌底线） | 不生成成片视频内容 |
| FTC 等广告披露合规检查清单 | 不构成法律意见，重大合规问题仍需法务确认 |
| 大使计划（Ambassador Program）设计 | 联盟分佣机制请配合 `referral-program` |
| ROI 衡量框架：追踪链接、专属折扣码、增量衡量 | 不能直接读取各平台后台数据 |

---

## 🧰 核心能力

| 模块 | 说明 |
|------|------|
| **Influencer ↔ Ambassador 光谱** | 帮你厘清一次性投放、长期合作、大使计划的边界与适用场景 |
| **选人与审核** | 受众匹配度、互动质量、假粉信号识别，B2C 与 B2B（LinkedIn/X/Newsletter/播客）双线覆盖 |
| **外联与谈判** | 首次触达话术结构、报价谈判要点、产品置换（Gifting/Seeding）策略 |
| **合规红线** | 广告披露（FTC Disclosure）要求逐条核对——这一节被标为 non-negotiable |
| **创作者 Brief** | 既给创作自由又守住品牌信息的 Brief 模板结构 |
| **衡量与 ROI** | 从虚荣曝光转向真实转化：追踪码、专属落地页、内容二次授权（Whitelisting）投放 |
| **Run-of-Show 清单** | 从选人→谈判→执行→复盘的四阶段执行清单，照着走不漏项 |

- ✅ 需要向老板证明达人投放 ROI 的增长负责人
