# 📮 Cold Email Outreach — 冷邮件外联工程：从送达率到合规的全链路设计

> 你的冷邮件进入了对方的收件箱，然后？然后就没有然后了。不是文案的问题——是你的域名没做SPF、你的邮件触发了垃圾过滤器、你的发送节奏让对方直接点了举报。

---

## 好文案 × 烂基础设施 = 零回复

**Cold Email Outreach** 是冷邮件外联的工程技术面：送达率优化、发送域预热、认证配置（SPF/DKIM/DMARC）、合规（CAN-SPAM/GDPR）、序列时序设计。它解决的是「邮件写好了，但到底能不能被看见」的问题。

---

## 明确的边界

| ✅ 覆盖范围 | ❌ 不覆盖 |
|---|---|
| 送达率诊断与优化 | 邮件文案撰写（见 `cold-email` 或 `email-composer`） |
| 域名预热、认证配置、健康指标 | 着陆页、产品定位 |
| 冷邮件时序设计与合规检查 | Klaviyo等营销自动化平台（见 `klaviyo-analyst`） |
| CAN-SPAM / GDPR 合规清单 | 社会媒体推广 |

---

## 核心能力

- **送达率三件套**：SPF、DKIM、DMARC 认证的检查与配置指引
- **域名预热路线图**：第1周5-10封→第5周+100-200封/天，阶梯式放量
- **健康基准仪表盘**：退订率 <2%、垃圾邮件投诉 <0.1%、打开率 >40%、回复率 >5%
- **最优序列结构**：Day 0 价值引入 → Day 3 新角度 → Day 7 社会证明 → Day 14 告别邮件
- **最佳发送窗口**：周二-周四 8-10am（收件人时区），绝不周一早上和周五下午
- **三级个性化**：调研级(每人5+分钟) → 模板级(1分钟) → 动态级(自动化合并字段)
- **CAN-SPAM & GDPR 合规**：真实发件人身份、物理地址、退订机制、合法利益基础

## 目标用户

- **RevOps / 营销运营**：负责邮件基础设施和送达率
- **SDR团队负责人**：管理批量外发，需要保证团队邮件能进收件箱
- **合规/法务**：关心冷邮件的法律边界
- **技术营销人**：既写文案也管域名的新一代营销从业者
