# 🎬 Video — 无需拍摄团队，用 AI 生产专业级营销视频

> **你的产品需要一个视频，但你不需要一个制片团队。**

三年前，一个 60 秒的产品 Demo 视频意味着：写脚本 → 找摄影师 → 布景拍摄 → 后期剪辑 → 配音。周期 2-4 周，预算 5000-50000 元。现在，AI 视频生成 + 程序化视频框架 + AI 虚拟主播把这条路压缩到小时级。这个技能是你的**AI 视频生产指挥中心**——从选型决策到最终输出，覆盖四种制作范式的完整流水线。

## ⚡ 四象限能力矩阵

| 范式 | 代表工具 | 最适合场景 |
|------|----------|-----------|
| **程序化视频** | Hyperframes (HTML/CSS), Remotion (React) | 数据驱动视频、产品更新、个性化批量产出 |
| **AI 视频生成** | Veo 3, Runway Gen-4, Kling 3.0, Pika | 产品 B-roll、概念场景、无法实拍的创意画面 |
| **AI 虚拟主播** | HeyGen（有 MCP 服务端）, Synthesia | 产品解说、功能公告、多语言内容 |
| **剪辑复用** | Descript, Opus Clip, CapCut | 将长视频（播客/Webinar）拆成社交短视频 |

### 🎯 四步决策树
1. 需要真人出镜？→ AI 主播（HeyGen）或自己录制
2. 画面可以纯代码生成？→ 程序化视频（Hyperframes，Agent 原生友好）
3. 需要无法实拍的画面？→ AI 视频生成（Veo/Runway）
4. 已有长内容想复用？→ Descript + Opus Clip 拆剪

---

## ⚠️ 常见踩坑

1. **让 AI 生成带文字的视频**——AI 模型无法可靠渲染可读文字，文字请用程序化叠加
2. **忽视字幕**——85% 的社交视频是无声播放的
3. **用错画幅**——社交 9:16、YouTube 16:9、Feed 1:1，错了等于白做
4. **过度制作**——TikTok 上\"粗糙但真实\"往往比\"精美但塑料\"表现更好
