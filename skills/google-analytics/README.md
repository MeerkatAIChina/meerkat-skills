# Google Analytics — 让 GA4 数据开口说话

> **打开 GA4 看数据不难，难的是看着数据知道下一步该做什么。**

---

## GA4 给了你数据，但给了答案吗？

Google Analytics 4 是每个营销人的标配——但 80% 的用户只停留在"看看流量涨没涨、跳出率降没降"的表层。GA4 的真正威力在于**交叉分析**：当你把流量来源 × 着陆页 × 转化事件放在一起看，才能发现"从 LinkedIn 广告进来的用户，在定价页停留时间比搜索流量短 40%，但注册转化率反而更高"这种级别的洞察。

这个技能不是为了帮你打开 GA4 后台——而是帮你**从 GA4 数据中提取可落地的增长决策**。

---

## 它能帮你做什么？

### 📊 流量诊断

- 识别哪些渠道在"刷量"（高流量低转化），哪些在"精准收割"
- 对比自然搜索 vs 付费搜索的用户质量，指导预算分配
- 发现突然的流量异常并追溯到具体来源/页面

### 🧠 用户行为洞察

- 跳出率高的页面，到底是内容问题还是匹配问题？
- 用户从哪个路径到达关键转化页？中间卡在哪里？
- 事件流分析：用户在注册流程的哪一步大量流失？

### 💰 转化与营收归因

- 不同渠道的 CPA（每获客成本）对比，而非只看 CPC
- 辅助转化 vs 最终转化：哪个渠道在"助攻"，哪个在"收割"
- 电商漏斗：从产品浏览到下单完成，各环节转化率

### 📈 周期对比

- 本期 vs 上期 vs 去年同期，排除季节性噪音
- 活动前后的关键指标变化：活动到底是"刺激增长"还是"提前消耗需求"？

## 工作流程：从提问到可执行建议

这个技能遵循一个清晰的分析节奏：

1. **连接 GA4 Data API**（通过服务账号认证，本地处理数据，不上传任何信息）
2. **按问题定向取数**——你不会被 200 行报表淹没，只拿回答你问题所需的数据
3. **上下文交叉分析**——流量 × 行为 × 转化，三角验证
4. **输出优先级建议**——每条洞察带优先级标记（🔴高/🟡中/🟢低）、预期影响和落地路径

> 不生产"参考参考"的信息，只交付"下周就值得做"的行动项。

## 常问的问题类型

- *"过去 30 天哪些渠道贡献了最多的转化？和上个月比有变化吗？"*
- *"新上线的落地页表现怎么样？跳出率和转化率是行业平均水平的多少？"*
- *"付费搜索的 CPC 在涨，但 CPA 在降——这是好事还是坏事？"*
- *"用户注册后平均几天会完成第一次关键行为？哪个步骤流失最多？"*

---

## 前置配置要求

这个技能需要 Google Analytics Data API 凭证：

- **GA4 媒体资源 ID**（在 GA4 后台 > 管理 > 媒体资源设置中获取，不是测量 ID）
- **Google Cloud 服务账号 JSON 密钥文件**（需在 GA4 媒体资源中授予"查看者"角色）
- 支持环境变量或 `.env` 文件配置，本地安全存储
