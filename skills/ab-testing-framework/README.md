# 📊 A/B Testing Framework — 统计严谨的转化实验方法论

**一句话说清楚**：这不是"AB Test Setup"的重复 — 这是一套平台无关的统计方法论框架，聚焦于如何计算样本量、判定统计显著性、选择频率派还是贝叶斯方法、避开 10 大常见实验陷阱。

## 什么时候用 A/B Testing Framework？

当你的问题更"数学"而非"运营"时：
- "我的实验需要多少样本才够？公式怎么算？"
- "p=0.06，该宣布赢家吗？还是再等等？"
- "流量小用频率派还是贝叶斯？有什么区别？"
- "我测了三个变体，为什么全都不显著？是不是方法错了？"
- "什么叫辛普森悖论？什么叫新奇效应？"

而 AB Test Setup 回答的是："我的定价页转化差，该测什么？怎么排优先级？实验体系怎么搭？"

两者互补：**AB Test Setup 管"测什么、怎么管"，AB Testing Framework 管"怎么算、怎么判"。**

## 核心方法论

### 五步实验流程

**Step 1：假设 → Step 2：样本量计算 → Step 3：执行铁律 → Step 4：统计分析 → Step 5：决策**

### 样本量公式（简化版）

```
每个变体所需样本 ≈ 16 × p(1-p) / MDE²

p  = 基准转化率（小数）
MDE = 最小可检测效应（小数）
```

**最短测试周期**：至少 2 个完整商业周，即使样本量提前达标。这是为了覆盖一周内不同天的行为差异——周三的用户和周六的用户不是同一群人。

### 频率派 vs 贝叶斯方法

| 维度 | 频率派（Z 检验） | 贝叶斯方法 |
|------|----------------|-----------|
| **输出** | "拒绝零假设的概率是 95%" | "B 变体优于 A 的概率是 94%" |
| **适用** | 大样本、标准实验 | 低流量、需要更快决策 |
| **要求** | 必须预设样本量 | 可以随时查看 |
| **解释难度** | 难（p 值常被误解） | 相对直观 |

### 决策框架

| 结果 | 统计显著性 | 行动 |
|------|-----------|------|
| 变体胜出 | p < 0.05 | 实施变体 |
| 对照组胜出 | p < 0.05 | 保留对照，从失败中学习原因 |
| 无差异 | p ≥ 0.05 | 保留对照，下次测更大胆的改变 |
| 变体边缘胜出 | p = 0.05-0.10 | 考虑流量是否足够，可能需要更多时间 |

## 10 大常见实验陷阱

1. **偷看（Peeking）**：反复看结果然后提前停止 → 假阳性率从 5% 飙升到 26%+
2. **早停（Early Stopping）**：达到显著性 ≠ 达到所需样本量
3. **变体太多**：每个变体都需要完整样本量，测试 5 个变体 = 5 倍的流量需求
4. **忽略分群差异**：整体胜出可能在某些关键分群上其实更差
5. **期望效应太小**：想测 2% 的提升需要海量样本，测 15-20% 的提升才现实
6. **不覆盖完整周期**：节假日、周末效应没被纳入
7. **多指标混淆**：主指标必须预先声明，辅助指标仅做方向性参考
8. **幸存者偏差**：只衡量完成转化的用户，忽略放弃的
9. **辛普森悖论**：分群层面的赢家在聚合层面反转为输家
10. **新奇效应**：新设计获得的是"新东西真好玩"的临时提升，2-4 周后重测可能消失

## 测什么（按影响力排序）

### 🔴 高影响力（优先测）
- 价值主张 / 标题
- CTA 文案和位置
- 定价和优惠结构
- 表单长度（减少字段）
- 页面布局（单列 vs 多列）
- 社交证明的存在和位置

### 🟡 中等影响力
- 图片/视频 vs 静态
- 评价形式（文字 vs 视频）
- 着陆页导航的有无
- 信任徽章和安全信号
- 紧迫感元素（倒计时、库存）

### 🟢 低影响力（通常不值得测）
- 按钮颜色（除非对比度严重不足）
- 字体变更
- 微小文案微调
- 图标风格
- 页脚内容

## 适合谁用？

- 需要精确计算实验参数的数据分析师/增长工程师
- 流量有限但想科学实验的早期创业团队
- 想深入理解统计推断而非只是"跑个测试"的产品经理
- 在做实验平台选型（频率派 vs 贝叶斯）的技术团队
