# 🕵️ 竞品画像分析（Competitor Profiling）

> **你只知道竞品比你便宜（或比你贵），但不知道他们每周发了多少内容、靠什么关键词拿流量、用户在 G2 上最抱怨什么。**

大多数团队做竞品分析的方式：打开竞品官网，看看定价页，截几张图，然后说"我们的功能更多"。但真正的竞争情报不在首页上——它在他们的 SEO 流量结构里、在他们的用户评论里、在他们的内容策略和产品迭代节奏里。你在看冰山，而冰山下面才是战场。

---

## 🚧 边界：我们能做什么，不做什么

| ✅ 能做的 | ❌ 不做的 |
|-----------|-----------|
| 抓取网站 + SEO 数据 + 用户评论 | 不夸大竞品劣势或隐藏其优势 |
| 所有结论可追溯到原始来源 | 不凭感觉做判断——每个发现标注来源 |
| 按统一模板产出可比画像 | 不混用不同指标的竞品比较 |

---

## ⚡ 核心能力

1. **三阶段研究** —— 网站抓取（Homepage / 定价 / 功能 / 关于 / 客户案例 / 集成 / Changelog）→ SEO 情报（域名权重 / 外链 / 关键词 / 流量估值）→ 评论挖掘（G2 / Capterra / Product Hunt 好评+差评）
2. **原始数据持久化** —— 所有抓取结果按日期保存，支持历史对比和审计回溯
3. **诚实评估** —— 强制标注"他们在哪里赢我们"和"我们在哪里赢他们"
4. **快扫 vs 深度** —— Quick Scan 只看首页+定价+SEO 概览；Deep Profile 覆盖全站+评论+技术栈+内容策略
5. **汇总对比** —— 多竞品分析完成后自动生成横向对比表和定位地图

---

## 👤 谁在用

- **产品营销经理**：理解竞品定位、定价、产品演进方向
- **SEO/内容团队**：找到竞品的关键词缺口和内容策略
- **销售团队**：拿到竞品档案后，调用 `sales-enablement` 制作战斗卡

---

## 🔗 配合使用

- 档案产出后 → `competitor-alternatives` 生成对比页和替代页
- 发现内容缺口 → `content-strategy` 制定差异化内容计划
- 分析竞品广告 → `competitor-ads-analyst` 进一步研究投放策略
- 定价分析 → `pricing-strategy` 基于竞品定价做深度建模

**输入**：竞品 URL 列表
**输出**：标准化竞品档案 + 横向汇总对比 + 定位地图 + 战略建议
