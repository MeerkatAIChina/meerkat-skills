# 📝 Form CRO — 表单转化率优化专家

**一句话说清楚**：每个表单字段都是有成本的。Form CRO 帮你逐字段审视你的表单 — 不管是线索捕获、Demo 请求、联系表单还是结账页面 — 找到那些在悄悄吃掉你转化率的元凶，然后给出可直接落地的优化方案。

## 表单优化的核心洞察：每个字段都在"收税"

这不是夸张。业界反复验证的经验法则是：

| 字段数量 | 完成率损失 |
|---------|-----------|
| 3 个字段 | 基线 |
| 4-6 个字段 | 减少 10-25% |
| 7 个以上字段 | 减少 25-50%+ |

所以 Form CRO 的第一个原则就是：**对每一个字段问三个灵魂问题** — 没有这个信息我们能不能帮到用户？能不能换个方式获取？能不能晚点再问？

## 全面覆盖的表单优化体系

### 逐字段优化指南

每个常见表单字段都有专项优化建议：
- **邮箱字段**：单项输入（不需要确认框）、内联验证、拼写纠错（gmial.com → gmail.com）、移动端正确键盘
- **姓名字段**：单一"姓名" vs 分拆"姓/名"（需要测试）、单一字段减少摩擦
- **手机号**：能选填就别设必填、如果必填说明原因、输入时自动格式化
- **公司/组织**：自动补全、提交后通过电子邮箱域名推断
- **消息/备注（自由文本）**：设选填、给合理的字数提示

### 表单布局黄金法则

- **单列 > 多列**：单列表单完成率更高，移动端天然适配。多列只用于极短的相关字段（如姓/名并列）。
- **标签 > 占位符**：占位符一打字就消失，用户瞬间忘记在填什么。标签始终可见，占位符仅用于示例。
- **字段排序**：先简单后敏感（姓名 → 邮箱 → 电话 → 公司规模），利用心理承诺效应逐步深入。

### 多步骤表单

超过 5-6 个字段就该考虑分步了。关键规则：
- 进度条必须清晰（第 X 步，共 Y 步）
- 每步一个主题
- 允许返回修改
- 保存进度（刷新不丢数据）
- 渐进承诺模式：第 1 步只要邮箱 → 第 2 步姓名+公司 → 第 3 步资格问题

### 提交按钮文案

这是被低估的转化杠杆。对比感受一下：
- ❌ "提交" / "发送"
- ✅ "获取我的免费报价" / "下载指南" / "预约演示" / "开始免费试用"

按钮文案应该 = **动作 + 用户将获得什么**。

## 移动端表单专项优化

移动端表单有自己的一套规则：
- 触控目标高度 ≥44px
- 调用正确的键盘类型（邮箱键盘、电话键盘、数字键盘）
- 开启自动填充
- 单列布局（没有例外）
- 提交按钮固定在底部
- 最大化减少打字（多用下拉、按钮、自动补全）

## 你能从输出里得到什么？

1. **表单审计**：逐问题列出 → 预估影响 → 具体修复 → 优先级（高/中/低）
2. **推荐表单设计**：必填字段列表及理由 → 字段排序 → 完整文案（标签、占位符、按钮、错误提示）→ 布局指导
3. **测试假设**：可以立即拿去 A/B 测试的具体想法

## 适合谁用？

- 线索表单完成率低于预期的 B2B 市场团队
- Demo 请求表单转化差的 SaaS 公司
- 结账表单弃单率高的电商运营
- 任何"表单有人开始填但没人提交"的场景
