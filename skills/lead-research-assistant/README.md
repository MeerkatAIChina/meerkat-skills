# 🎯 销售线索研究助手 — 让 AI 替你找到「最可能成交」的客户，并告诉你怎么接触他们

> 不是给你一堆公司名字——而是给你每个线索的匹配理由、联系策略、决策人定位和开场白建议。从「我不知道找谁」到「我知道怎么开口」，一步到位。

---

## 痛点开篇

销售最怕的不是被拒绝——是根本不知道找谁。

你的产品很好，你的价值主张很清晰，但当你打开 LinkedIn 或者 CRM 系统，面对茫茫多的公司，你脑子里只有一个问题：「哪些公司真正需要我的产品？我该联系谁？第一句话说什么？」

翻 LinkedIn 翻到手腕酸，搜 Crunchbase 搜到眼睛花，最后还是靠「感觉」选了几家公司发了一堆模板消息——然后石沉大海。

这个 SKILL 就是你的 AI 销售 SDR。它会理解你的产品和 ICP、搜索匹配的公司、打分排序、找到决策人、给每一家写个性化的接触策略。

---

## 边界说明

| ✅ 能做什么 | ❌ 不做什么 |
|-----------|-----------|
| 基于产品描述和 ICP 搜索匹配的潜在客户公司 | 不实际发送邮件或自动外联 |
| 对每条线索打分和排序（1-10 匹配度） | 不替代 CRM 系统 |
| 提供决策人角色定位和 LinkedIn 链接 | 不获取个人联系方式（需用户自行查找） |
| 为每条线索输出个性化接触策略和开场白 | 不做信用评估或财务尽调 |
| 基于公开信息（新闻、招聘、技术栈）判断需求信号 | 不保证数据的实时准确性（取决于搜索时点） |

---

## 核心能力

| 能力模块 | 说明 |
|---------|------|
| **产品理解** | 分析你的代码库或产品描述，提取价值主张和核心功能 |
| **ICP 画像** | 确定目标行业、公司规模、地域、技术栈、痛点匹配 |
| **线索搜索** | 基于 ICP 搜索匹配公司，识别需求信号（招聘、融资、技术栈变化） |
| **打分排序** | 1-10 匹配度评分，综合 ICP 匹配度、需求紧迫性、预算可能性 |
| **决策人定位** | 给出目标联系人的角色/Title（如「VP of Engineering」） |
| **接触策略** | 每条线索提供个性化价值主张、开场话题和推荐接触方式 |

---

## 谁应该用

- ✅ B2B 销售代表和 SDR，需要快速建立高质量潜在客户清单
- ✅ 创业公司创始人自己做早期客户拓展
- ✅ 市场人员需要了解目标客户画像和需求信号
- ✅ 商务拓展 (BD) 人员寻找合作伙伴
- ✅ 从零搭建销售管道的新产品团队

## 配合其他 SKILL

- 💰 结合 `cold-email` / `cold-email-outreach` — 把线索研究成果直接转化为个性化冷邮件
- 🎯 结合 `icp-research` — 先用 ICP 研究提炼画像，再用本 SKILL 匹配具体公司
- 📊 结合 `competitor-profiling` — 了解竞品客户群，找到差异化切入角度
- 🏢 结合 `sales-enablement` — 把线索列表输出为销售团队的作战地图
- 📧 结合 `email-composer` — 为每条线索生成定制化的商务邮件
