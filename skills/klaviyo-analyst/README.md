## Klaviyo不是「搭好就行」的工具，是「持续审计和优化」的营收引擎

**Klaviyo Analyst** 从营销运营和分析视角，提供Klaviyo的深度审计、Flow优化、分层策略、送达率管理和收入归因。它不是教你「怎么在Klaviyo里发一封邮件」，而是帮你回答「你的Klaviyo正在漏掉多少钱」。

---

## 核心能力

- **4阶段深度审计框架**：状态盘点→配置审计→数据结构审计→策略建议（含预期ROI和实施路线图）
- **10项必要Flow检查清单**：欢迎系列、弃购挽回、浏览放弃、购买后、赢回、日落/再激活、评价请求、补货、生日/周年、VIP
- **RFM分层策略**：按活跃度划分四层——活跃(0-30天)、温暖(31-90天)、风险(91-180天)、流失(180天+)
- **送达率三件套**：SPF/DKIM/DMARC认证 + 发信域预热 + 列表清洗
- **行业分层基准**：B2B批发、DTC直客、订阅制——各有独立指标标准
- **SMS平台对比框架**：Klaviyo SMS vs Attentive，含决策推荐
- **事件Schema诊断**：发现重复/无用/缺失的标准事件，识别嵌套对象阻断Flow分流和Segment筛选的问题
- **画像数据利用分析**：什么数据被采集了 vs 什么数据真正被用于分层和个性化
