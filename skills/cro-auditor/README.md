# cro-auditor — 转化率优化审计师

## 定位

对落地页、注册流程、结账漏斗、表单和 CTA 进行系统性转化率优化（CRO）审计。基于启发式评估框架（LIFT模型），识别摩擦点，按 ICE/PIE 优先级框架输出可执行的优化建议。

## 核心能力

- **LIFT 启发式评估**：价值主张、相关性、清晰度、紧迫感、焦虑感、干扰度六维度评分
- **页面级审计清单**：首屏、价值主张、CTA、社交证明、表单、信任要素逐项检查
- **漏斗分析**：从认知到留存的各阶段流量、流失率、退出点分析
- **优先级框架**：ICE（影响力/信心/易实施性）和 PIE（潜力/重要性/易测试性）评分
- **A/B 测试建议**：包含假设、主要指标、最小样本量和测试周期
- **中国市场适配**：天猫/京东/拼多多等电商平台专属优化 + 微信生态转化路径

## 适用场景

- 落地页转化率低于行业基准
- 注册/购买流程有显著流失
- 需要系统性 CRO 审计报告
- 表单完成率低，需要优化
- 中国市场电商/小程序/SaaS 转化优化

## 工作流程

```
确定审计范围 → 启发式评估 → 漏斗数据分析 → 问题优先级排序 → 输出审计报告
```

| 步骤 | 说明 |
|------|------|
| 1. 确定范围 | 选择页面/流程/漏斗阶段 |
| 2. 启发式评估 | LIFT 模型六维度逐项打分 |
| 3. 漏斗分析 | 流量→流失率→退出点→摩擦指标 |
| 4. 优先级排序 | ICE/PIE 评分，识别 Quick Wins |
| 5. 输出报告 | 执行摘要 + 问题清单 + A/B 测试建议 |

## 使用方法

在对话中提及 CRO 相关需求即可激活：

> "审计我们的注册落地页，看看哪里可以提升转化率"
> "分析我们的购买流程流失情况"
> "对我们的天猫详情页做一次 CRO 审计"

## 示例输出

```
**问题:** CTA 按钮颜色与背景对比度不足，在移动端难以识别
**位置:** 首屏 CTA 区域
**影响:** HIGH — 预估影响转化率 15-25%
**依据:** 与白色背景对比度仅 2.1:1（WCAG 最低要求 4.5:1）
**修复:** 将 CTA 按钮颜色由 #E8F0FE 改为 #2563EB
**测试假设:** "将 CTA 按钮颜色从浅蓝改为深蓝，预计按钮点击率提高 20%"
**ICE 评分:** 9/10
```

## Skill 配合

- **google-analytics**：拉取转化数据作为 CRO 建议的量化基础
- **page-cro**：单页面深度优化
- **ab-test-setup**：设计并分析 CRO 优化测试
- **pro-report-builder**：生成专业 CRO 审计交付报告

## 局限性

- 依赖用户提供页面 URL 或截图进行分析
- 启发式评估为定性框架，最终需 A/B 测试验证
- 转化率基准为全球平均，中国市场需按品类调整
- 合规建议不构成法律意见，涉及广告法/价格法需咨询法务
