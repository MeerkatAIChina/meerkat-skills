# 🧠 CRO Auditor — 全漏斗转化率优化审计师

**一句话说清楚**：CRO Auditor 是一套系统化的转化率优化审计框架，覆盖着陆页、注册流程、支付漏斗、表单和 CTA 等关键转化节点。无论你是 SaaS 创始人、电商运营还是增长负责人，这套技能能帮你像顶级增长咨询师一样，精确诊断你的转化漏斗到底哪里在"漏水"。

## 它解决了什么问题？

你盯着后台数据心里发毛：流量不少，钱没少花，但就是没人点"立即购买"。改按钮颜色？换个标题？全是凭感觉的散打。CRO Auditor 给你一套完整的诊断工具：

- **LIFT 模型**：从价值主张、相关性、清晰度、紧迫感、焦虑感、干扰度六个维度，对页面元素逐一打分。不是凭经验拍脑袋，而是结构化地找到转化杀手。
- **页面级审计清单**：首屏、价值主张、CTA、社交证明、表单、信任要素……每个关键区块都有明确的检查项，对号入座就知道缺了什么。
- **漏斗分析**：从 Awareness → Interest → Desire → Action → Retention，逐阶段定位用户流失节点，给出各页面类型的转化率基准参照（好的、一般的、差的分别是多少）。
- **优先级矩阵**：ICE / PIE 双框架打分，帮你把有限的开发资源投在回报最高的优化上，而不是"先改个颜色试试"。
- **中国市场特别适配**：针对天猫/淘宝/京东/拼多多等主流电商平台，以及微信生态 SaaS 转化路径、移动端优化、支付方式覆盖、ICP 合规等，给出了完整的本地化指南。

## 适合谁用？

- 电商运营：想提升详情页转化、降低跳出率
- SaaS 增长团队：漏斗转化率远低于行业基准
- 独立创业者：自己动手优化着陆页但不知道从何下手
- 代理商/顾问：需要给客户交付专业 CRO 审计报告

## 审计输出长什么样？

一份完整的审计报告包含：
1. **执行摘要** — 当前转化率 vs 基准、Top 3 转化杀手、预估收入影响
2. **逐项问题清单** — 位置、影响等级、证据、具体修复建议、A/B 测试假设
3. **ICE 评分** — 每个建议的可执行优先级一目了然
4. **测试计划** — 假设 → 主指标 → 最小样本量 → 建议测试周期，直接可落地

## 10 大常见转化杀手速查

1. 页面加载慢（每 100ms 延迟 = 转化降 1%）
2. 价值主张模糊（用户 5 秒内看不懂你是干嘛的）
3. 表单字段太多（每多一个字段完成率降 5-10%）
4. CTA 文案弱（"提交" vs "开始免费试用"）
5. 零社交证明（92% 消费者购物前看评价）
6. 隐藏费用（购物车弃单第一杀手）
7. 多个竞争 CTA（决策瘫痪）
8. 移动端体验差（按钮太小、横滑、加载慢）
9. 信任缺失（无安全标识、无评价、无联系方式）
10. 离开时无挽留（无邮箱捕获、无退出意图弹窗）
