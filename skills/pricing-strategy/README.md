# Pricing Strategy — SaaS定价与商业化策略专家

## 技能定位

Pricing Strategy 是一个专注于SaaS产品定价与商业化策略的AI技能模块。它帮助产品经理、创始人和增长团队系统化地制定定价方案——从套餐结构设计、价值度量选择、价格点设定，到定价页面优化和提价策略，覆盖定价决策的完整链路。

当用户需要回答"我应该收多少钱"、"如何设计定价套餐"或"现在该涨价了吗"等问题时，本技能提供结构化的分析和建议框架。

---

## 核心能力

### 1. 价值导向定价
基于客户感知价值（而非成本）设定价格区间，在"次优替代方案"和"客户感知价值"之间找到最优价格点。帮助你理解和量化产品的差异化价值。

### 2. 套餐结构设计
运用 Good-Better-Best 三层框架，通过功能分级、用量限制、支持等级和访问权限四个维度进行套餐差异化设计。确保各套餐之间边界清晰、向上引导自然。

### 3. 定价研究方法
掌握 Van Westendorp 价格敏感度模型和 MaxDiff 特征分析等方法，通过定量研究确定客户支付意愿和最优价格区间，避免凭感觉定价。

### 4. 提价策略制定
识别提价时机信号（市场信号、业务信号、产品信号），提供四种提价执行策略：老客户保留原价、延迟提价通知、捆绑增值提价、套餐重构提价。

### 5. 定价页面优化
基于行为心理学原理（锚定效应、诱饵效应、魅力定价）优化定价页面布局，包括套餐对比表、推荐标签、年付折扣和信任信号的最佳实践。

## 适用场景

**适合使用的场景：**
- 新产品或新功能需要首次定价
- 现有定价策略需要优化或调整
- 从免费模式转向付费模式（或增加付费套餐）
- 考虑提价并需要策略建议
- 设计或优化定价页面
- 分析竞品定价并制定竞争策略
- 选择或调整价值度量（按用户/按用量/按功能等）

**不适合使用的场景：**
- 应用内升级弹窗或支付墙的设计优化 → 请使用 `paywall-upgrade-cro` 技能
- 用户流失分析和挽留定价 → 请使用 `churn-prevention` 技能
- 定价页面的文案撰写 → 请配合 `copywriting` 技能
- A/B测试的具体执行方案 → 请配合 `ab-test-setup` 技能

## 工作流程

本技能遵循以下五步定价决策流程：

### 第一步：背景信息收集
加载产品营销上下文文件（如存在），收集业务类型、当前定价、目标市场、市场进入模式、核心价值主张、竞品定价、当前转化率/ARPU/流失率等关键数据。明确优化目标是增长、收入还是利润率。

### 第二步：定价研究分析
运用 Van Westendorp 价格敏感度测试确定可接受价格区间，通过 MaxDiff 分析识别客户最看重的功能，结合竞品对标和客户反馈形成数据驱动的定价基础。

### 第三步：价值度量与套餐设计
选择合适的价值度量（按用户、按用量、按功能等），确保价格随客户获得的价值同步增长。基于 Good-Better-Best 框架设计套餐层级，明确各套餐的差异化要素。

### 第四步：价格点设定
基于研究数据设定具体价格点，运用锚定效应、诱饵效应和魅力定价等心理学原理优化价格呈现。制定年付折扣策略（通常17-20%），设计企业版/定制版定价方案。

### 第五步：实施与优化
遵循定价页面最佳实践构建套餐展示页，制定提价执行计划（如适用），建立定价效果监控指标（转化率、ARPU、各套餐占比），持续迭代优化。

## 注意事项与局限性

### 注意事项
1. **定价是动态的**：市场环境、竞品策略和产品价值会随时间变化，定价应定期审视调整
2. **数据驱动优先**：尽量基于用户调研和数据分析，而非主观判断
3. **测试验证**：任何定价变更建议在全面推行前进行小范围测试
4. **沟通至关重要**：提价时对现有用户的沟通策略直接影响流失率
5. **本地化考量**：不同市场的支付习惯和价格敏感度差异显著

### 局限性
1. 本技能提供的是结构化框架和最佳实践，最终定价决策需结合具体业务判断
2. 定价研究方法的精度依赖于样本量和调研设计质量
3. 无法替代专业的定价顾问或市场调研机构的深度服务
4. 各国法律法规（特别是消费者保护和反垄断方面）需另行咨询法务

## 中国市场适配

> 以下内容引自本技能「中国市场适配」章节，为中国市场用户提供本地化定价指导。

### 中国SaaS市场特征
中国企业更倾向于私有化部署和定制化服务，价格敏感度高于欧美市场。相较于订阅制，许多中国企业偏好一次性付费或按项目计费，因此在定价时需要灵活考虑混合收费模式。

### 微信生态变现
微信小程序/公众号的定价模式主要包括：
- **免费+增值服务**：基础功能免费，高级功能付费，降低用户获取门槛
- **会员制**：按月/按年订阅，享受专属权益，适合内容社区和工具类产品
- **按次付费**：适用于低频使用的工具类、内容类产品，用户接受度高

### 中国消费者定价心理学
- 中国消费者对"免费试用"接受度极高，但转化为付费用户需要明确的价值感知和紧迫感设计
- "自动续费"需严格遵守《消费者权益保护法》，必须在显著位置以显著方式提请消费者注意，并提供便捷的退订渠道
- 价格末尾数字偏好："8"（谐音"发"）和"9"（谐音"久"）被视为吉利数字
- "限时优惠"和"拼团"模式在中国市场转化效果显著

### 法规注意事项
- 《价格法》要求明码标价，不得价格欺诈
- 《电子商务法》规范线上交易定价行为
- SaaS出口业务需考虑跨境支付合规、汇率波动和税务筹划
- 《反垄断法》关于掠夺性定价的规定
- 《个人信息保护法》影响动态定价策略

### 本地支付方式
- 支付宝/微信支付的分期付款（花呗、分付）
- 企业银行转账（对公打款）
- 发票管理（普票/专票）是B2B交易必要环节
- 银联支付、Apple Pay等本地化支付渠道
