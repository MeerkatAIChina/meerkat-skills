# 🎙️ 会议洞察分析师 — 从你的会议录音中发现沟通盲区，成为更高效的沟通者

> 不是帮你记会议纪要——是帮你「看见」自己开会时的行为模式：你是不是总回避冲突？你的说话占比是不是太高？你的填充词是不是在关键时刻暴增？

---

## 痛点开篇

你开了一天会，晚上躺在床上回想——今天那个方案明明是错的，但你当时只是说了句「嗯，这个方向我们可以再想想」；你其实有话想说但插不上嘴，因为另外两个人一直在说；你感觉自己会议主导得不错，但事后听到别人说你「总是打断别人」。

**你在会议中的表现，自己往往是最后一个知道的。**

这个 SKILL 把你所有的会议录音/转录文件变成一面镜子——它会分析你的冲突回避模式、说话占比、填充词频率、倾听质量、主持会议的风格。每一个发现都附带时间戳和具体引用，让你**听到自己当时是怎么说的**，并给你一个**更好的说法**。

---

## 边界说明

| ✅ 能做什么 | ❌ 不做什么 |
|-----------|-----------|
| 分析会议转录文本中的沟通模式 | 不实时录制或转写会议（需要提前准备好文本） |
| 识别冲突回避、打断、填充词等行为 | 不评估会议的业务成果或决策质量 |
| 给出时间戳定位的具体改进建议 | 不替代领导力教练或职业发展顾问 |
| 对比多时间段的沟通能力变化趋势 | 不分析视频画面或肢体语言 |
| 支持 .txt / .md / .vtt / .srt / .docx 格式 | 不做会议纪要总结 |

---

## 核心能力

| 分析维度 | 具体检测项 |
|---------|-----------|
| **冲突回避** | 检测「maybe」「kind of」「I think」等模糊表达，识别岔开话题、间接表达的时刻 |
| **说话占比** | 计算你在每个会议中的发言百分比、平均发言轮次时长、问题 vs 陈述比例 |
| **填充词** | 统计「um」「uh」「like」「you know」的频率和触发场景 |
| **主动倾听** | 识别转述他人观点、追问澄清、在他人的基础上延展的发言 |
| **会议引导** | 分析决策方式（指令型 vs 协作型）、如何处理分歧、是否带动安静成员参与 |
| **趋势追踪** | 跨会议对比，追踪具体能力的改善或退步趋势 |

## 谁应该用

- ✅ 经常参加客户会议、想要优化沟通风格的咨询顾问
- ✅ 正在辅导下属沟通能力的团队负责人
- ✅ 想要对比自己 Q1 和 Q2 沟通变化的自驱型学习者
