# 🧪 A/B Test Setup — 实验设计与增长实验体系搭建

**一句话说清楚**：把"我们试试看"变成"我们验证一下" — A/B Test Setup 帮你从零设计科学严谨的 A/B 测试，包括假设构建、样本量计算、指标体系搭建和完整的增长实验流程。同时还能帮你把单次测试升级为一套持续运转的增长实验引擎。

## 散打实验 vs 科学实验

没有章法的 A/B 测试长这样：改个按钮颜色 → 跑了三天 → 看数据好像好一点 → 全量上线。一个月后回头看，转化率没变。

科学的 A/B 测试长这样：
1. **基于观察/数据提出假设**（不是拍脑袋）
2. **提前计算样本量和最小测试周期**
3. **预定义主指标、辅助指标和护栏指标**
4. **不偷看、不早停、不改变量**
5. **统计显著后做决策，把学到的写入知识库**

## 假设框架：从"我觉得"到"因为……所以……"

差的假设：
> "改一下按钮颜色也许能提高点击。"

好的假设：
> "因为热力图和用户反馈显示 CTA 不易被发现，我们相信把按钮尺寸加大并使用对比色，将使新访客的 CTA 点击率提升 15% 以上。我们将衡量从页面浏览到注册开始的点击率。"

模板：
```
因为 [观察/数据]，
我们相信 [改动]，
将会导致 [预期结果]，
针对 [目标用户]。
当 [指标] 验证时，我们就知道这是真的。
```

## 样本量速查表

| 基准转化率 | 10% 提升 | 20% 提升 | 50% 提升 |
|-----------|---------|---------|---------|
| 1% | 15 万/变体 | 3.9 万/变体 | 6 千/变体 |
| 3% | 4.7 万/变体 | 1.2 万/变体 | 2 千/变体 |
| 5% | 2.7 万/变体 | 7 千/变体 | 1.2 千/变体 |
| 10% | 1.2 万/变体 | 3 千/变体 | 550/变体 |

> 关键认知：基准转化率越低、期望检测的效应越小，需要的样本量就越大。不要测 2% 的微弱提升 — 你跑不出显著结果。

## 三个指标层次

| 指标类型 | 作用 | 示例 |
|---------|------|------|
| **主指标** | 用来判定胜负的唯一指标 | 方案选择率 |
| **辅助指标** | 解释为什么赢/输 | 页面停留时间、方案分布 |
| **护栏指标** | 绝不能变差的东西 | 客服工单数、退款率 |

## 运行中的铁律

- ✅ 监控技术问题和数据质量
- ✅ 记录外部因素（广告投放变化、节假日）
- ❌ 偷看结果然后提前停止（假阳性率从 5% 飙升到 26%+）
- ❌ 测试中途修改变体
- ❌ 中途新增流量来源

**最短测试周期**：至少 2 个完整商业周（覆盖周内/周末的差异），即使样本量提前达标也要跑满。

## 不止是单次测试 — 这是一套增长实验引擎

AB Test Setup 的进阶价值在于帮你把单次实验升级为**持续实验体系**：

### 实验飞轮
```
产生假设 → ICE 优先级排序 → 设计运行测试 → 统计分析 → 优胜模式入库 → 从经验中产生新假设 → 循环
```

### ICE 优先级框架
每个假设在 1-10 分上打分：
- **影响（Impact）**：如果做对了，能多大程度推动主指标？
- **信心（Confidence）**：基于数据（不是直觉）我们多确定这会成功？
- **容易度（Ease）**：多快多便宜能实现和衡量？

**ICE 分 = (I + C + E) / 3**，从高分开始做。

### 实验节奏建议
- **每周 30 分钟**：巡检运行中的实验（只看护栏，不偷看结果）
- **双周**：结束到期实验，分析结果，更新知识库，启动下一个
- **每月 1 小时**：复盘实验速度、胜率、累计提升，补充假设池，重排 ICE
- **每季度**：审计实验知识库 — 哪些已验证的模式还没规模化？漏斗哪一段欠测试？

### 实验知识库模板
每个赢/输的实验都应归档：
> 实验名称 → 日期 → 假设 → 样本量 → 结果 → 护栏指标 → 分群差异 → 为什么成功/失败 → 可复用模式 → 应用到哪些其他页面

## 适合谁用？

- 想开始做 A/B 测试但不知道怎么科学设计的团队
- 已经在做测试但总觉得"测不出结果"的增长负责人
- 想从单次测试升级为系统化实验引擎的成熟增长团队
- 负责搭建公司实验文化和流程的增长/产品 VP

> ⚠️ 注意：样本量数据基于标准统计公式（α=0.05, β=0.20），实际需求会因流量稳定性、季节性等因素浮动。建议使用 Evan Miller 或 Optimizely 的在线计算器根据你的具体情况精确计算。
