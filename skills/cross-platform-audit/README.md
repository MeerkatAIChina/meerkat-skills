# Cross-Platform Audit 跨平台广告审计大师

> **Google 说自己 ROAS 4×，Meta 说自己 ROAS 3.5×，加起来 7.5×——但你 GA4 里显示只有 2.8×。问题出在哪？这个 Skill 就是来回答这个问题的。**

---

## 一、跨平台审计解决的核心痛点

你不会只有 Google Ads。你可能有 Google + Meta + Microsoft 三个平台在跑。

但每个平台的报告都在「各说各话」：

- 归因窗口不一致（Google 用 30 天点击，Meta 用 7 天点击 + 1 天浏览）
- 转化定义不统一（Meta 的 Purchase 和 Google 的 Purchase 可能不是同一个事件）
- 平台之间互相抢功劳（同一个用户被 Google 和 Meta 各算一次转化）

`cross-platform-audit` 是**广告审计的总司令**——它不会自己审计每个平台，而是并行启动 Google / Meta / Microsoft 三个专业审计，然后**把结果合并成一个统一的健康评分**。

---

## 二、它做了什么单个平台审计做不到的事？

| 分析维度 | 单平台审计 | Cross-Platform |
|----------|-----------|----------------|
| 预算分配 | 只知道自己 | 跨平台最优分配 |
| 归因重叠 | 看不到 | 检测双平台重复计数 |
| 素材一致性 | 看不到 | 检测跨平台消息矛盾 |
| 追踪一致性 | 只检查自己 | 检测转化定义是否统一 |
| 全局 Kill List | 只杀自己平台 | 跨平台 CPA>3× 目标一键标记 |
| 放量机会 | 只知道自己的 | 识别哪个平台预算不够花 |

---

## 三、工作流程

1. **收集上下文** → 业务类型、月预算、各平台分配、目标、可用数据
2. **并行启动三个审计** → Google（74 项检查）/ Meta（46 项检查）/ Microsoft（30 项检查）
3. **合并结果** → 按预算权重计算综合健康分 `Σ(平台分 × 预算占比)`
4. **跨平台分析** → 预算分配 / 追踪一致性 / 素材对齐 / 归因重叠 / Kill List / 放量机会
5. **生成统一报告** → 含综合评分、各平台得分卡、优先级行动计划
6. **可选输出** → 一键生成客户汇报 PPT（通过 pro-deck-builder）

---

## 四、内置硬规则（跨平台通用）

1. **学习期内禁止任何修改建议**
2. **3× Kill Rule 全域适用**：任何平台 Campaign CPA > 目标 3× 立即标记
3. **转化追踪必须优先验证**——追踪坏了，其他优化都是白做
4. **预算重分配必须满足平台最低门槛**
5. **归因重叠必须标记**——平台总报告转化数超过 GA4 20%+ 即报警

## 五、谁应该用？

- ✅ **CMO / 增长 VP**：一眼看清全渠道投放健康度
- ✅ **代理商客户总监**：为客户提供跨平台整合审计报告
- ✅ **内部增长团队**：季度全渠道审计 + 预算重新分配决策
- ✅ **年投放 > $50K 的团队**：归因重叠造成的浪费可能占预算 15-30%
