# 🏛️ Marketing Council — 12 位殿堂级营销大师，围着你的方案吵一架

> **方案拿出来，团队全说「挺好」——没人反驳，也没人看得见风险。你需要的从来不是掌声，而是分歧。这个 SKILL 把 12 位营销大师请上桌，用他们各自公开的框架给你的具体问题挑刺，并告诉你他们在哪里吵起来了。**

---

## 😫 你是否也遇到过这些问题？

- 一个定位 / 定价 / 落地页方案出来，团队一致通过，上线后才发现方向就错了
- 想听不同视角，但公司里没人敢唱反调，也没人有跨品类的经验
- 读过一堆营销大师的书，但轮到自己具体问题，不知道谁的方法该用在哪
- 想知道「这个方案在 A 大师眼里会怎么被批」，但手边没人能扮演这个角色
- 决策靠感觉，缺一个能强制暴露「真实取舍」的机制

如果这说的就是你——这个 SKILL 就是为你准备的。

## ✅ 能做什么 | ❌ 不做什么

| ✅ 能做 | ❌ 不做 |
|---------|---------|
| 模拟 12 位大师（Godin / Ogilvy / Schwartz / Hopkins / Halbert / Brunson / Hormozi / Dunford / Sutherland / Sharp / Handley / Vaynerchuk）基于其**已发表的框架与立场**给出意见 | 不代表本人真实评价——输出全程标注为「模拟委员会」 |
| 三种模式：快问快答（1 位）、委员会会议（3–5 位，默认）、全体大会（12 位） | 不编造引语、不虚构背书或指责 |
| 强制安排至少一位「异议者」，确保委员会不是回音壁 | 不处理法律意见、内部政治或人身评价 |
| 输出**分歧地图**——最有价值的部分：谁和谁在哪儿真正冲突、背后的取舍是什么、什么证据能判定 | 不做执行工作（不写落地页、不写广告），方向定了就交接给执行 SKILL |
| 主席综合建议 + 具体下一步 + 执行交接清单 | 不承诺任何效果数字 |
| 可添加自定义顾问（你自己的老领导、内部高管，立场由你提供） | 不能替代真实的专家咨询与用户调研 |

## 🧰 核心能力

| 模块 | 说明 |
|------|------|
| **12 人顾问席** | 刻意选择视角互相冲突的人选——Sharp（证据派品牌科学）对 Godin（最小可行受众）、Hopkins（测一切）对 Sutherland（反直觉）、Dunford（定位）对 Hormozi（Offer） |
| **选座逻辑** | 按问题类型推荐强适配人选 + 天然异议者：定位类、Offer/定价类、品牌建设类、文案创意类、漏斗转化类、内容策略类、付费媒体类、增长放量类、受众渠道类、发布类各有配置 |
| **单顾问档案** | 每位顾问的视角、框架、有出处的立场、标志性提问、最擅长与盲区、语言风格、代表作——只加载上桌的那几位 |
| **委员会流程** | 加载档案 → 可选实时研究 → 每位 2–4 段意见 → 分歧地图 → 主席综合 |
| **实时研究通道** | 话题够具体时，去查这些大师**真的**就这类问题说过什么（书、文章、访谈、播客），带引用回来；研究结论与档案冲突时，以研究为准并注明修正 |
| **接地规则（不可协商）** | 标注模拟、不编造引语、不虚构背书、在世顾问额外谨慎、实质性分歧而非漫画化、档案与问题不重叠时用显式类比推理 |
| **反模式清单** | 一致同意的委员会、只换个名字的通用建议、名言拼贴、用委员会做执行工作、给一句标题上 12 个人 |

## 👤 谁应该用

- ✅ 做重大定位 / 定价 / 品牌决策、需要一个强制暴露取舍的机制的市场负责人
- ✅ 咨询顾问，为客户方案做「多视角压力测试」再交付
- ✅ 快消 / 消费品品牌的策略岗，需要在广告公司提案前先自己过一遍不同流派的批判
- ✅ 创始人 / 独立操盘手，没有团队可以吵架，但需要听到真正的反对意见
- ✅ 想系统化学习不同营销流派、理解各自适用边界的学习者
