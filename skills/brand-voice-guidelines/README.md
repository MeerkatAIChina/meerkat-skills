# Brand Voice Guidelines Skill — 品牌声音体系构建专家

> 帮 AI Agent 建立、记录和维护统一的品牌声音。从声音属性定义到语调矩阵，从消息框架到风格指南——一套完整的品牌声音体系输出。

---

## 📌 定位

**Brand Voice Guidelines** 帮团队将\"我们听起来像谁\"这个模糊问题，转化为可执行、可检验的品牌声音文档。产出涵盖：声音属性（Do/Don't）、语调矩阵（不同场景的声音适配）、消息框架（价值主张/标语/电梯演讲）、写作风格指南和渠道适配规范。

> **声音（Voice）= 你是谁（不变）。语调（Tone）= 你如何适配场景（可变）。**  
> 声音是品牌人格，始终一致；语调根据场景切换——庆祝 vs 危机，社交 vs 客服，博文 vs 法律文书。

---

## 🎯 核心能力

### 1. 品牌声音属性定义
从 9 大品牌人格原型（智者/创造者/英雄/弄臣/关怀者/叛逆者/探索者/统治者/凡夫俗子）中选择匹配，定义 3-5 个声音属性，每个属性标注\"我们是\"与\"我们不是\"的边界。

### 2. 语调矩阵
定义声音如何在不同场景中调整——官网 vs 社媒 vs 客服 vs 法务 vs 危机公关，每个场景明确：自信度、正式度、幽默度、共情度四个维度的取值。

### 3. 消息框架
结构化的品牌信息输出：
- 品牌承诺（一句话）
- 价值主张（3-5 条，每条配证明点）
- 标语方案（3 个备选）
- 电梯演讲（30 秒版）
- 标准简介段落（媒体/关于页通用）

### 4. 写作风格指南
语法与规范决策记录：牛津逗号用不用、缩略形式用不用、表情符号规则、大小写规范、数字格式、人称代词选择。含禁用词汇表（\"utilize\"→\"use\"\"leverage\"→\"use\"\"synergy\"→\"collaboration\" 等）。

### 5. 声音一致性审计
跨渠道抽样评分（每渠道 3 页 × 声音属性 1-5 分），识别离群内容，验证语调与场景匹配。

## 📋 适用场景

### ✅ 应该使用
- 品牌刚起步，需要定义\"我们的声音是什么\"
- 品牌声音不一致——不同渠道听起来像不同公司
- 团队扩张，新成员需要品牌声音参考文档
- 启动品牌重塑或声音升级
- 需要一份可供所有营销物料对齐的\"品牌声音宪章\"

### ❌ 不应该使用
- 具体文案撰写 → 使用 `copywriting`（在品牌声音框架下执行）
- 单页转化优化 → 使用 `page-cro`
- 视觉品牌设计 → 本 Skill 只处理文字声音，不涉及视觉

## 🔄 工作流程

```
Step 1: 审计现有内容
    │   分析 10-20 篇跨渠道内容 → 找出一致和不一致的模式
    ▼
Step 2: 定义声音属性
    │   选 3-5 个属性 → 每个属性 "我们是 / 我们不是" 边界标注
    ▼
Step 3: 匹配品牌人格原型
    │   9 大原型中选 1-2 个 → 明确品牌人格定位
    ▼
Step 4: 创建语调矩阵
    │   7+ 场景 × 4 维度（自信/正式/幽默/共情）
    ▼
Step 5: 编写消息框架
    │   品牌承诺 + 价值主张 + 标语 + 电梯演讲 + 标准简介
    ▼
Step 6: 制定写作风格指南
    │   语法/词汇/格式规范 + 禁用词表
    ▼
Step 7: 输出品牌声音文档 + 一致性审计清单
```

## 🚀 使用方法

### 安装

```bash
git clone https://github.com/thatrebeccarae/claude-marketing.git
cp -r claude-marketing/skills/brand-voice-guidelines ~/.claude/skills/
```

### 触发方式

- \"帮我建立品牌声音指南\"
- \"我们的品牌听起来应该是什么样的\"
- \"做一个语调矩阵\"
- \"审核一下各渠道的品牌声音是否一致\"

### 最佳实践

1. **先收集素材** — 准备 10-20 篇现有内容（官网/邮件/社媒/客服）再做审计
2. **团队共识优先** — 声音属性不是一个人说了算，拉上市场和品牌负责人一起确认
3. **Do/Don't 示例要具体** — \"我们是温暖的\" → 太模糊；\"温暖 = 用'你'开头，先肯定再解决问题\" → 可执行
4. **语调矩阵覆盖真实场景** — 不只是\"社媒\"，细化到\"产品故障公告\"\"裁员沟通\"\"节日祝福\"等
5. **定期审计** — 每季度抽查各渠道内容，防止声音漂移

## 📊 输出示例

```markdown
# [品牌名] 声音指南

## 我们是谁
[一段话描述品牌性格]

## 声音属性
### 1. 自信但不傲慢
- ✅ Do: "我们的方法经过了 500 家企业的验证"
- ❌ Don't: "我们是市场上唯一的正确选择"

### 2. 专业但不学究
- ✅ Do: "数据告诉我们三件事"
- ❌ Don't: "据多维度数据交叉验证表明……"

### 3. 温暖但不随意
- ✅ Do: "先别急，我们一步步来"
- ❌ Don't: "没事的宝贝，都会好起来的"

## 语调矩阵
| 场景 | 自信度 | 正式度 | 幽默 | 共情 |
|------|--------|--------|------|------|
| 官网首页 | 高 | 低-中 | 轻 | 中 |
| 博文 | 高 | 低 | 中 | 中 |
| 客服回复 | 中 | 中 | 无 | 极高 |
| 危机公关 | 高 | 高 | 无 | 极高 |
```

## ⚠️ 注意事项与局限性

### 局限性
- **需要团队共识** — 声音定义不是纯技术输出，需要品牌负责人参与确认
- **首次建立需要较多输入** — 没有现有内容时，需要大量讨论来确定声音方向
- **不涉及视觉品牌** — 只处理文字声音，Logo/色彩/排版等视觉元素不在范围内
- **语调矩阵是起点不是终点** — 实际运营中可能需要补充更多细分场景
- **执行比定义更难** — 写出品牌声音文档只是第一步，真正让所有内容对齐需要持续投入

### 声音一致性审计清单
- [ ] 每渠道抽样 3 页内容
- [ ] 每个声音属性打分（1-5）
- [ ] 标记离群内容（不像品牌声音的页面）
- [ ] 检查禁用词汇
- [ ] 验证语调匹配场景
- [ ] \"大声朗读\"测试——听起来像同一个人吗？
