# HTML Report Builder — 咨询级报告，一行代码都不用写设计

> 大多数技术报告长什么样？白底黑字 + 表格 + 一些截图。这不是你交付给客户的东西——至少不应该是。

## 痛点：技术报告的内容是一流的，排版是三流的

你花了两周做审计，收集了 347 个数据点，发现了 12 个关键问题。然后你把结果放进 Google Docs，调了调字体，加了几个表格，转成 PDF 发给了客户。

问题在哪？——你的报告内容和你的报告视觉根本不在同一个级别上。客户看到的是：白底黑字、缺少视觉层次、数据没有强调、关键结论淹没在正文中。你传递的信号是"内容很专业，但我不太在意呈现"。

更现实的是：你根本没时间从头设计。你不是设计师，你没有精力在 Figma 里搭一套报告模板。

## 能力：开箱即用的咨询级报告设计系统

`html-report-builder` 是一套**完整的设计系统 + 组件库**，专为技术报告（审计报告、性能分析、策略文档、案例研究）定制。你只需要提供数据和叙事逻辑，排版、字体、配色、组件全部开箱即用：

- **双模式排版**：暗色封面页（`#141414` 深黑）+ 暖奶油色内容页（`#FAF7F2`），一眼区别于白底文档。
- **专业字体系统**：Switzer（标题和正文，来自 Fontshare CDN）+ Cartograph CF（所有数字/数据内容，等宽字体）。
- **8 种精选组件**：KPI 卡片（大数字+标签+详情）、数据表格（等宽数字+严重级别着色）、洞察 Callout 框、编号建议卡（含影响力和工作量标记）、优先级横幅、章节分割线、自定义标记列表、编号列表。
- **叙事规则内置**：先用数据说话、每个章节一个洞察、每个指标都要有基准对比、语义色只用于性能指标。

输出是**独立 HTML 文件**——无需任何构建工具，浏览器直接打开，Cmd+P 即可导出为 PDF（设置无边距 + 启用背景图形）。

## 谁在用？

- **咨询顾问**：为客户交付专业的审计报告和策略文档。
- **技术负责人**：向管理层呈现系统性能分析和架构评估。
- **DevRel / 解决方案架构师**：为客户输出技术评估报告。
- **数据分析师**：将数据洞察转化为可读性强的正式文档。

## 配合其他技能

- **`image`**：如果需要更定制化的视觉风格而非固定设计系统。
- **`pro-deck-builder`**：如果交付物是演示文稿而不是报告文档。
- **`pro-report-builder`**：另一个报告生成器，偏向 8.5×11 英寸印刷排版（本技能注重视觉冲击力更多的咨询风格）。
- **`brand-dna`**：用品牌 DNA 覆盖默认的绿色 accent 色。

> **"你的分析值得一套配得上它的排版。让报告成为你专业度的延伸，而不是一个文档附件。"**
