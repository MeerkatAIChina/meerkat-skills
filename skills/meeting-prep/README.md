# 📋 会前准备引擎 — 不再"裸奔"进会议室

> **一句话：输入会议对象和类型，自动搜索历史笔记、过往承诺、背景信息，生成结构化会议 Brief——附赠可追问的尖锐问题。让你的每一次会议都带着情报进场。**

---

## 🤔 你是不是也经历过这些？

- 还有 10 分钟开会，你还在翻聊天记录找「上次聊了什么」
- 会上对方提到一个你「承诺过但忘了」的事项，你只能尴尬地说「我再确认一下」
- 每次见客户前都在想「我该问什么？」，最后就随便聊了聊
- 会议结束才想起来「我应该问一下他们对我们新功能的看法」

**会前准备引擎**强制你在会前 10 分钟做完所有功课——查历史、翻笔记、对承诺、列问题——让你带着情报和策略走进每一个会议室。

---

## 🎯 边界说明

| ✅ 能做什么 | ❌ 不做什么 |
|-----------|-----------|
| 从你的笔记库（Obsidian Vault）搜索与参会人/公司相关的历史记录 | 不在你没有权限的系统中搜索 |
| 提取过往会议纪要、待办事项、未完成的承诺 | 不自动发送会议邀请或邮件 |
| 按会议类型（销售/策略/合作/面试…）生成定制化议程 | 不替代实时会议记录工具 |
| 输出结构化 Brief：优先级→背景→追问列表→期望结果 | 不编造你没有记录过的信息 |
| 保存 Brief 到指定目录，形成会议准备档案 | — |

---

## 🧰 核心能力

| 步骤 | 能力 |
|------|------|
| **信息摄入** | 确认参会人姓名/公司、会议类型、时间、可选的前次会议记录 |
| **Vault 搜索** | 在你的 Obsidian 笔记库中搜索与参会人/公司相关的所有笔记 |
| **历史会议** | 提取过往会议 Brief，回顾上次聊了什么、达成了什么 |
| **承诺检查** | 扫描待办事项和跟进项，揪出你承诺过但未完成的事 |
| **议程生成** | 按会议类型生成定制化议程（WRS/Sales/Strategy/Partnership/Interview） |
| **尖锐问题** | 基于搜索结果生成 5 个可追问的尖锐问题 |
| **风险预警** | 标注已知的异议点、敏感话题、未闭合的对话 |
| **输出保存** | 结构化 Brief 输出 + 自动保存到 vault 指定目录 |

---

## 👤 谁应该用

- ✅ 销售负责人——见客户前快速回顾历史，带着情报去谈
- ✅ 咨询顾问——每个客户会议都值得做功课
- ✅ 客户成功经理——回顾客户历史问题、未解决的需求
- ✅ 创业者/CEO——投资人会议、合作洽谈，不能「裸奔」
- ✅ 产品经理——用户访谈前回顾上次反馈和遗留问题
- ✅ 任何人——只要你开重要会议，这个技能就值得跑一遍
