# Social Media Strategy 社交媒体策略大师

> **「多发点内容」不是策略。策略是：选对平台、定好节奏、建立内容支柱、设计互动机制、用数据迭代。**

---

## 一、核心痛点

大多数社交媒体运营的问题不是「发得不够多」，而是：
- 选错了平台（B2B 猛发 Instagram，B2C 死磕 LinkedIn）
- 没有内容支柱（今天发行业洞察，明天发猫图）
- 频率不合理（一天 10 条 Twitter 但 0 互动）

`social-media-strategy` Skill 提供**从平台选择到内容日历到互动策略**的完整体系。

---

## 二、核心能力

- **平台选择矩阵**：根据行业/受众/目标自动推荐最优平台组合
- **内容支柱框架**：40% 教育 / 25% 社交证明 / 25% 行业洞察 / 10% 个人
- **内容日历**：2 周样本日历含每日主题 + 格式 + 跨平台复用
- **互动策略**：如何回复评论、如何主动参与对话
- **KPI 体系**：各平台的核心指标和基准

---

## 三、谁应该用？

- ✅ 从零开始做社交媒体的品牌
- ✅ 已有社交媒体但缺乏系统策略的团队
- ✅ 代理商为客户做社交媒体方案
