# 📧 Email Sequence — 邮件序列设计与自动化流程

> 你有了1000个订阅用户……然后呢？第一封欢迎信发了，第二封迟迟没想好怎么写，一个月后用户的热情凉了，你的转化率也跟着凉了。邮件序列不是「想到什么发什么」——它是你和用户之间持续对话的设计蓝图。

---

## 每一封邮件都是一个台阶，把用户从「刚认识」带到「愿意付费」

**Email Sequence** 是邮件序列设计的专业引擎，覆盖七大序列类型：欢迎序列、线索培育序列、再激活序列、购买后序列、事件触发序列、教育序列、销售序列。它帮你系统化地规划「发什么、什么时候发、发给谁、达到什么目的」。

---

## 明确的边界

| ✅ 覆盖范围 | ❌ 不覆盖 |
|---|---|
| 自动化多封邮件序列设计 | 冷邮件外联（见 `cold-email`） |
| 欢迎/培育/再激活/购买后/教育序列 | 单封邮件撰写（见 `email-composer`） |
| 主题行策略、延迟设置、CTA设计 | 应用内引导（见 `onboarding-cro`） |
| 序列指标与工具集成 | Klaviyo平台操作（见 `klaviyo-analyst`） |

---

## 核心能力

- **7种序列类型全模板**：欢迎序列(5-7封/12-14天)、线索培育(6-8封/2-3周)、再激活(3-4封/2周)、产品上手(5-7封/14天)、购买后、事件触发、教育/销售序列
- **4项核心原则**：一封邮件一个任务、先给价值再开口、相关性比数量重要、每封邮件推动用户前进一步
- **精准时序**：欢迎信立即发送→早期序列每1-2天→培育每2-4天→长期每1-2周；B2B避周末、B2C测试周末
- **主题行策略**：清晰>聪明、具体>模糊、40-60字符最佳、预览文本不重复主题行
- **邮件类型全览**：上手邮件、留存邮件、账单邮件、使用报告、赢回邮件、活动邮件——每种有专属模板
- **工具集成矩阵**：Customer.io / Mailchimp / Nitrosend / Resend / SendGrid / Kit 的选用指南

## 配合使用建议

| 技能 | 配合方式 |
|---|---|
| `cold-email` | 冷邮件获取线索→email-sequence做线索培育 |
| `onboarding-cro` | 应用内引导+邮件引导配合，不重复 |
| `lead-magnets` | 规划钩子内容→导入培育序列 |
| `churn-prevention` | 取消挽回+催收策略，邮件为支撑渠道 |
| `ab-test-setup` | 测试邮件主题行、CTA、发送时间 |
| `popup-cro` | 弹窗收集邮箱→进入邮件序列 |
