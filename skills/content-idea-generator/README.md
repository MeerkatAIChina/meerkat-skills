# Content Idea Generator Skill — AI 选题灵感引擎

> 内容没有定位就是噪音。基于定位驱动选题，6 大框架 + 4 道质量过滤，让灵感和策略同步到位——不再拍脑袋想选题。

---

## 📌 定位

**Content Idea Generator** 是一个定位驱动的选题生成器。它不随机抛话题，而是先确认你的定位是否足够具体，然后基于定位、ICP 痛点和真实证据点，用 6 个内容框架系统化生成高质量选题。

> ⚠️ 定位不过关，选题不开始。模糊的定位只会产出模糊的选题。

---

## 🎯 核心能力

### 1. 三种模式灵活选择
| 模式 | 产出 | 适合场景 |
|------|------|---------|
| `quick` | 5 个选题，即时输出，无深度调研 | 卡壳时快速破局 |
| `standard` | 10-15 个定位锚定的选题（含格式和理由） | 日常内容规划 |
| `deep` | 完整内容日历系统：支柱、格式、节奏、30 天计划 | 启动或重构内容策略 |

### 2. 六大选题框架
1. **问题点名** — \"[受众]在[话题]上犯的最大错误\"
2. **实操拆解** — \"如何[达成结果]同时避免[常见障碍]\"
3. **逆向观点** — \"别再[常见做法]，真正有效的是……\"
4. **幕后真相** — \"我[做了某件事]，实际发生了什么\"
5. **模式洞察** — \"[经历A]教给我的[话题B]启示\"
6. **资源栈** — \"[数量]个我真正在用的[结果]工具\"

### 3. 四道质量过滤器
每个选题必须通过三重检验才进入输出：
- **够具体吗？** — 有具体角度（\"如何用 LinkedIn 拿客户\" → ❌；\"500 粉以下如何靠框架帖收到 DM\" → ✅）
- **有钩子吗？** — 能写出让人停下滑动的第一句
- **连接 ICP 痛点吗？** — 直击目标客户真实焦虑

### 4. 自我纠错机制
批量生成后执行自检：所有选题是否锚定定位？是否有足够具体的钩子？是否至少一个选题关联了用户提供的真实证据点？不达标直接替换。

## 📋 适用场景

### ✅ 应该使用
- 不知道今天/这周发什么
- 需要批量产出选题做内容日历
- 感觉内容越写越散，缺乏主线
- 想从\"灵感驱动\"升级为\"定位驱动\"的内容生产
- LinkedIn/Twitter/Newsletter 持续运营但创意枯竭

### ❌ 不应该使用
- 定位本身还不清晰 → 先用 `positioning-basics` 明确定位
- 需要写具体文章 → 选题确定后用 `copywriting`
- 已有内容支柱（来自 `linkedin-authority-builder`）→ 本 Skill 会自动对齐现有支柱，不会生成外部话题

## 🔄 工作流程

```
定位检查（定位不具体则拒绝开始）
    │
    ▼
Phase 1: 上下文分析（定位强度 + 证据点审计 + 平台匹配 + 内容缺口）
    │
    ▼
Phase 2: 时效性检查（Web 搜索最新趋势 → 找到当前话题钩子）
    │
    ▼
Phase 3: 选题生成（6 框架 × N 个选题）
    │
    ▼
Phase 4: 质量过滤（具体性 ✅ + 钩子 ✅ + ICP 痛点 ✅）
    │
    ▼
Phase 5: 自我纠错（替换不达标题选 + 标注原因）
    │
    ▼
输出：Quick Wins（本周可发）+ Authority Builders（本月值得投入）
```

## 🚀 使用方法

### 安装

```bash
cp -r skills/content-idea-generator ~/.claude/skills/
```

### 触发方式

- \"帮我想一些选题\"
- \"这周发什么好？\"
- \"给我一些 LinkedIn 帖子的灵感\"
- \"做一个 30 天的内容日历\"

### 最佳实践

1. **先跑 `positioning-basics`** — 如果定位还写不出\"我帮[具体人群]通过[独特方式]实现[具体结果]\"，先别生成选题
2. **提供真实的客户反馈** — 销售电话记录、客户问题、支持工单都是选题金矿
3. **选择匹配的模式** — 日常卡壳用 `quick`，定期规划用 `standard`，系统搭建用 `deep`
4. **不跳过自检** — Phase 5 的自我纠错能筛掉 80% 的泛泛选题

## ⚠️ 注意事项与局限性

### 局限性
- **定位是硬门槛** — 定位模糊则放弃生成，防止产出噪音
- **不了解你的全部业务细节** — 基于你提供的信息，可能遗漏内部独有的洞察
- **时效性搜索依赖网络** — 话题趋势可能因搜索时效而有延迟
- **批量生成不等于批量发布** — 选题质量 > 数量，不建议一次性发完所有选题

### Fluff Filter（不生成这些）
- ❌ \"感恩这段旅程\"式感悟帖
- ❌ 没有具体观点的通用励志语录
- ❌ 无实际观点的空泛\"思想领导力\"
- ❌ 纯互动诱饵（\"同意吗？评论区见\"）
- ❌ 超出定位范围的话题
