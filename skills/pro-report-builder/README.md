# Pro Report Builder — 印刷级排版的技术报告，从 HTML 到 PDF 一气呵成

> 一份 30 页的技术审计报告，如果在 Word 里排版需要 8 小时。在 Pro Report Builder 里——你只需要提供数据和洞察。

## 痛点：多页技术报告的排版是体力活

长报告和 PPT 的排版逻辑完全不同。PPT 是一页一页讲故事的，每页独立；报告是连续的，页码、页脚、章节延续标记、表格跨页处理……这些"排版细节"在 Word/Google Docs 里需要手动维护，稍有不慎就乱。

更糟糕的是：当你的数据变化了一点——某个数字更新了、某个表格多加了两行——整个文档的页面分布可能就变了。你不得不重新检查每一页是否溢出、页码是否仍然正确、章节"接续"标记是否还在正确的位置。**这是编辑，不是创作——但占用了你交付前 80% 的时间。**

## 能力：8.5×11 英寸印刷排版设计系统 + 完整组件库

`pro-report-builder` 是一套专为**多页技术文档**设计的完整排版系统。它和 `pro-deck-builder`（16:9 幻灯片）是互补的——报告用这个，演示用那个。

核心设计语言：

- **页面规格**：8.5×11 英寸竖版（Letter），模拟印刷品阅读体验。
- **品牌可定制**：所有颜色、字体、间距通过 CSS 自定义属性集中管理，替换一组变量即可切换品牌。
- **双模式页面**：暗色封面页（`#141414`）+ 暖奶油色内容页（`#FAF7F2`）——拒绝纯白底。
- **专业字体系统**：Switzer 作标题/正文 + Cartograph CF 作所有数据和数字内容。封面标题使用 Light (300) 字重而非 Bold——轻盈即自信。

内置 7 类 20+ 种组件，每个都有完整的 HTML+CSS 实现：

| 类别 | 组件 |
|------|------|
| **页面结构** | 页面容器、封面页、内容区、页脚（含页码）、章节标题+accent 下划线、章节续接标记 |
| **数据展示** | KPI 卡片行（4 列网格）、风险 KPI 卡片（红色调变体）、数据表格（斑马纹+accent 表头+严重级别着色） |
| **内容块** | Callout 框（蓝/绿/红/琥珀四色左边界）、正文段落、Bullet 列表、编号列表 |
| **建议区** | 优先级横幅（CRITICAL/HIGH/MEDIUM/LOW）、建议卡片（多字段+左 accent 条）、快赢行动表 |

**页面溢出防护是内置的**：每个页面高度固定 11 英寸，生成前自动预算内容区高度，建议卡片每页最多 3 张完整版，表格超 12 行自动降级为密集模式。

## 谁在用？

- **咨询顾问 / 分析师**：交付 20-50 页的专业审计报告、评估文档或策略建议书。
- **安全工程师**：输出渗透测试报告和合规审计文档。
- **技术负责人**：架构评审、技术选型分析等需要长篇论证的内部文档。
- **DevRel / 解决方案架构师**：客户交付的技术白皮书和实施建议。

## 配合其他技能

- **`pro-deck-builder`**：同一个项目的数据可以同时输出报告（本文档）和演示文稿（pro-deck-builder）。
- **`html-report-builder`**：另一个 HTML 报告生成器，风格偏视觉冲击力强的咨询报告（本技能偏印刷排版）。
- **`brand-dna`**：用品牌色覆盖默认的 accent 绿色。
- **`frontend-design`**：如果需要完全定制化的页面设计而非固定排版系统。
