# RevOps — 收入运营：把营销、销售、客户成功焊成一台发动机

> **营销说"线索质量差"，销售说"线索根本没人跟"，CS 说"接手的客户什么都不懂"——RevOps 解决的就是这些。**

---

## 为什么大多数公司的"收入引擎"实际上在空转？

大多数 B2B 公司的市场到营收链路长这样：

```
市场产生线索 → 扔给销售 → 销售挑着跟 → 跟成了签单 → 签完了扔给 CS
```

每个箭头都是一道**信息断崖**。市场不知道哪些线索变成了营收，销售不知道哪些行为是购买信号，CS 不知道客户是怎么被卖进来的。各部门对着自己的 KPI 优化，加起来未必是营收最大化。

RevOps 技能要做的就是把这三个部门焊成一条**端到端的收入流水线**——从线索到现金（Lead-to-Cash），每一个交接点都有定义、有 SLA、有度量。

## 核心能力矩阵

### 🔄 线索生命周期框架

七阶段标准定义——每个阶段都有明确的**进入标准、退出标准和责任人**：

| 阶段 | 进入标准 | 退出标准 | 负责人 |
|------|----------|----------|--------|
| **订阅者** | 订阅内容（博客/邮件） | 提供公司信息或展示参与度 | 市场部 |
| **线索（Lead）** | 已识别联系人+基本信息 | 达到基础匹配标准 | 市场部 |
| **MQL** | 匹配度+参与度双达标 | 销售在 SLA 内接受/拒绝 | 市场部 |
| **SQL** | 销售接受并完成初步沟通 | 创建商机或退回培育 | 销售（SDR/AE） |
| **商机** | BANT 确认 | 赢单或输单 | 销售（AE） |
| **客户** | 已签单 | 增购/续约/流失 | CS |
| **布道者** | 高 NPS+推荐+案例 | 项目持续参与 | CS + 市场部 |

### 🎯 线索评分模型设计

**一个合格的 MQL 必须同时具备"匹配度"和"参与度"：**

- **显性评分（匹配度）**——他们是理想客户画像吗？（公司规模、行业、职位、技术栈）
- **隐性评分（参与度）**——他们表现出购买意愿了吗？（定价页访问、Demo 请求、多次回访）
- **负向评分**——哪些信号应降分？（竞品邮箱、学生邮箱、退订、不匹配的职位）

单纯匹配合格只是"好人"，高参与度的学生只是"热心网友"——两者都不是 MQL。

### 📬 线索路由规则

| 路由方式 | 机制 | 适用场景 |
|----------|------|----------|
| 轮询分配 | 平均分配 | 区域均等、客单价相近 |
| 地域/行业匹配 | 按地区或垂直行业分配 | 区域团队、行业专家 |
| 指定账户 | 为命名客户分配对应销售 | ABM、战略客户 |
| 能力匹配 | 按交易复杂度/产品线/语言分配 | 多产品线、国际团队 |

核心原则：**速度是转化率的第一要素**——5 分钟内联系线索，转化率比 30 分钟后高 21 倍。

### 📊 商机管道管理

- **阶段必须字段**：每推进一个阶段，必填字段不完成则不能推进
- **停滞交易告警**：超过平均停留时间 2 倍的交易自动标记
- **跳阶段检测**：从"合格"直接跳到"提案"的异常路径告警
- **关闭日期纪律**：推迟日期必须带原因说明

### 🔍 数据卫生与季度审计

- 去重策略（邮箱域名 + 公司名称 + 电话）
- 阶段推进时强制补齐必填字段
- 季度审计：合并重复记录 → 验证邮件可送达性 → 归档 12 月未活跃联系人 → 检查生命周期阶段分布 → 抽查数据准确性

### 🤝 交易台（Deal Desk）审批层级

| 折扣力度 | 审批层级 |
|----------|----------|
| 标准定价 | 自动通过 |
| 10-20% | 销售经理 |
| 20-40% | 销售 VP |
| 40%+ 或定制条款 | 交易台审核（销售 + 法务 + 财务） |
| 多年/企业级 | 财务 + 法务 |

## RevOps 核心指标仪表盘

| 指标 | 公式 / 定义 | 基准 |
|------|-------------|------|
| 线索 → MQL 率 | MQL / 总线索数 | 5-15% |
| MQL → SQL 率 | SQL / MQL | 30-50% |
| SQL → 商机率 | 商机 / SQL | 50-70% |
| 管道速度 | (交易数 × 平均交易额 × 赢率) / 平均销售周期 | 因 ACV 而异 |
| CAC | 销售+市场总支出 / 新客户数 | LTV:CAC > 3:1 |
| 响应速度 | 表单提交到销售首次联系的时间 | < 5 分钟为优 |
| 赢单率 | 赢单 / 总商机数 | 20-30%（因行业而异） |
