## 一、Google Ads 账户的「冰山效应」

你以为你在优化广告。实际上：

- 70% 的搜索词报告你从来没看过
- 品牌词和非品牌词混在一起互相抢预算
- Performance Max 在悄悄蚕食你表现最好的 Search 广告
- 增强型转化追踪没开，数据黑洞越来越大

**Google Ads 是世界上最复杂的广告系统之一。** 大多数账户的问题不是「不知道怎么优化」，而是「根本不知道哪里出了问题」。

`google-ads` 这个 Skill，把资深 SEM 优化师「打开账户 30 秒定位核心问题」的诊断直觉，封装成 AI 可执行的 11 步全链路审计。

## 二、它不是什么东西？

- ❌ **不是自动投放机器人**：不会直接操作你的 Google Ads 账户
- ❌ **不是关键词研究工具**：不替代 Keyword Planner，但在审计中帮你发现关键词盲区
- ❌ **不能保证排名第一**：但能告诉你为什么没排到、怎么修

它是：**从 4 小时手工排查到 10 分钟 AI 诊断的效率革命。**

## 三、真实场景：一个 CPA 飙升的 B2B SaaS 账户

账户月消耗 $25,000，CPA 在过去 90 天从 $120 涨到了 $225。

**11 步审计后发现了这些「沉默杀手」**：

1. **转化追踪** → 增强型转化未开启，30%+ 转化数据丢失，CPA 被虚高计算
2. **账户结构** → 品牌词和非品牌词混在同一广告系列，品牌词占 80% 预算
3. **出价策略** → 3 个广告系列用 Target CPA 但没有足够转化数据支撑（学习失败循环）
4. **关键词** → 15% 搜索词完全不相关，Quality Score 平均 5.2（低于 6 的红线）
5. **PMax 自查** → 正在与品牌 Search 广告互相竞价，没有品牌排除
6. **落地页** → 移动端加载速度 4.2 秒，SEO 落地页和广告落地页消息不一致

**输出：一份 0-100 分健康评分 + Quick Wins 清单 + 按预期营收影响排序的行动计划。**

## 四、核心能力矩阵

| 能力模块 | 覆盖范围 |
|----------|----------|
| **全链路审计** | 转化追踪、账户结构、预算出价、关键词、广告文案、Shopping、PMax、受众、落地页、竞争对手 11 维度 |
| **广告类型** | Search / Shopping / Performance Max / Display / Video / Demand Gen / App |
| **出价策略** | Manual CPC / Target CPA / Target ROAS / Max Conversions / Target Impression Share |
| **受众策略** | Customer Match / 网站访客 / In-market / Affinity / 自定义受众 / RLSA |
| **转化追踪** | Google Tag / GTM / 增强型转化 / 离线转化导入 / GA4 集成 |
| **PMax 专项** | 素材组质量、受众信号、URL 扩展、品牌排除、搜索广告冲突检测 |

### 内置硬规则

1. **广泛匹配 + 人工出价 = 禁止**（预算失控组合）
2. **CPA > 目标 3× → 立即标记暂停或重建**
3. **增强型转化必须推荐开启**
4. **欧盟流量必须启用 Consent Mode v2**
5. **至少 3 个否定关键词列表**（竞品/招聘/免费/无关）
6. **学习期内禁止修改建议**
7. **品牌和非品牌必须分离**（独立预算和出价）
8. **PMax 必须排除品牌**（当存在品牌 Search 广告系列时）
