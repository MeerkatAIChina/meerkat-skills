# 🐦 Twitter 算法优化器 — 基于开源推荐算法逆向工程，让你的推文获得最大算法分发

> 不靠玄学、不靠运气。Twitter 的推荐算法已经开源——这个 SKILL 把 Real-graph、SimClusters、TwHIN、Tweepcred 四大排名机制翻译成人话，逐条告诉你怎么写、怎么改、为什么。

---

## 痛点开篇

你花了一小时打磨一条推文，自觉写得很好——有观点、有干货、甚至还有幽默。发出去之后，24 小时过去了，3 个 Like，0 条评论。

而隔壁那个明显没你专业的人，随便发了一句「大家都用什么工具？」结果 200 条评论。

你不是内容不行——你是**不了解算法的游戏规则**。

Twitter 的推荐系统不是随机分发，也不是按时间线公平展示。它背后有 Real-graph（互动预测）、SimClusters（社区检测）、TwHIN（知识图谱）、Tweepcred（权威评分）四套模型在同时打分。你的推文写得好不好是一回事，**能不能通过这四套模型的评分是另一回事**。

这个 SKILL 就是你的算法说明书。它基于 Twitter 开源代码，逐条分析你的推文在每一层评分中会拿多少分，然后告诉你具体怎么改。

## 边界说明

| ✅ 能做什么 | ❌ 不做什么 |
|-----------|-----------|
| 基于 Twitter 开源算法分析推文优化空间 | 不保证一定获得高曝光（算法 > 内容质量 > 运气） |
| 给出每条推文在 Real-graph/SimClusters/TwHIN/Tweepcred 下的评分 | 不帮你刷量或操作虚假互动 |
| 基于算法机制给出具体的改写建议 | 不适用于 LinkedIn/TikTok/Instagram 等算法不同的平台 |
| 教你如何触发点赞/回复/转发/收藏四种正向信号 | 不替代内容策略——好内容 + 好算法 = 最佳效果 |
| 分析推文为什么表现不佳 | 不分析已删除的推文 |

---

## 核心能力

| 算法模型 | 优化策略 |
|---------|---------|
| **Real-graph（互动预测）** | 让你的粉丝「一定会互动」——问问题、激发争议、@相关创作者 |
| **SimClusters（社区共振）** | 选一个明确的 Topic，用圈内语言，让算法精准推给对应社区 |
| **TwHIN（内容-用户匹配）** | 保持领域一致性，建立主题权威，让算法正确归类你的内容 |
| **Tweepcred（权威评分）** | 跟高信用用户互动，持续高质量输出，避免互动诱饵 |
| **正向信号触发** | 针对 Like/Reply/Retweet/Bookmark 四种信号设计不同的触发策略 |
| **负向信号规避** | 避免触发屏蔽、举报、取关等惩罚性信号 |
