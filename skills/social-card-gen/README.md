# 🃏 Social Card Gen — 一条素材，三个平台，零翻车

> **你把同一条帖子复制粘贴到 Twitter、LinkedIn 和 Reddit——然后三个平台都没反响。不是内容不好，是\"换个平台就换种说话方式\"这件事，大多数人低估了。**

Twitter 要锋利。LinkedIn 要厚重。Reddit 要真诚。同一个观点，三个平台的读者期待完全不同的语气、节奏和社区规则。Social Card Gen 不是"一键多发"工具——恰恰相反，它强制你为每个平台**重写**。从一条原始消息出发，按每个平台的写作规则、字符限制、禁忌列表，生成三个**本质相同但表达不同**的版本，带自检评分表。

---

## 🚧 边界

| ✅ 能做的 | ❌ 不做的 |
|-----------|-----------|
| 一条源消息 → Twitter/LinkedIn/Reddit 三版改写 | 不生产"复制粘贴"式的跨平台垃圾 |
| 内置各平台写作规则引擎（Hook 结构、字符限制、Hashtag 规则、禁忌词） | 不自动发布（你负责最终判断和发送） |
| 强制质量自检表 + 迭代循环 | 不做其他平台（Instagram/Threads/Bluesky 暂不支持） |

---

## ⚡ 核心能力

### 🛡️ 四问前置（不回答不生成）

1. **源消息是什么？**（核心想法/更新/故事）
2. **语气目标？**（信息型 / 挑衅型 / 低调炫耀型 / 对话型 / 教育型）
3. **目标读者？**（创始人 / 营销人 / 开发者 / 大众）
4. **行动号召？**（访问链接 / 回复 / 关注 / 分享 / 引发讨论）

### 📐 三平台规则引擎

| 维度 | 🐦 Twitter/X | 💼 LinkedIn | 🔵 Reddit |
|------|-------------|------------|----------|
| 字符限制 | 280（单条）/ 长线文 | 3000，首两行决定"展开"率 | 无硬限制，但长文需分层标题 |
| 语气规则 | 锋利、直接、有观点 | 专业但人性化，思想领导力 | 真实、好奇、社区优先 |
| Hashtag | 最多 1-2 个 | 3-5 个，正文末尾 | 绝对不用 |
| 致命错误 | 长开场、被动语态、企业腔、Hashtag 墙 | "很荣幸宣布…"类开场、过度自夸 | 明显营销、缺乏真诚、"看看我的XX" |

### ✅ 强制自检表

每版生成后必须逐项打分：

| 检查项 | Twitter | LinkedIn | Reddit |
|--------|---------|----------|--------|
| Hook 够强？（读者会停止滑动？） | ✅/❌ | ✅/❌ | ✅/❌ |
| CTA 清晰？ | ✅/❌ | ✅/❌ | ✅/❌ |
| 平台契合度？（语气匹配社区规范） | ✅/❌ | ✅/❌ | ✅/❌ |
| 红线通过？（见下方五条铁律） | ✅/❌ | ✅/❌ | ✅/❌ |

---

## 🚨 五条铁律（绝不违反）

1. ❌ 三条绝不能完全相同——每版必须在语气和结构上有实质差异
2. ❌ LinkedIn 禁止正文中夹杂 Hashtag——只能在末尾，最多 5 个
3. ❌ Reddit 禁止任何自我推广式开场——社区价值永远第一位
4. ❌ 禁止模糊 Hook——"我对 X 有一些想法"不是 Hook
5. ❌ 禁止跨平台假设——Reddit 读者不知道你的 LinkedIn 粉丝是谁

---

## 👤 谁在用

- **个人品牌建设者**：一次写好，三处发布，不翻车
- **内容团队**：统一消息策略，平台级本地化
- **社群运营**：Reddit 发帖不再被当广告删

---

## 🔗 配合使用

- 先写好 → `copywriting` 或 `copywriting-frameworks` 搞定核心消息
- 单平台深挖 → `tweet-draft-reviewer` 专门打磨 Twitter 推文
- 内容策略 → `social-media-strategy` 决定什么话题上什么平台
- 语气校准 → `voice-extractor` 确保所有版本都是"你"在说话

**输入**：一段源消息 + 四问回答
**输出**：三版平台优化文案 + 质量自检报告 + 最弱版本改进建议
