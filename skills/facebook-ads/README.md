## 三、真实场景：一个 ROAS 下降的账户是怎么被「解剖」的

假设你是一个 DTC 电商品牌，发现最近 14 天的 ROAS 从 4.2 掉到了 2.1。

**以前的做法**：打开广告管理器 → 看曲线 → 凭感觉关掉几个广告组 → 新建几个 → 等结果。

**用这个 Skill 的做法**（10 步全链路审计）：

1. **Pixel & CAPI 健康检查** → 发现 CAPI 事件匹配质量只有 5.8（低于 6.0 临界值），30%+ 转化数据在流失
2. **账户结构排查** → 24 个广告组中 11 个在学习受限状态（>30% 红线），需要立即合并
3. **受众重叠分析** → 3 个 prospecting 广告组面向同一批 1% LAL，互相竞价抬高了 CPM
4. **创意疲劳诊断** → 主力视频广告的 CTR 从 3.1% 跌到 1.8%，频率超过 4.2，需要立即替换
5. **预算 & 出价审计** → 2 个广告组日预算低于 5×CPA，永远无法脱离学习期
6. **归因窗口对齐** → 7 天点击窗口下的转化数在 GA4 只匹配了 67%，存在重复计数
7. **全漏斗覆盖检查** → retargeting 预算占比过高（55%），prospecting 严重不足

**输出不是「怎么调」的一句话建议，而是一份包含健康评分（0-100）、优先级排序的完整行动方案。**

## 四、核心能力矩阵

| 能力模块 | 覆盖范围 |
|----------|----------|
| **账户审计** | 结构、目标、受众、创意、追踪、归因 10 维度 |
| **受众策略** | Core / Custom / LAL / Advantage+ / Broad Targeting 全覆盖 |
| **创意管理** | 格式选择、测试框架、疲劳检测、UGC 集成、DCO |
| **追踪体系** | Meta Pixel + CAPI + AEM + UTM + GA4 交叉验证 |
| **预算 & 出价** | CBO vs ABO、最低成本 vs 成本上限 vs 出价上限 |
| **购物广告** | Advantage+ Shopping、商品目录、Feed 质量 |
| **iOS 14.5+** | CAPI 强制、8 事件优先级、价值优化策略 |

### 内置硬规则（不可违反）

1. Pixel + CAPI 缺一不可（仅浏览器追踪丢失 30-40% 数据）
2. 事件去重（event_id 匹配）必须开启
3. Purchase 事件匹配质量 ≥ 8.0
4. 广告组日预算 ≥ 5×目标 CPA（否则无法脱离学习期）
5. 学习期内的广告组不允许修改
6. CTR 14 天内下降 >20% 且频率 >3 → 立即替换创意
7. 学习受限广告组占比 <30%
8. 已转化用户必须从 prospecting 广告组排除
