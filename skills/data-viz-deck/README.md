## 从数据到成品的工作流

### Step 1：识别数据源
读取审计 Markdown、CSV、JSON 或数据库查询结果 → 解析关键指标、表格、发现 → 结构化 DataFrame。

### Step 2：为数据选对图表

| 数据模式 | 图表类型 | 典型用例 |
|----------|----------|----------|
| 分类 + 数值 | **横柱状图** | 渠道收入排名 |
| 分类 + 基准线 | **带参考线的柱状图** | 表现 vs 行业基准 |
| 占比 | **环形图** | 渠道花费分配 |
| 时间序列 | **折线图** | 30 天转化率趋势 |
| 双变量 | **散点图** | 预算 vs 转化相关性 |
| 绩效评分 | **热力表格** | 红/黄/绿颜色编码 |
| 差距分析 | **瀑布图** | 收入机会量化 |
| 漏斗 | **漏斗图** | 发送 → 打开 → 点击 → 转化 |

### Step 3：应用设计系统

这套技能内置了一套专业设计系统——所有颜色、字体、布局规范都已定义好，也支持替换为你的品牌色。

**配色体系：**
- 品牌主色：森绿色 `#3D7A5C`（仅在最佳表现指标和重点标注处使用）
- 语义色：绿色 🟢 超基准 / 琥珀色 🟡 需关注 / 红色 🔴 需行动（**绝不用于装饰**）
- 内容页底色：暖奶油色 `#FAF7F2`（**不使用纯白背景**）
- 暗色模式：仅用于封面页、章节分隔页和结尾页

**字体体系：**
- 标题：Switzer Light（300 字重）——轻盈而自信，**绝不用粗体**
- 数据：Cartograph CF（等宽字体）——所有数字、表格、KPI 使用
- 标签：Cartograph CF Regular + 正字距 + 全大写

### Step 4：按标准结构生成

每份 PPTX 遵循统一结构：

```
第 1 页   封面             — 报告名称 + 日期（暗色模式）
第 2 页   执行摘要         — 3-5 个 KPI 磁贴 + 核心发现
第 3 页   绩效记分卡       — 颜色编码表现总览表
第 4-N 页 深挖页（每页一个洞察）— 左 60% 图表 + 右 40% 洞察与建议
第 N+1 页 机会量化        — 瀑布图或柱状图
第 N+2 页 优先级建议      — 快速赢单 / 战略 / 维护三类
第 末 页  附录            — 完整数据表
```

## 九条设计铁律

1. **一页一个洞察**——不要在一页里塞多个发现
2. **标题即结论**——"售后邮件 RPM $0.07，低于基准 14 倍"，而不是"售后邮件分析"
3. **无基准不比数**——没有上下文的数字只是噪音
4. **颜色即含义**——绿色 = 好，琥珀 = 注意，红色 = 行动，绝无装饰性用色
5. **图表至多 6-8 个项目**——超出部分归入"其他"
6. **执行摘要即全篇**——只读第 2 页也要能理解整个故事
7. **有真实数据就不用估算**
8. **绝不用纯白底色**——永远是暖奶油色 `#FAF7F2`
9. **标题绝不用粗体**——Light 字重更高级
