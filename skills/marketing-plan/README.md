## 🧰 核心能力

| 模块 | 说明 |
|------|------|
| **三阶段工作流** | Phase 1 研究+信息采集 → Phase 2 逐章节交互评审 → Phase 3 汇编校验成稿 |
| **AARRR 全漏斗框架** | Acquisition / Activation / Retention / Referral / Revenue 五环逐层规划 |
| **17 节现状审计** | 先摸清现状再开药方——内嵌完整的 current-state 打分标准 |
| **预算科学化** | 按阶段与融资里程碑设定预算，而不是拍脑袋 |
| **营销运营栈映射** | 计划的每一部分对应到可执行的 Skill 与 MCP/API 集成，规划直接接执行 |
| **客户类型变体** | fCMO 客户、自有产品、顾问项目等不同场景的定制维度 |
| **参考库全配套** | 附 13 份 references：方法论、AARRR 框架、预算规划、增长模式、衡量框架、成稿模板等 |
