# Pro Deck Builder — VC 级 SaaS 演示文稿，用代码写 PPT

> 不是 PowerPoint 自带的 SmartArt。不是 Google Slides 的默认模板。是 Linear、Vercel、Attio 那种级别的设计语言——用 PptxGenJS 生成真正的 .pptx 文件。

## 痛点：开发者做的 PPT 一看就是开发者做的

你知道那个感觉——你有一个重要的 pitch，你的想法很清楚，你的数据很扎实。然后你打开 PowerPoint，拖了几个文本框，选了一个"看起来很专业"的模板，调了 20 分钟配色，最后输出了一份"不难看但也不像回事"的演示文稿。

开发者的 PPT 有几个经典死穴：用默认字体（Calibri）、居中正文、每页排版完全一样、标题下面画一条装饰横线（"AI 味"的 #1 标志）、加了不知所云的渐变和剪贴画……一句话总结：**你会写代码，但你的幻灯片不会。**

## 能力：可复用的设计系统 + 自动化代码生成

`pro-deck-builder` 把你的演示文稿变成**一套可复用的设计系统**。它基于 PptxGenJS 生成真正的 `.pptx` 文件，完整支持：

- **明暗双模式**：深色模式（`#0A0A0C` 深空黑，适合 Keynote/投资路演）+ 浅色模式（纯白，适合数据密集报告）。整份演示文稿统一模式，不混用。
- **12 种内置调色板**：Electric Blue（SaaS 科技）、Neon Lime（开发工具）、Hot Coral（市场营销）、Indigo（AI/ML 创业）、Teal Trust（医疗金融）、Gold Standard（投资/董事汇报）……每种调色板定义一种 accent 色，遵循 85/10/5 配色规则。
- **智能字体选择**：自动检测系统已安装字体，优先使用 Inter → DM Sans → Avenir Next → Poppins → Calibri 降级链。等宽数据字体优先 JetBrains Mono。
- **12 种幻灯片布局轮换**：标题页、KPI 仪表盘、图表+洞察、全幅图表、图标功能网格、数据表、章节分隔页、引用页、超级数字页、对比页、图文页、结束页。强制轮换避免重复。
- **图表数字智能格式化**：自动按数据量级选择 `K/M` 缩写，OOXML 条件格式处理混合量级数据，数据标签和坐标轴分别格式化。

最难得的是它对细节的偏执：标题永远左对齐、正文永远不会溢出窄面板、底部的 Callout 框在每一页高度和字号完全一致、表格和下方 Callout 框间距经过精确计算避免重叠。

## 谁在用？

- **创业者 / 创始人**：投资人路演需要 VC 级别的视觉呈现。
- **技术负责人 / 架构师**：向管理层汇报技术方案和架构评审。
- **解决方案架构师 / 售前**：为客户输出专业的提案演示。
- **DevRel / 布道师**：技术分享的幻灯片与产品官网保持一致的品质。

## 配合其他技能

- **`brand-dna`**：用品牌 DNA 生成自定义调色板替代内置选项。
- **`html-report-builder`** / **`pro-report-builder`**：如果交付物是报告文档而非演示文稿，用这两个。
- **`frontend-design`**：如果需要 web 交互界面而非静态幻灯片。
