# De-AI-ify Skill — AI 文本人性化引擎

> 系统化去除 AI 生成文本的\"机器味\"，恢复自然人类声音。基于 1,000+ 篇 AI vs 人类内容对比分析，47 种模式精准检测 + 替换，让你的内容读起来像人写的。

---

## 📌 定位

**De-AI-ify** 不是一个简单的\"改写得更口语化\"工具——它是一套系统化的 AI 文本检测与人性化引擎。它不会随机改写（像直接问 ChatGPT\"让这段更有人味\"那样结果不稳定），而是用固定的 47 种检测模式 + 评分系统 + 变更日志，每次产生一致、可追溯的结果。

> 直接让 ChatGPT \"写得更像人\"每次结果不同。De-AI-ify 用同一套方法论，每次输出一致、有评分、可追踪改动。

---

## 🎯 核心能力

### 1. 系统化的 47 种模式检测
覆盖五大类 AI 文本特征：
- **过度使用的过渡词**（14 种）— \"Moreover\"\"Furthermore\"\"Additionally\" 等
- **AI 陈词滥调**（18 种）— \"In today's fast-paced world\"\"Unlock your potential\"\"Game-changer\" 等
- **模糊限定语**（8 种）— \"It's important to note\"\"It's worth mentioning\"\"various/numerous/plethora\" 等
- **企业黑话**（12 种）— \"utilize\"→\"use\"\"leverage\"→\"use\"\"synergize\"→\"work together\" 等
- **机械化句式**（9 种）— 三段式排比、自问自答、固定三个要点等

### 2. 人性化评分系统（0-10）
- **0-3**：明显 AI 生成（多个陈词滥调、机械化结构）
- **4-5**：AI 痕迹重（有些人类特征但需要大量修改）
- **6-7**：混合型（可能是人也可能是 AI，缺乏鲜明声音）
- **8-9**：人类自然感（自然声音，极少量 AI 痕迹）
- **10**：与熟练人类写作者无异

### 3. 三种处理模式
| 模式 | 处理深度 | 适合场景 |
|------|---------|---------|
| `quick` | 移除明显 AI 痕迹，单次扫描，不评分 | 博文、快速社媒文案 |
| `standard` | 47 种模式全扫描 + 人性化评分 + 变更日志 | 任何对外发布的内容 |
| `deep` | 全扫描 + 根据写作者真实样本校准声音 | 代笔写作、品牌声音匹配 |

### 4. 变更可追溯
输出包含原始评分、修订评分、具体改动清单和需人工复核的标记项。你知道改了什么、为什么改、还有什么需要注意。

## 📋 适用场景

### ✅ 应该使用
- AI 生成的内容要对外发布，需要\"去 AI 味\"
- 博文、社媒文案、营销邮件被读者反馈\"太像机器写的\"
- 用 AI 写初稿后需要系统化人性化润色
- 品牌声音一致性要求高，需要可重复的处理流程
- 代笔/品牌内容需要匹配特定写作者的声音

### ❌ 不应该使用
- 修正事实错误 → 本 Skill 不改内容事实（需单独核实）
- 提升论证质量 → 保持原有结构和论点
- 替换不恰当的示例 → 标记出来由人工处理
- 改变内容意图或语调 → 保留你的表达意图

## 🚀 使用方法

### 安装

```bash
cp -r de-ai-ify ~/.openclaw/skills/
```

无需额外依赖——纯模式匹配和文本分析。

### 使用方式

```bash
# 标准模式（推荐）
/de-ai-ify document.md

# 快速模式（仅去明显 AI 痕迹）
/de-ai-ify document.md --mode quick

# 深度模式（匹配特定声音）
/de-ai-ify document.md --mode deep

# 自定义目标分数
/de-ai-ify document.md --score-threshold 8

# 保留正式语体（白皮书/案例研究）
/de-ai-ify document.md --preserve-formal

# 学术模式（允许"Moreover/Furthermore"等）
/de-ai-ify document.md --academic
```

## ⚠️ 注意事项与局限性

### 局限性
- **不修正事实错误** — 事实核查需要单独完成
- **不提升论点质量** — 原文论证弱则输出论证不变
- **不改意图和语调** — 保留你的表达目的
- **学术文本不适合激进去 AI 化** — 使用 `--academic` 模式保留必要正式语体

### 最佳实践
1. **重度 AI 内容跑两轮** — 第一轮抓明显痕迹，第二轮精修
2. **搭配人工审核** — De-AI-ify 做第一遍，人工编辑做最终打磨
3. **建立自定义黑话库** — 把你行业特有的 AI 高频词加入检测
4. **B2B 内容用 preserve 模式** — 企业内容保留适度正式感
5. **追踪评分** — 长期监测人味度变化，目标稳定保持 8+

### 质量检查
处理完成后验证：
- [ ] 大声朗读自然流畅
- [ ] 抽象表述已被具体例子替换
- [ ] 句式长短交替有节奏
- [ ] 无明显的 AI 陈词滥调残留
- [ ] 事实和数据保持准确
- [ ] 你的核心观点完整保留
- [ ] 对外内容评分 8+/10
