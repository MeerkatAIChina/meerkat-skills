# 👥 理想客户画像研究（ICP Research）

> **你说"目标客户是中小企业"，但"中小企业"里有人根本不需要你的产品——你浪费的每一分钱都是因为画像太模糊。**

靶心画得不够小，箭就永远射不中。你花钱投广告、写内容、做外拓，结果吸引来一堆"看起来像客户但其实不是"的人——他们嫌贵、用不起来、一个月就流失。这不是产品的问题，是你从一开始就没搞清楚：**到底谁才是你最该服务的那个人？**

---

## 🚧 边界：我们能做什么，不做什么

| ✅ 能做的 | ❌ 不做的 |
|-----------|-----------|
| 从人口/心理/购买行为三维构建画像 | 不把一个 ICP 模板套给所有客群 |
| 去社区挖掘客户真实语言 | 不跳过社区验证直接下结论 |
| 为每个痛点生成消息角度 | 不用"营销语言"替换客户原话 |

---

## ⚡ 核心能力

1. **八步画像构建** —— 产品上下文 → 市场定义 → 人口统计 → 心理画像 → 购买行为 → 痛点映射 → 异议处理 → 购买触发器
2. **痛点优先级评分** —— 每个痛点按"频率 × 强度"打分，精准排序
3. **社区语言挖掘** —— 用搜索模板去 Reddit、LinkedIn、Quora、G2 抓客户原话和情绪表达
4. **三类意图分级** —— 积极求购者 / 意识到问题但未行动 / 纯粹吐槽者，帮你过滤噪音
5. **消息角度生成** —— 每个痛点配套标题 + 证明 + CTA

---

## 👤 谁在用

- **市场团队**：做投放和内容前，先锁定靶心
- **销售团队**：理解"谁才是值得跟的人"
- **产品团队**：搞清楚需求的优先级和真实来源

---

## 🔗 配合使用

- 画像产出后，直接喂给 `launch-strategy`（知道对谁发布）、`copywriting`（用对的语言）、`content-strategy`（覆盖他们关心的主题）
- 需要进一步研究客户动机 → 调用 `customer-research` 做深度访谈分析
- 需要做旅程建模 → 基于 ICP 调用 `customer-journey-mapping` 绘制分角色路径

**输入**：产品描述 + 目标市场
**输出**：完整 ICP 档案（人口/心理/行为/痛点/异议/触发器/社区语录/消息策略）
