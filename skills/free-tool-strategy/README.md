# 免费工具获客策略（Free Tool Strategy）——把产品能力「开源」，让用户自己找上门

## 😫 痛点

你的内容团队写了上百篇博客，投放烧了几万块广告，但线索质量越来越差、获客成本越来越高。更糟的是——你花三个月打磨出一份电子书，下载的人很多，真正试用产品的人寥寥无几。

**问题出在：你在「描述」价值，而不是「证明」价值。**

真正会增长的 SaaS 公司，懂得一个秘密：**做一个用户离不开的免费工具，比做十本电子书更有用。** 工具让用户在动手操作中理解你的产品解决的问题，它天然吸引搜索流量、自然积累外链，而且——每个使用者都是带着真实需求来的高意图线索。

但免费工具不是随便做一个就能成功的。做错了，你只是在烧研发预算；做对了，它就是一个永不停歇的获客引擎。

## 🎯 这个技能能做什么

| ✅ 能做什么 | ❌ 不做什么 |
|:---|:---|
| 帮你判断「该不该做免费工具」以及做什么类型 | 不替你写代码或画 UI |
| 设计从创意验证→MVP规划→上线推广的全链路 | 不保证 SEO 排名或线索转化率 |
| 评估工具与核心产品的衔接路径，让工具使用者自然流向付费 | 不跳过「你有没有技术资源维护」的诚实评估 |
| 输出可对照执行的评估记分卡（8维度打分） | 不替代 downloadable 内容型 lead magnet 策略（那归 `lead-magnets` 管） |

## 🧠 核心能力

| 能力模块 | 说明 |
|:---|:---|
| **六类工具匹配** | 计算器 / 生成器 / 分析器 / 检测器 / 素材库 / 交互式工具——根据你的产品和用户场景匹配最适合的类型 |
| **创意验证框架** | 从搜索需求、竞争空白、线索质量、开发可行性四个维度验证工具idea是否值得做 |
| **门控策略设计** | 全锁/半锁/无锁+可选——四种线索捕获策略的利弊分析，帮你平衡「使用量」和「线索量」 |
| **SEO 关键词策略** | 工具落地页 + 支持性内容的双层关键词架构，让工具同时赚流量和外链 |
| **自建 vs 采购决策** | 什么时候定制开发、什么时候用无代码工具（Outgrow/Typeform/Bubble）、什么时候嵌入已有方案 |
| **MVP 范围定义** | 砍掉账号注册、结果保存、高级功能——只保留「做一件事，做好」的最小可用版本 |
| **8 维评估记分卡** | 搜索需求、受众匹配、独特性、产品路径、开发可行性、维护负担、外链潜力、传播力——总分 25+ 果断做，15-24 可探索，<15 重新想 |

## 👤 谁应该用

- ✅ **SaaS 增长负责人**：需要一个新的、可持续的获客渠道，不再只依赖付费投放
- ✅ **产品营销经理**：产品功能很强大但用户「感知不到」，需要一个低门槛体验入口
- ✅ **创业者/独立开发者**：资源有限，想用一个免费工具撬动 SEO 流量和口碑

## 🔗 配合其他技能

- 工具做完需要落地页优化 → 调用 `page-cro`
- 工具上线后需要 SEO 优化获取搜索流量 → 调用 `seo-audit`
- 需要追踪工具使用数据和转化漏斗 → 调用 `analytics-tracking`
- 工具收集的线索需要培育转化 → 调用 `email-sequence`
- 如果评估下来更适合做内容型引流而非工具 → 调用 `lead-magnets`
- 不确定整体营销方向时先找灵感 → 调用 `marketing-ideas`

## ✨ 一句话总结

> *「最好的营销不是说服人买你的产品，而是让用户先用上一个离不开的工具——然后自己找过来。」*
