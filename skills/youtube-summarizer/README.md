# 📹 YouTube Summarizer — 20 秒把视频变成结构化知识资产

> **你看了一个 45 分钟的视频，关上标签页后还能记住多少？**

这就是 YouTube Summarizer 要解决的问题。大多数人用 ChatGPT 做视频摘要的流程是：打开视频 → 手动开启字幕 → 复制粘贴到 ChatGPT → 等它吐出一堆不分结构的 bullet points → 手动排版 → 保存文件。整个过程 5-10 分钟，而且每次都从零开始。这个技能把它压缩到 **20 秒**：丢一个 YouTube 链接进去，自动抓取完整字幕，生成标准化摘要（论点→洞察→行动项），保存带时间戳的完整转录稿，需要的话直接推送到 Telegram。

---

## 🚧 边界

| ✅ 能做的 | ❌ 不做的 |
|-----------|-----------|
| 自动抓取 YouTube 视频字幕并结构化摘要 | 不处理无字幕的视频 |
| 三种深度：Quick（3 点 TL;DR）/ Standard（完整摘要）/ Deep（逐章分解+内容复用建议） | 不下载视频文件 |
| 多语言字幕提取（指定语言 + 英文兜底） | 不分析视频画面/视觉内容 |
| 完整转录稿归档（时间戳 + 元数据） | 不做情感分析（在 Roadmap 中） |

---

## ⚡ 核心能力

### 🎯 三种模式一键切换

| 模式 | 产出 | 适用场景 |
|------|------|----------|
| `quick` | 3 点 TL;DR + 1 句核心观点 | 快速扫读，分享给群聊 |
| `standard`（默认） | 完整结构摘要：论点 + 5 条洞察 + 补充细节 + 可执行结论 | 学习笔记、研究参考 |
| `deep` | Standard + 逐章分解 + 内容复用机会（可转写为推文/博客/Newsletter） | 把视频变成内容资产 |

### 📋 标准摘要模板

每次输出统一的六段结构：

```
📹 视频：[标题]
👤 频道：[名称] | 👁️ 播放：[数] | 📅 发布：[日期]

🎯 核心论点：[1-2 句中心观点]

💡 关键洞察：
- [3-5 条，每条 1-2 句]

📝 补充要点：[2-4 条支持细节]

🔑 行动建议：[1 条可落地的结论]
```

### ☁️ VPS/云端可用

使用 Android 客户端模拟方式抓取字幕，绕过 YouTube 对云服务器 IP 的封锁（这恰恰是 yt-dlp 在 VPS 上经常失败的原因）。
