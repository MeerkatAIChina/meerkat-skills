# 🎨 概念图解引擎 — 用代码画出专业级 SVG 示意图

> **你不是设计师，但你仍然需要一张能拿得出手的示意图——放进 PPT、博客、白皮书、客户提案里。concept-diagrams 让你用一段 Prompt 生成一张专业级 SVG，不需要打开 Figma。**

---

## 你正面临的痛点

市场人和咨询顾问最尴尬的时刻：你有一份精彩的策略分析，但 PPT 里的示意图是你用 PowerPoint 拼出来的——方框没对齐、配色辣眼睛、导出模糊。一张糟糕的图会让整个方案的体感打折扣。

找设计师？排期两周、沟通三回、修改五次。自己画？你没有设计基础，也不知道「好图」的标准是什么。

**concept-diagrams 解决了这个矛盾**：你只需要描述你想表达什么（一个流程？一个系统架构？一个客户旅程？），AI 会生成一张符合专业设计规范的 SVG 图——扁平、极简、配色语义化、支持暗黑模式、在任何浏览器中完美渲染。

---

## 这个 Skill 能做什么

| ✅ 能做 | ❌ 不做 |
|---------|---------|
| 生成 8 种类型的 SVG 示意图（流程图/结构图/API图/微服务/数据流/物理对象/系统集成/仪表盘） | 不会生成带渐变、阴影、模糊的炫酷效果——这是扁平极简风格 |
| 自动适配明暗模式——一套代码，两种视觉 | 不会替代专门的软件架构图工具（如果你需要深色科技风架构图，用 `tech-diagram`） |
| 9 色语义调色板——颜色编码含义而非装饰 | 不会生成动画或视频 |
| 严格的设计系统——字体大小只有两种、描边宽度只有 0.5px、圆角只有三个值 | 不会输出需要 Figma 打开的格式——输出是直接可在浏览器打开的单文件 HTML |
| 输出独立 HTML 文件——离线可用、无依赖、复制即用 | 不会生成无类名或内联样式的裸 SVG |

## 核心能力

| 能力 | 说明 |
|------|------|
| **8 种图类型** | 流程图 / 结构容器图 / API 端点图 / 微服务拓扑 / 数据流 / 物理结构 / 系统集成 / 仪表盘 |
| **统一定制语言** | 9 色语义调色板（紫/青/珊瑚/粉/灰/蓝/绿/琥珀/红），每种 7 个色阶 |
| **自动暗黑模式** | CSS class 驱动——浅色模式 50 底色+600 描边，暗黑模式 800 底色+200 描边——无需两套 SVG |
| **严格排版系统** | 仅两种字号（14px 标题 + 12px 副标题），统一 Sentence case，无全大写 |
| **精确间距规则** | ViewBox 680px 宽 / 安全区 x=40~640 / 盒子间 60px 最小间距 / 容器内 20px padding |
| **15 个参考示例** | 急诊流程、电影制作管线、客机结构、风力发电机、智能手机分层、公寓平面图、SN2 化学反应等 |
| **物理形状** | 支持 `<path>` 曲线、`<polygon>` 锥形、`<ellipse>` 圆柱、嵌套 `<rect>` 分层 |

### 这 8 种图在营销场景中的映射
| 图类型 | 营销应用 |

| **结构图** | 产品架构、技术栈分层、组织架构 |

| **仪表盘** | 营销 Dashboard 低保真原型 |
| **叙事旅程** | 品牌故事线、客户生命周期、产品演进 |
