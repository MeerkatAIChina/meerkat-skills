# 一句话生成社交媒体爆款表情包，让营销内容自带传播力

> 社交媒体运营每天要发内容，但找图、P图、排版太耗时间——一个梗图从创意到发布，往往要切三个工具、花半小时。现在，用自然语言描述你的想法，AI 直接帮你生成可发布的 .png 表情包，10秒出图。

---

## ✅ 能做什么

| 能力 | 说明 |
|------|------|
| ✅ 10套精选模板（Drake、This is Fine、Distracted Boyfriend 等） | 文字位置精调，开箱即用 |
| ✅ 动态调用 imgflip API 热门模板 | 支持按关键词搜索，模板库持续更新 |
| ✅ 自定义 AI 生成图片 + 文字叠加 | 没有合适模板时，用 AI 生成底图再叠加文字 |
| ✅ Overlay / Bars 两种文字模式 | 自动适配背景复杂度，确保文字清晰可读 |
| ✅ 视觉验证（Vision Verify） | 生成后自动检查文字是否清晰、构图是否合理 |

## ❌ 不能做什么

| 限制 | 说明 |
|------|------|
| ❌ 不是专业设计工具 | 不支持图层编辑、矢量绘图、精细排版 |
| ❌ 不生成仇恨/攻击性内容 | 明确禁止生成恶意、人身攻击或歧视性内容 |
| ❌ 不做动图/视频 | 仅输出静态 .png 图片 |

---

## 核心能力

**模板驱动，智能匹配**
内置 10 套精选模板（This is Fine、Drake、Expanding Brain、Gru's Plan 等），每套都有针对特定场景的推荐用法。输入"凌晨两点调试生产环境"，自动匹配"This is Fine"模板，文字位置精调到位。

**动态模板库**
精选模板之外，还能通过 imgflip API 搜索任意热门模板——输入关键词即可找到合适的梗图底板，自动适配文字排版。

**自定义 AI 图片模式**
当经典模板都不合适时，用 AI 生成专属场景图，再叠加文字。支持 Overlay（白字黑边直接叠在图上）和 Bars（上下黑条白字，适合复杂背景）两种模式。

**视觉质量保障**
生成后可调用 Vision 模型自动检查——文字是否清晰、位置是否合理、整体效果是否达标。不过关自动重试。

## 快速上手

```bash
# 查看所有可用模板
python generate_meme.py --list

# 生成一张经典梗图
python generate_meme.py drake /tmp/meme.png "用 P 手动 P 图" "用 AI 一句话生成"

# 搜索特定主题模板
python generate_meme.py --search "disaster"

# 自定义 AI 图片 + 文字叠加
python generate_meme.py --image /path/to/scene.png --bars /tmp/meme.png "顶部文字" "底部文字"
```
