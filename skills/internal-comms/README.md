# 🏢 内部沟通大师 — 让 AI 替你搞定公司内部所有书面沟通

> 从 3P 周报到全员 Newsletter，从 FAQ 到事故报告——AI 理解你们公司的沟通格式，直接产出「拿过来就能发」的内部文档。

---

## 痛点开篇

你有没有过这种经历——

周五一早盯着空白的文档，脑子里塞满了本周完成的工作但却不知道怎么组织成「领导想看的格式」？写短了怕显得没干活，写长了怕没人读。全员 Newsletter 发出去结果零回复。FAQ 写到一半发现语气不对。事故报告写得像甩锅现场。

**内部沟通是每个职场人的必修课，但几乎没有人教过你怎么写。** 而且每个公司的格式还不一样——创业公司的 Slack 更新风格，传统企业的红头文件模板，外企的中英双语周报，甲方和乙方的汇报逻辑完全不同。

这个 SKILL 就是你的内部沟通 AI 写手。它不只是生成文字，而是**按你们公司的格式和语言风格**直接出活。

---

## 边界说明

| ✅ 能做什么 | ❌ 不做什么 |
|-----------|-----------|
| 基于公司已有模板/示例生成各类内部沟通 | 不会自己发明你们公司的沟通格式 |
| 3P 更新（Progress/Plans/Problems） | 不替代你对业务的理解——你得告诉 AI 发生了什么 |
| 全员 Newsletter 撰写 | 不负责外部公关稿或媒体通稿 |
| FAQ 问答起草 | 不做实时聊天回复 |
| 项目状态更新、领导层简报 | 不管理邮件发送或日历排期 |
| 事故报告 / 复盘文档 | 不替代正式的合规/法务审核流程 |

---

## 核心能力

| 能力模块 | 说明 |
|---------|------|
| **3P 更新** | Progress（进展）/ Plans（计划）/ Problems（问题）三段式团队周报 |
| **公司 Newsletter** | 全员邮件/内部通讯，包含亮点、数据、人事动态 |
| **FAQ 问答** | 常见问题标准化回复，保证语气一致、信息准确 |
| **领导层简报** | 面向高管的精简汇报，突出关键指标和决策需求 |
| **项目更新** | 里程碑进展、风险项、资源需求的结构化报告 |
| **事故报告** | 事故时间线、影响评估、根因分析、改进措施 |

---

## 谁应该用

- ✅ 需要每周写团队周报但总在拖到最后一刻的项目经理
- ✅ 负责内部 Newsletter 但不知道写什么的 HR/行政负责人
- ✅ 经常被老板追问「进度怎么样了」的一线主管
- ✅ 需要向投资人或董事会汇报的创业公司创始人
- ✅ 想让团队内部沟通「有章法」但不想花时间写模板的团队 Lead
