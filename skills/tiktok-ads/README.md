# TikTok Ads 短视频广告大师

> **TikTok 广告不是「把电视广告竖过来放」。93% 的用户开着声音看，73% 的爆款广告用了文字叠加——你是在跟原生内容抢注意力，不是在跟其他广告竞争。**

---

## 一、TikTok 广告的底层逻辑：原生感 > 品牌感

TikTok 用户每秒都在刷走他们不感兴趣的内容。你的广告必须在**前 3 秒**完成两件事：

1. 让人停下手指（Hook）
2. 让人以为是普通内容而非广告（Native）

这不是一个「投放技巧」问题——这是一个「创意策略」问题。

`tiktok-ads` 这个 Skill，就是把 TikTok 广告投手的完整知识体系——从 Campaign 结构、Spark Ads 打法、TikTok Shop 整合到创意疲劳管理——封装成 AI 可执行的标准。

---

## 二、它不是什么东西？

- ❌ **不是视频制作工具**：帮你规划创意策略和公式，但不生成视频本身
- ❌ **不是 TikTok Shop 代运营**：帮你诊断 Shop 广告设置，不帮你选品

它是：**TikTok 广告的系统化军师——知道什么该做、什么不该做、什么时候该换素材。**

---

## 三、TikTok 创意黄金公式（内置）

```
Hook（0-3秒） → 价值/故事（3-15秒） → CTA（最后3秒）
```

**7 条创意铁律**：
1. **前 3 秒必须有钩子**——文字叠加、意外画面、或直接面对镜头
2. **必须看起来像 TikTok**——手机拍、真人出镜、trending sound，不要广告感
3. **声音必须开**——93% 的 TikTok 消费是开声音的
4. **全部竖屏 9:16**——永远不要横屏加黑边
5. **文字叠加是标配**——73% 的爆款广告用了屏幕文字
6. **快速剪辑**——每 2-3 秒切一次，静态画面必死
7. **创作者风格 > 品牌精修**——UGC 风格持续碾压棚拍素材

### 创意疲劳管理
- 每 **7-14 天**刷新素材（比 Meta 快 2-3 倍）
- 每个广告组保持 **3-5 个活跃素材**
- 周频次 >3 = 疲劳风险警告
