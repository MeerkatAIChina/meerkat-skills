# ✍️ 研究型内容创作搭档 — 从大纲到发布，AI 陪你写完每一段的「第二大脑」

> 不是替你写，是陪你写——研究资料自动找好、引用自动标好、每一段写完给你反馈、Hook 写得不够好给你三个优化版本。它是你的写作搭档，不是你的代笔。

---

## 痛点开篇

你坐在电脑前，光标在空白的 Markdown 文件里一闪一闪。

你知道要写什么——这个话题你研究了三个月。但你不知道怎么开头。写了一段感觉平平。第二段写完不知道逻辑顺不顺。查了半天的数据不确定该放哪里。写到最后发现引用没标，返回去翻了十几篇论文找出处。

**写作最难的从来不是「写」这个动作，而是写作过程中的每一个决策：结构怎么搭、开头怎么抓人、这段写得到底行不行、数据放哪合适。**

这个 SKILL 把 AI 从一个「代笔工具」变成一个「写作搭档」——你不必一个人面对空白文档。它陪你搭大纲、帮你找研究资料、优化你的 Hook、给你逐段反馈，但**始终保持你的声音和风格**。

---

## 边界说明

| ✅ 能做什么 | ❌ 不做什么 |
|-----------|-----------|
| 协作搭建文章大纲和结构 | 不替代你的专业知识和观点 |
| 搜索并标注引用来源 | 不保证引用的最新性（依赖搜索时间点） |
| 逐段分析并给出具体改进建议 | 不替代专业编辑或事实核查 |
| 优化 Hook 和引言（给出 3 个替代版本） | 不自动发布到 CMS 或社交媒体 |
| 保持和强化作者的写作风格 | 不做 AI 代笔——核心内容由你撰写 |
| 管理引用格式（行内/编号/脚注） | 不生成图片或视频内容 |

---

## 核心能力

| 阶段 | 能力 |
|------|------|
| **大纲协作** | 帮你搭建逻辑结构，标注研究缺口，迭代调整 |
| **研究辅助** | 搜索相关资料，提取关键事实/数据/引用，自动标注来源 |
| **Hook 优化** | 分析你写的开头，给出 3 个不同风格的优化版本 |
| **逐段反馈** | 每写完一段：清晰度分析、逻辑流检查、证据充分性评估、措辞建议 |
| **声音保持** | 学习你的写作样本，确保所有建议都匹配你的风格 |
| **引用管理** | 支持行内引用、编号引用、脚注三种格式 |
| **终稿审查** | 全篇通读：结构、内容质量、技术准确性、可读性、发布前检查清单 |
