# 🔍 /last30days — 7分钟掌握行业最新动向

> **不是去年的趋势报告，不是上季度的过时数据。是此时此刻社区里正在发生的事。**

---

## 你是不是也这样？

想做内容策略，搜了一堆 2024 年的博客文章。想了解用户对某个工具的真实看法，翻了几页 Reddit 就放弃了。想知道 LinkedIn 算法现在偏爱什么格式，最后靠猜。

**传统研究的问题：ChatGPT 数据太老，Perplexity 漏掉社区讨论，手动搜索要 2 小时起步。** 等你研究完，趋势可能已经变了。

---

## 一句话说清楚

**/last30days 在 7 分钟内扫描 Reddit、X(Twitter) 和全网过去 30 天的内容，识别高频模式、提取社区情绪、输出可直接使用的 prompts 和行动建议。** 相当于一个研究助理用 2 小时干的活。

---

## 它到底查了什么？

```
Web 搜索（30天新鲜度过滤）→ Reddit 讨论（真实用户声音）→ X 信号（实时热点）→ 模式识别 → 行动建议
```

最后你会拿到一份结构化情报：

- 🔥 **Top 3-5 高频模式** — 什么话题被反复提及？附原文引用和出处
- 📊 **社区情绪地图** — 大家对这件事是狂热、观望、还是吐槽？按子版块/话题分类
- 🐦 **X 信号分析** — 谁在引领讨论？什么类型的帖子在涨粉？
- 🎯 **即用的 Prompt** — 基于社区最佳实践写好的 prompt，复制就能用
- 💡 **行动建议** — 不是空泛的「可以考虑」，而是具体的「做什么、为什么、怎么做」

## 真实案例

一个 B2B SaaS 的市场人，原来每季度手动研究趋势：每主题 2-3 小时，到处翻，笔记散落各处，很难跨源找规律。

使用 /last30days 三个月后：
- 每主题研究时间降到 **7-10 分钟**
- 产出趋势报告 **10 份**（以前只能做 2-3 份）
- 每月节省约 **20 小时**
- 团队开始把报告当内部情报源传阅

> *"光是模式自动检测就值了——手动看的时候有些关联我根本注意不到。"*
