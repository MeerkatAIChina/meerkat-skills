# ✉️ Email Composer — 专业商业邮件撰写：从外联到提案，一封到位

> 你盯着空白的邮件草稿栏，打了又删、删了又打。写完发现——150字能说清的事你写了400字，三个不同的行动要求挤在同一封邮件里，收件人看完直接归档。

---

## 一封邮件只做一件事，但要把那件事做到极致

**Email Composer** 是通用商业邮件撰写引擎，覆盖四大场景：外联与客触、客户沟通、内部/团队协作、销售与提案。它解决的是「我会写邮件，但我写的邮件对方真的会看完、会行动吗」的问题。

---

## 明确的边界

| ✅ 覆盖范围 | ❌ 不覆盖 |
|---|---|
| 商务邮件的结构、语调、主题行 | 冷邮件专项策略（见 `cold-email`） |
| 客户沟通、团队协作、提案邮件 | 多封邮件自动化序列（见 `email-sequence`） |
| 语气校准（正式/专业/轻松/紧急） | Klaviyo平台操作（见 `klaviyo-analyst`） |

---

## 核心能力

- **四大邮件场景**：外联与客触、客户沟通、内部团队、销售与提案——每个场景有专用结构和语调
- **四档语气校准**：正式（C-suite/法务）→ 专业（客户/同事）→ 轻松（内部团队）→ 紧急（时间敏感）
- **5种主题行公式**：行动+时间 / 数字+收益 / 提问 / 价值+背景 / 紧迫+具体
- **黄金结构**：主题行→一句背景→2-3短段落→一个明确的CTA→符合关系的结尾
- **反模式清单**：禁止"just checking in"、禁止被动语态CTA、禁止多请求、禁止泛主题行（"Update""Quick question""FYI"）、禁止情绪化发信
- **150词上限原则**：尊重收件人的时间，让每一句都有存在的理由

## 目标用户

- **客户成功/客户经理**：每天与客户频繁邮件沟通
- **项目经理**：需要清晰传达需求和进度
- **销售**：从提案到合同的全流程邮件跟进
- **任何职场人**：想让自己的邮件被真正读完、被真正回应

## 配合使用建议

| 技能 | 配合方式 |
|---|---|
| `cold-email` | 冷邮件专项用cold-email，其他商业邮件用email-composer |
| `email-sequence` | 当多封邮件需要编排序列时切换 |
| `brand-dna` | 自动读取品牌语调文件，保持邮件风格一致 |
| `sales-enablement` | 销售邮件+销售资料联动 |

## 一句说完

> **一封好邮件的标准不是「我写完了」，而是「对方读完了，并且知道接下来该做什么」。** 一封邮件，一个CTA，一种结果。
