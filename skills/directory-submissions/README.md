# Directory Submissions 目录提交引擎

> **「把产品提交到100个目录」——这句话说对了一半。目录本身就是流量基础层，但90%的人提交的方式是错的：复制粘贴同一段描述、跳过审查站但浪费在垃圾站、从不做产品展示页就往外推。错误的目录策略不仅浪费一个下午——还会让搜索引擎的垃圾检测标记你。**

---

## 一、核心痛点

- 产品做好了但没人知道——SEO还在等排名，广告烧不起，冷启动不知从哪开始
- 搜「Best AI Tools 2026」——ChatGPT/Claude/Perplexity的推荐里全是竞品，没有你
- 域名权重（DR）为零，任何长尾词都排不上去——因为没有高质量反向链接
- 知道要提交目录，但提交了50个全是DR<10的垃圾站——不仅没效果还可能被惩罚
- 提交后登录页没有转化机制——访客来了看了主页就走了

`directory-submissions` Skill 覆盖从**基础准备、分层提交、定位变体、产品展示页到AI引用优化**的全流程目录战略。

---

## 二、核心能力

- **三大铁律**：基础不齐不提交→目标页没有不提交→描述不可复制粘贴跨目录重复
- **七级目录体系**：Tier 1 旗舰发布（Product Hunt/BetaList等15个）→ Tier 2 创业/SaaS（G2/Capterra/AlternativeTo等15个）→ Tier 3 AI目录（TAAFT/Futurepedia等25个）→ Tier 4 Agent/MCP注册表→ Tier 5 无代码目录→ Tier 6 Best of列表外联→ Tier 7 集成市场
- **产品展示页策略**：竞品对比页（转化率5-15%）+ 场景页 + 模板库 + 自写Best of榜单 + 集成页——反向链接流进去的终点必须是能转化的页面
- **准备阶段9项检查**：公开可访问、定价页、隐私条款、Logo素材、截图+演示视频、结构化数据、对比页数量、模板数量、可邀请评价的用户数
- **Product Hunt深度攻略**：2026算法权重在「评论质量」而非「点赞数」——三周预热+首两小时50支持者+问反馈不要求点赞+12:01AM PT周二到周四发布
- **评价获取协议**：「10-in-30」方法——从20个活跃用户中获取10条G2/Capterra评价，含邀请邮件模板
- **GEO优化（AI引用）**：单一H1+序列标题（引用率2.8倍）、FAQ Schema、对比表格、原始研究数据——让你的页面被ChatGPT/Claude/Perplexity引用

---

## 三、谁应该用？

- ✅ 有产品即将发布或已发布的SaaS/AI创始人
- ✅ 需要冷启动但预算有限的创业团队
- ✅ 准备产品发布（Product Hunt等）的市场负责人
- ✅ SEO负责人（需要高效获取高质量dofollow反向链接）
