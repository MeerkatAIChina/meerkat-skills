# 💎 Offers — 报价与成交方案设计引擎

> **文案再好也救不了一个平庸的 Offer。这个 SKILL 不帮你「写得更好听」，而是帮你把「卖的东西本身」变得让人无法拒绝。**

---

## 😫 你是否也遇到过这些问题？

- 落地页改了八版、文案换了三轮，转化率还是上不去——问题可能根本不在文案，在 Offer
- 报价单只有一个干巴巴的价格，没有价值堆叠、没有保障设计、没有紧迫感
- 想做高客单的服务 / 课程 / 咨询产品，但不知道怎么包装才能让客户觉得「值」
- 用了稀缺、限时这些手法，却总感觉像套路，怕伤品牌

如果这说的就是你——这个 SKILL 就是为你准备的。

---

## ✅ 能做什么 | ❌ 不做什么

| ✅ 能做 | ❌ 不做 |
|---------|---------|
| Offer 结构设计：价值框架、赠品堆叠、保障、稀缺/紧迫、命名、付款结构 | 不写呈现 Offer 的落地页文案（交给 `copywriting`） |
| 价值方程（Value Equation）诊断你的 Offer 为何不转化 | 不做定价层级/Freemium 设计（交给 `pricing-strategy`） |
| 保障与风险反转（Risk Reversal）设计 | 不鼓励虚假稀缺——SKILL 内置「什么时候不该用这些手法」 |
| 服务产品化、高客单 B2B、课程/咨询类 Offer 构建 | 纯自助式 SaaS 场景建议先看 `pricing-strategy` |
| 升单/降单（Upsell/Down-sell）与付款计划设计 | 不承诺任何具体转化率提升 |
| 内置禁用词表（Banned Vocabulary），避免油腻话术 | — |

---

## 🧰 核心能力

| 模块 | 说明 |
|------|------|
| **价值方程** | 从梦想结果、成功概率、时间延迟、付出成本四个维度拆解 Offer 吸引力 |
| **完整 Offer 解剖** | 核心交付 + 赠品堆叠 + 保障 + 稀缺/紧迫 + 命名 + 付款方式的结构化组装 |
| **诊断循环** | 「为什么我的 Offer 不转化」——用 Diagnostic Loop 逐项排查 |
| **保障设计参考库** | 附 7 份 references：价值方程、Offer 解剖、赠品堆叠、保障设计、稀缺紧迫、格式与案例 |
| **道德底线** | 明确列出何时不该用 Offer 手法与禁用词表——做增长，不做套路 |

---

## 👤 谁应该用

- ✅ 服务型公司 / 代理机构，想把服务产品化、提高客单价
- ✅ 课程、咨询、知识付费从业者，需要设计「无法拒绝」的报价方案
- ✅ 高客单 B2B 销售负责人，报价方案总是被压价或被搁置
- ✅ 快消品 / 电商运营，设计大促套装、赠品组合与限时机制
- ✅ 咨询顾问，为客户做商业模式与成交方案设计

## 🔗 配合其他 SKILL 使用

| 场景 | 组合 |
|------|------|
| 先定价格体系，再包装 Offer | `pricing-strategy` → `offers` |
| Offer 定了，写呈现它的页面 | `offers` → `copywriting` / `landing-page-optimizer` |
| 把 Offer 推向市场的发布节奏 | `offers` → `launch-strategy` |
| 给销售团队配套弹药 | `offers` → `sales-enablement` |
| 用心理学原理校准说服设计 | `marketing-psychology` + `offers` |
