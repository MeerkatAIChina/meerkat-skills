# SEO Content Writer — 让搜索引擎和用户同时点头的内容引擎

> **你的文章写得不差，但排名永远在第二页？问题不是你不会写——是你写的每一段话，搜索引擎都理解不了。**

---

## 一、好内容 ≠ 能排名

大部分内容团队踩的坑：写稿时全凭感觉，发稿时祈祷算法开恩。结果呢？花三天写的深度文章，输给竞品花三十分钟攒的拼接稿。

为什么？因为**内容质量是必要条件，不是充分条件**。光写得好不够——要让搜索引擎能读懂你的结构、判断你的权威、建立你的话题关联。`seo-content-writer` 不是教你怎么写文章，而是教你怎么把好内容武装到牙齿。

---

## 二、先搞清楚：这个 Skill 不是什么

| ❌ 不是 | ✅ 正确选择 |
|---------|------------|
| AI 代写工具（一键出稿） | 它是写作框架 + SEO 优化指南，需要人参与创作 |
| 只给 SEO 技巧 | 品牌声音分析 + SEO 优化 + 平台特定框架 |
| 只管博客文章 | 覆盖博客、社媒、邮件、着陆页、产品描述 |
| 替代关键词研究 | 基于你提供的核心关键词进行优化 |
| 适合所有内容 | 偏营销/SEO 内容；技术文档 → 用 `technical-seo-audit` |

## 三、真实场景演示

**场景**：一个 B2B 产品需要写一篇"企业如何选择项目管理工具"的指南文章。

**`seo-content-writer` 会怎么做？**

```
1. 品牌声音分析（未建立时）：
   → 分析 3-5 篇已有内容 → 提取语调/视角/词汇特征
   → 输出：专业但接地气、第二人称、中等句子长度

2. 关键词规划：
   → 主关键词：「项目管理工具选择」
   → 辅助关键词：「项目管理软件对比」「企业项目管理」「团队协作工具」
   → 搜索意图：信息型 → 需要的是指南，不是产品页

3. 内容框架：
   H1: 企业如何选择项目管理工具：2026 完整指南
   H2: 先定义你的团队需求
   H2: 5 个必须评估的维度 → 对比表
   H2: 市面主流工具速览 → 每种一句话
   H2: 常见选型错误
   H2: FAQ → 每组 Q&A 带 FAQ Schema

4. 优化细节：
   → 主关键词出现在 Title/H1/前 100 词/Meta Description
   → 次级关键词自然分布在各 H2
   → 可读性 Grade 8-9（面向管理者，不是开发者）
   → 全文唯一的 CTA：「联系我们获取定制化选型建议」
```

## 四、核心能力矩阵

| 能力 | 说明 | 输出 |
|------|------|------|
| **品牌声音分析** | 从已有内容提取语调/视角/词汇特征 | 声音指南 + 样本段落 |
| **关键词整合** | 主关键词 + 3-5 次级关键词自然嵌入 | 关键词分布图 |
| **框架生成** | 按内容类型适配结构模板 | 带注释的大纲 |
| **可读性优化** | Flesch-Kincaid / Gunning Fog 评分 | 可读性报告 |
| **SEO 细节** | Title/Meta/H1/Alt/内链 | SEO 检查清单 |
| **多内容类型** | 博客、社媒、邮件、着陆页、产品描述 | 每个类型的目标字数/关键词密度/可读性级别 |

---

## 五、谁应该用

- ✅ **内容创作者**：写文章时不确定 SEO 做得对不对
- ✅ **市场团队**：统一内容输出质量和品牌声音
- ✅ **创业团队**：一个人要做内容 + SEO，需要系统化方法论
- ✅ **代理商写手**：提升交付物的 SEO 水平，给客户看专业度

## 六、简单上手步骤

```bash
cp -r skills/seo-content-writer ~/.claude/skills/
```

两句话触发：
> "帮我写一篇关于 [话题] 的博客文章，关键词是 [XX]"
> "用我们的品牌声音，写一篇 [类型] 内容"

Agent 会先确认品牌声音（首次使用）、关键词、内容类型，然后输出完整的结构化大纲 + 优化要点。

## 七、配合使用

| 配合 Skill | 为什么 |
|-----------|--------|
| `seo-audit` | 先审计找出内容缺口，再用 Writer 填补 |
| `schema-markup-generator` | 文章生成后，补充 FAQ/Article Schema |
| `aeo-geo-optimizer` | 在内容中嵌入 AI 可提取的答案结构 |
| `content-strategy` | 策略层规划做什么 → Writer 负责具体怎么做 |
| `brand-dna` | 提供品牌声音配置，Writer 读取后自动适配 |
