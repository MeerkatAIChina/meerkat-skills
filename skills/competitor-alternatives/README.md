# Competitor & Alternative Pages — 竞品对比与替代页面生成技能

## 📌 技能定位

`competitor-alternatives` 是一个面向 **SEO 驱动的竞品对比内容生产** 的 Hermes Agent 技能。它帮助营销团队系统化地创建用于搜索引擎获客的竞品对比页面和替代产品页面，覆盖 **SaaS/数字产品** 和 **FMCG/消费品** 两大行业，支持 4 种页面格式，并内置从调研到发布的全流程 SOP。

---

## 🎯 核心能力

1. **四格式竞品页面生成** — 覆盖「替代页面（单数/复数）」「你 vs 竞品」「竞品 A vs 竞品 B」四种搜索意图，每种格式有完整的页面结构模板
2. **双行业深度适配** — 同时支持 SaaS（功能、集成、定价层级）和 FMCG/消费品（成分、感官、渠道、单位价格）的对比维度，含行业专属数据模板
3. **端到端 SOP 工作流** — 4 阶段 18 步骤：发现调研 → 策略规划 → 内容生产 → 优化交付，每步有明确输入/输出
4. **转化率优化（CRO）内置** — 按访客意图分层 CTA 策略、信任信号清单、A/B 测试优先级排序
5. **法律合规与效果追踪** — 覆盖美国/欧盟/英国/中国/东南亚的对比广告法规指南，含 KPI 仪表板和收入归因模型

## 🚀 使用方法

### 触发关键词

在对话中提及以下任意词语即可自动激活本技能：
- `alternative page` / `vs page` / `competitor comparison`
- `[产品A] vs [产品B]` / `[产品名] alternative`
- `competitive landing pages` / `battle card` / `competitor teardown`
- `竞品对比页` / `替代产品页` / `对比着陆页`

### 基础用法

```
请为我们的项目管理工具创建一个 Notion Alternative 页面。
```

```
分析元气森林 vs 农夫山泉的无糖茶产品，生成对比页面。
```

```
生成一份完整的竞品页面计划：列出所有值得做的对比页，按搜索量排优先级。
```

### 高级用法

```
基于 competitor_data/ 下的竞品数据，批量生成 15 个 "You vs Competitor" 
格式的着陆页，每个页面包含 TL;DR、功能对比、定价对比、适用人群、CTA。
目标行业：SaaS / 协同办公。
```

```
为我们的 FMCG 品牌（植物蛋白饮料）生成竞品对比体系：
1. 竞品数据文件（YAML）—— 豆本豆、植选、OATLY
2. 替代页面 ×3（单数格式）
3. 竞品A vs 竞品B 页面 ×3
4. 对比索引中心页面
要求包含成分表对比、每100ml价格分析、渠道可得性地图。
```

## ⚠️ 局限性

1. **SaaS 偏向性遗留** — 虽然 v2.0 新增了 FMCG 适配，但核心模板和示例仍以 SaaS 为主，消费品场景需用户自行适配细节
2. **无实时数据源** — 竞品定价、评价等数据依赖用户手动提供或定期维护，技能本身不联网爬取
3. **法律风险需自行评估** — 提供的法规指南仅为概览，具体对比广告合规性应由法务团队审查，尤其在中国市场
4. **不支持多语言原生生成** — 页面内容以英文为主要生成语言，中文/多语言版本需额外翻译和本地化步骤
5. **依赖外部 References** — 详细页面模板和内容架构模板存储在 `references/` 子目录，离线使用时需确保文件可访问
6. **行业深度有限** — FMCG 适配覆盖了食品饮料品类，但美妆、家电、汽车等垂直品类的特殊对比维度尚未细化
7. **无 A/B 测试自动执行** — 提供了 A/B 测试优先级建议，但实际测试执行需配合 `ab-test-setup` 技能
