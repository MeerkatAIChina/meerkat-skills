# 🎯 Prospecting — 把「谁会买」从一句感觉，变成一张可执行、可溯源的名单

> **老板说「去找客户」，你打开 LinkedIn 刷了两小时，导出 200 个名字——一半邮箱无效、一半根本不在目标行业、一个也说不出「为什么是现在」。这个 SKILL 把 ICP 定义变成一张带证据、带打分、带合规底线的线索表。**

---

## 😫 你是否也遇到过这些问题？

- 「我们的目标客户是谁」永远停在形容词层面，落不到可筛选的条件
- 名单靠手工搜、靠感觉挑，条数不少，但质量说不清
- 冷邮件发出去退信率高，域名信誉一路下滑
- 想找本地客户（门店、诊所、健身房这类），不知道从哪下手
- 早期产品，没有客户名单，也不知道「第一批种子用户」去哪找
- 不确定哪些数据来源能用、哪些操作会踩 LinkedIn / Google Maps 的平台条款

如果这说的就是你——这个 SKILL 就是为你准备的。

## ✅ 能做什么 | ❌ 不做什么

| ✅ 能做 | ❌ 不做 |
|---------|---------|
| 四条分支精准分流：**SaaS** / **通用 B2B** / **本地小商户** / **需求信号**（找第一批客户、设计伙伴、Beta 用户） | 不代写外联文案——名单建好后交给 `cold-email` |
| 五阶段通用流程：定义 ICP → 构建候选池 → 逐条资格验证 → 打分排序 → 输出名单表 | 不批量爬取 LinkedIn、Google Maps、付费墙站点或限流 API |
| 每条线索附**证据来源 URL**，标注高/中/低置信度 | 不绕过验证码、登录墙或反爬机制 |
| Hot / Warm / Cold / Skip 四档打分规则与默认比例目标 | 不基于健康、宗教、性取向等敏感属性做筛选或个性化 |
| 邮箱可投递性验证（避免无效邮箱污染域名信誉） | 不销售、转售抓取数据；不采购无来源的泄露数据集 |
| 输出聊天表格（默认）或 CSV（>25 行）＋「优先外联目标」Top 3–5 | 不做账号级深度竞品调研（交给 `competitor-profiling`） |
| 合规护栏：GDPR / CAN-SPAM / CASL 意识、来源与日期留存、自我限速 | 不保证线索一定能成单 |

## 🧰 核心能力

| 模块 | 说明 |
|------|------|
| **四条分支** | 卖给谁决定「合格」的定义：SaaS 看 ICP＋技术栈＋增长信号；B2B 看行业＋规模＋地域＋触发事件；本地小商户看经营状态＋网站情况＋距离＋决策人可达性；需求信号看**公开痛点证据**而非公司画像 |
| **ICP 五要素** | 公司画像、技术画像、购买信号（为什么是现在）、决策人画像、排除条件——输出一段式陈述＋通过/否决清单，没这个不进下一步 |
| **候选池构建** | 先找 2–3 倍于目标数量的候选，资格验证会大幅淘汰；SaaS/B2B 用 2–3 个来源交叉验证，本地商户用浏览器辅助研究 |
| **资格验证与置信度** | 每条线索必须带证据 URL；High＝两个独立来源确认，Medium＝一个可信来源＋一致搜索证据，Low＝证据不完整并明确标注不确定项 |
| **打分与优先级** | Hot（强 ICP 匹配＋明确购买信号＋决策人可达＋联系方式已验证）／Warm／Cold／Skip；默认约 20% Hot、30% Warm |
| **数据源速查** | Apollo / Clay / Clearbit / ZoomInfo / Hunter / Snov / Truelist / LinkedIn Sales Nav / BuiltWith / Crunchbase / GitHub / Google Maps＋浏览器 / Firecrawl / Browserbase 各自的最佳用途 |
| **合规八条** | 不批量抓取、不绕过防护、只用公开商务联系渠道、留存来源与日期、不转售数据、自我限速、不用泄露数据、不推断敏感属性 |
| **交付物** | 分支化的表格列定义（SaaS/B2B 与本地商户不同）、CSV 列结构、质量自检清单、常见错误九条 |

## 👤 谁应该用

- ✅ 快消 / 消费品品牌的渠道拓展与招商岗，需要按区域、门店类型建目标客户名单
- ✅ B2B / SaaS 的增长与销售开发（SDR），要把 ICP 落成可外联的清单
- ✅ 早期创业者，产品刚上线，需要找第一批客户和设计伙伴
- ✅ 本地服务生意的经营者，想系统化找到周边目标商户
- ✅ 咨询顾问，为客户交付「目标客户名单＋优先级」这一基础件
- ✅ 需要向管理层证明「线索质量」而不只是「线索数量」的市场负责人

|------|------|

| 对单个重点账号做深度调研 | `prospecting` → `competitor-profiling` |
| 线索路由、生命周期、CRM 交接 | `prospecting` → `revops` |
| 外联时需要的作战卡与一页纸 | `prospecting` → `sales-enablement` |
| ICP 的源头定义 | `product-marketing-context` / `icp-research` → `prospecting` |
| 后续外联序列设计 | `prospecting` → `cold-outreach-sequence` |
