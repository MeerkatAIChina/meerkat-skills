# 🏠 Homepage Audit — 首页/着陆页系统化转化审计

**一句话说清楚**：把你的首页扔给 Homepage Audit，它会像一位收费 $500/小时的 CRO 顾问那样，逐区块打分、逐行改写标题、逐项排优先级 — 告诉你到底该先改什么、为什么改、怎么改。

## 它跟泛泛的"网站点评"有什么不同？

大多数人对首页的判断是："这页面感觉不太对。"Homepage Audit 要的是**系统化诊断**，而不是感觉。它有三个工作模式：

| 模式 | 适用场景 | 产出 |
|------|---------|------|
| **Quick（快速扫描）** | 上线前的最后检查 | 5 秒测试 + Top 3 最高影响力修复 |
| **Standard（标准审计）** | 网站改版、转化诊断 | 逐区块打分 + 完整优先级矩阵 |
| **Deep（深度审计）** | 全面重设计、CRO 专项 | 全部打分 + 逐区块改写建议 + A/B 测试假设 |

默认走 **Standard** 模式 — 既不会太浅，也不会太重。

## 审计方法：6 大区块 × 加权评分

不像一般点评那样"我觉得这个 CTA 可以再大一点"，这套框架把首页拆成 6 个评分区：

1. **首屏（权重 25%）**：标题、副标题、主 CTA、视觉素材、加载速度、移动端表现 — 各按 1-5 分打分
2. **价值主张（权重 25%）**：利益清晰度、目标人群明确度、差异化、功能→利益的翻译质量
3. **社交证明（权重 10%）**：评价质量、Logo 墙、硬数据/统计
4. **清晰度与文案（权重 15%）**：可扫描性、简洁度、无术语、利益 vs 功能比例
5. **CTA 与转化（权重 15%）**：CTA 可见性、CTA 出现频次、低门槛选项
6. **信任与风险降低（权重 10%）**：定价透明度、风险对冲、异议处理

加权总分出来后，你得到的不止是一个分数，还有一个清晰的评级：**优秀（4.5+）/ 良好（3.5-4.4）/ 需改进（2.5-3.4）/ 需大修（<2.5）**。

## 核心亮点：标题强制重写 + 影响×投入矩阵

**标题重写环节**：每次审计必须输出"当前标题 → 为什么弱 → 改写版本 → 为什么强 → 备选方案"。这不是可选项，是每次审计的必答题。因为首屏标题通常是对转化影响最大的单一元素。

**影响×投入矩阵**：每一个发现的修复建议都标注影响分（1-5）和投入分（1-5），自动归类为三种优先级：
- 影响 4-5 + 投入 1-2 → **本周内搞定**
- 影响 4-5 + 投入 3-5 → **本月安排**
- 影响 1-3 → **先放着**

最后还有一个**自我批判环节**：审计师必须检查自己有没有跳过任何区块、标题改写是不是真的比原来更具体、"本周搞定"的建议是不是真的低投入。

## 适合谁用？

- 正在准备网站改版的产品/市场负责人
- 首页转化率明显低于预期的增长团队
- 想获得专业级首页反馈的独立创业者
- 需要给客户交付结构化首页审计报告的代理商

> ⚠️ 注意：审计依赖 URL 实际访问或截图内容，本技能内所有评分标准为方法论框架，不包含任何具体客户数据。
