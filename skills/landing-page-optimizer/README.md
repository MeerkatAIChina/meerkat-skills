# Landing Page Optimizer (落地页优化器)

对落地页进行审计和优化，以最大化转化率。

## 安装

```bash
git clone https://github.com/thatrebeccarae/claude-marketing.git && cp -r claude-marketing/skills/landing-page-optimizer ~/.claude/skills/
```

## 审计框架

### 首屏设计（前5秒）

访客必须在瞬间回答3个问题：
1. **这是什么？**（清晰的标题）
2. **与我何干？**（以利益为核心的副标题）
3. **我该做什么？**（可见的行动号召）

### 首屏布局模式

| 模式 | 适用场景 | 结构 |
|---------|----------|-----------|
| **左文案/右视觉** | SaaS、B2B | 左侧标题+CTA，右侧产品截图 |
| **居中首屏** | 简单产品 | 居中标题、副标题、CTA |
| **视频首屏** | 复杂产品 | 自动播放背景视频或嵌入式说明视频 |
| **社交证明首屏** | 需要高信任度 | 标题配合客户Logo或数据指标 |
| **分流测试** | 双用户群 | 两条不同路径，各自独立CTA |

### 价值主张层级

```
H1：核心利益（用户获得什么结果）
副标题：如何实现（机制或差异化优势）
支撑要点：3个证明点或功能点（项目符号）
CTA：具体行动 + 减少顾虑的微文案
```

### CTA优化

- **文案**：行动动词 + 具体结果（如"开始免费试用"，而非"提交"）
- **设计**：与背景高对比度、充足的留白和内边距
- **位置**：首屏可见、每个内容板块后、滚动时悬浮
- **微文案**：CTA下方减少顾虑（如"无需信用卡"、"随时取消"）

### 社交证明模式

| 类型 | 位置 | 效果 |
|------|-----------|--------|
| 客户Logo | 首屏下方 | 建立信任（B2B） |
| 数据指标（"5万+用户"） | 标题附近 | 规模证明 |
| 星级评分 | CTA附近 | 购买信心 |
| 用户评价引用 | 页面中部 | 情感证明 |
| 案例研究结果 | 页面深处 | 详细证明 |
| 信任徽章 | 表单/结算附近 | 安全保障 |

### 表单优化

- 每移除一个字段，完成率提升5-10%
- 标签放在字段上方（绝不要仅用占位符）
- 内联验证（实时反馈，而非提交时）
- 智能默认值和自动填充（autocomplete属性）
- 多步骤表单优于单步长表单
- 多步骤表单需显示进度指示器

### 移动端优化

- 触摸目标最小48×48px
- 单列布局
- 拇指友好型CTA位置（屏幕下半部）
- 无横向滚动
- 简化导航（汉堡菜单或无需导航）
- 快速加载（4G网络下LCP <2.5秒）

## 转化率基准

| 页面类型 | 优秀 | 一般 | 较差 |
|-----------|------|---------|------|
| SaaS试用注册 | >5% | 2-5% | <2% |
| 电商产品页 | >3% | 1.5-3% | <1.5% |
| 线索生成（B2B） | >10% | 5-10% | <5% |
| 邮件订阅 | >5% | 2-5% | <2% |
| 线上活动报名 | >30% | 15-30% | <15% |

## 反面模式

1. **多个竞争性CTA** — 每页一个主要行动
2. **以功能为中心的标题** — 以利益而非功能开头
3. **使用图库照片** — 使用真实产品截图或真人照片
4. **落地页上的导航栏** — 付费流量页面应移除导航
5. **仅首屏以下有CTA** — CTA必须首屏可见
6. **缺乏社交证明** — 每个落地页都需要信任信号
7. **加载速度慢** — 每100毫秒延迟损失1%转化率
8. **仅桌面端设计** — 60%以上的流量来自移动端

## 中国市场适配

### 中国落地页平台

- **微信落地页** — 微信生态内的落地页，需适配微信内置浏览器（iOS微信对`position:fixed`支持有限）
- **百度营销页** — 百度搜索推广落地页，需遵循百度质量度评分规则
- **抖音企业号主页** — 抖音生态内的品牌落地页，重视短视频内容引导
- **小红书专业号主页** — 强调种草内容和用户笔记互动

### 百度SEO注意事项

- 百度质量度评分直接影响广告展现概率和点击成本
- 页面打开速度必须<3秒
- 内容与推广关键词需高度相关，禁止恶意跳转
- 页面底部需有明确的品牌信息和联系方式

### ICP备案

- 所有在中国大陆运营的落地页域名必须完成ICP备案
- 未备案域名可能被运营商直接屏蔽
- 落地页底部应展示ICP备案号

### 中国移动端UX特殊考虑

- 微信内置浏览器兼容性（`position:fixed`在iOS微信中不可靠）
- 小程序落地页需配置业务域名白名单
- 中国用户普遍单手操作，CTA应放在屏幕下半部
- 二维码入口需确保URL参数可追踪

### 广告法规合规

- 广告法禁用词：不得使用"第一"、"最"、"国家级"等极限用语
- 弹窗广告必须有明显关闭按钮
- 收集用户信息需弹出隐私协议弹窗
- 涉及医疗、金融、教育等行业需展示经营许可证照

### 中国CTA规范

- ✅ "立即咨询" / "免费咨询"
- ✅ "免费领取" / "领取优惠" / "领取福利"
- ✅ "立即体验" / "免费试用"
- ✅ "查看详情" / "了解更多"
- CTA按钮常搭配紧迫感微文案："仅限今日"、"剩余名额32"、"已有12,856人领取"

### 中国落地页信任信号

- 用户评价截图（带真实头像） > 客户Logo墙
- 销量数据 > 国外客户数量
- 明星/KOL背书 > 客户Logo展示
- 国内知名媒体报道标志（腾讯、新浪、网易、36氪等）
- 行业认证/奖牌（国家高新技术企业、ISO认证等）
- 实时动态数据（"今日已有328人咨询"）效果优于静态评价
