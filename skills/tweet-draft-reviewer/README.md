# 🐦 Tweet Draft Reviewer — 在发出去之前，让 8 条铁律替你审一遍

> **你写了一条推文，读了三遍觉得还行——发出去，2 个赞。问题不在观点，在表达。**

大多数"没火"的推文不是想法差，是犯了低级的表达错误：以 "I" 开头、夹着 AI 味词汇（"delve" "game-changing"）、结尾是"你怎么看？"这种泛泛提问、一句话超过 20 个单词读得喘不过气。Tweet Draft Reviewer 用 **8 条从真实高互动推文中提炼的铁律**给你的草稿打分——10 分制，每一条规则逐条标记 ✅/❌，低于 7 分自动给出重写版本。30 秒，一条推文的品控闭环。

---

## 🚧 边界

| ✅ 能做的 | ❌ 不做的 |
|-----------|-----------|
| 用 8 条规则逐条审查推文草稿 | 不分析图片/视频内容 |
| 0-10 分制 + 逐规则原因说明 | 不提供"粉丝什么时候在线"这类发布时机建议 |
| 低于 7 分自动重写（保证新版本 7+） | 不管理你的内容日历和排期 |
| 批量扫描推文草稿文件夹 | 不做多平台适配（那是 social-card-gen 的事） |

---

## ⚡ 8 条铁律详解

| # | 规则 | 如何判定 FAIL | 为什么重要 |
|---|------|-------------|-----------|
| 1 | **禁 "I" 开头** | 第一个单词是 `I`（不包括 In/It/If） | "I" 开头把读者推开——他们不关心你，关心你发现了什么 |
| 2 | **强开场** | 首句是问句或以 "Have you/Do you/Are you/What if" 开头 | 问句开场在时间线上缺乏锚点；陈述句、数字、事实开场更强 |
| 3 | **无 AI 味** | 含 `delve` `certainly` `game-changing` `it's worth noting` `invaluable` `unleash` `revolutionize` `transformative` | 这些词在 2025 年就是"ChatGPT 写的"信号灯 |
| 4 | **禁泛泛结尾** | 以 "what do you think""drop a comment""thoughts?""agree?" 结尾 | 泛泛提问不接受互动——用陈述句、结论或长线文钩子收尾 |
| 5 | **Corey 测试（具体度）** | 无数字、无时间范围、无具名工具、无具体结果 | 模糊语言（"巨大提升""改变了一切"）= 没人相信 |
| 6 | **字符数** | >280 字符且未做长线文格式（1/ 2/ 3/） | 超出 280 不标记线程 = 发布时会自动截断 |
| 7 | **单一论点** | 3+ 个不相关的主张，没贯穿线 | 一条推文 = 一个观点。想讲三个观点？写三条推文 |
| 8 | **节奏感** | 任何句子 >20 词，或有"我最近一直在想…"类铺垫 | 长句 = 读者划走。铺垫 = 读者划走。第 2 行之前必须到点 |

## 🎯 评分速查

| 通过数 | 得分 | 判定 |
|--------|------|------|
| 8 | 10/10 | 满分 |
| 7 | 9/10 | 可以发 |
| 6 | 8/10 | 可以发 |
| 5 | 6/10 | **需要重写** ← 低于 7 分触发重写 |
| 4 | 5/10 | 需要重写 |
| ... | ... | ... |
| 0 | 0/10 | 从头来过 |

---

## 👤 谁在用

- **个人创作者**：每条推文在 Typefully/调度工具里排队前先过审
- **内容团队**：统一推文质量标准，减少"AI 味"翻车
- **创始人**：确保个人品牌推文读起来像人写的，不像 ChatGPT 写的

---

## 📂 批量模式

如果你的内容库有 `content/tweet-drafts/` 文件夹，可以批量扫描所有未审核草稿（通过 `reviewed: true` frontmatter 标记已审），输出每篇的评分 + 需要重写的自动改稿 + 批量汇总。

---

## 🔗 配合使用

- 先写稿 → `copywriting` 生成初稿后再来审
- 多平台 → `social-card-gen` 把审核通过的推文改写成 LinkedIn/Reddit 版本
- 语气校准 → `voice-extractor` 确保审查标准匹配你的真实表达习惯
- 品牌语调 → `brand-voice-guidelines` 补充品牌层面的额外规则

**输入**：一段推文草稿（或文件夹路径）
**输出**：8 规则逐条审查 + 0-10 评分 + 低于 7 分的改写版本
