# Braze 客户互动平台大师

> **Braze 是全球最强大的客户互动平台之一——但它也是一台「配置复杂度极高」的机器。Canvas 画错了、Segment 逻辑漏了、数据架构搭偏了……修起来比建起来还贵。**

---

## 一、核心痛点

- Braze Canvas 设计混乱：逻辑漏洞、时机冲突、遗漏了关键分支
- Segment 定义不精确导致消息推给了不该推的人
- 多渠道（Email / Push / SMS / In-App / Content Card）各自为战，没有协同
- 数据架构从头开始设计，不知道什么 Event 该打、什么 Attribute 该存

`braze` Skill 提供 Braze 全平台的专业审计、设计和优化能力。

---

## 二、核心能力

| 模块 | 覆盖 |
|------|------|
| **Canvas 审计** | 逻辑错误、时机问题、遗漏机会、Action/Audience/Experiment Path |
| **Segment 设计** | 用户属性/自定义事件/购买行为/互动 + 预测受众 |
| **多渠道 Campaig** | Email + Push + SMS + In-App + Content Card + Webhook |
| **数据架构** | Event/Attribute Schema 设计、Currents 导出、CDP 集成 |
| **可投递性** | SPF/DKIM/DMARC、IP 预热、Push Token 管理、合规（GDPR/CCPA/TCPA） |

---

## 三、谁应该用？

- ✅ Braze 管理员 / 运营团队（审计 Canvas 和 Campaign）
- ✅ MarTech 架构师（数据架构设计 + Currents 导出）
- ✅ 从 Klaviyo / Iterable / Salesforce MC 迁移到 Braze 的团队
- ✅ CRM / 生命周期营销负责人（全渠道协同策略）
