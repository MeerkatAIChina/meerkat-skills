# Community Marketing 社区营销大师

> **「建个 Discord 群吧」——这句话毁了无数社区。社区不是微信群，是需要战略设计、架构规划、持续运营的产品。**

---

## 一、核心痛点

- 用户说想建社区，但不知道选什么平台
- 社区有了但没人说话（「死群」）
- 不知道社区应该服务什么业务目标
- 缺乏合格的 Moderator 和管理制度

`community-marketing` Skill 覆盖从**零启动到规模化运营**的完整社区建设方法论。

---

## 二、核心能力

- **平台选择**：Discord / Slack / Circle / Reddit / Facebook Groups / 论坛
- **阶段诊断**：Pre-launch → 0-100 → 100-1K → Scaling → Established
- **目标对齐**：留存 / 激活 / 口碑 / 支持分流 / 产品反馈 / 变现
- **架构设计**：频道结构、角色体系、内容节奏
- **风险处理**：零用户、毒化社区、不合理期望

---

## 三、谁应该用？

- ✅ SaaS 创业者（社区驱动增长）
- ✅ DevRel / 社区经理
- ✅ 创作者（把粉丝变成社区）

---

> **社区的本质不是「人聚在一起」，而是「人为了一个共同的目标互相帮助」。**
