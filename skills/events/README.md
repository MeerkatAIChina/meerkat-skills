# 🎪 Events — 展会、Webinar、发布会，钱别只花在「现场那几天」

> **展位搭了、胸牌扫了一摞、伴手礼发完了，两周后才想起来跟进——线索全凉了。这个 SKILL 把活动从「花钱露个脸」变成一条可衡量的管道：先选对活动，再打赢会前与会后。**

## 😫 你是否也遇到过这些问题？

- 每年报几个展会，老板问「值不值」，你只能回答「品牌曝光」
- 花钱做了展位和物料，现场聊得挺好，回来跟进时对方已经忘了你是谁
- 办 Webinar 报名几百人，实际到场不到两成，到场了也没转化
- 想办自己的活动，但不知道选 Webinar、工作坊、晚宴还是峰会
- 活动结束就结束了，录播素材躺在硬盘里，没人二次利用
- 拿「胸牌扫描数」当成果汇报，心里也知道那不是商机

如果这说的就是你——这个 SKILL 就是为你准备的。

## ✅ 能做什么 | ❌ 不做什么

| ✅ 能做 | ❌ 不做 |
|---------|---------|
| 四种角色全覆盖：**主办**（Webinar/工作坊/晚宴/聚会/峰会/用户大会）、**赞助参展**、**演讲**、**纯参会** | 不替你订场地、做物料、排差旅——那是执行层 |
| 活动组合策略——先解决「该投哪些活动」，再谈执行 | 不承诺具体 ROI 数字或到场率 |
| Webinar 完整漏斗（选题、promise、报名页、提醒节奏、到场率、复盘） | 不生成成片视频或剪辑素材 |
| 赞助评估与谈判、展位动线、赞助 ROI 测算 | 邮件/短信序列本身交给 `email-sequence` / `sms` |
| 演讲获取（CFP）与演讲设计、录音复利 | 不保证拿到演讲名额 |
| 会前约会议、会中对话质量优先、会后 24–48 小时跟进纪律 | 不提供实时活动数据库或票务系统 |
| 内容弧线——录播→切片→文字稿→社媒→销售弹药 | 不代替你做差旅和现场人力调度 |
| 衡量体系：虚荣指标 / 真实指标 / 决定性指标三层 | 不做法律或合同审查 |

## 🧰 核心能力

| 模块 | 说明 |
|------|------|
| **角色选择** | 主办 / 赞助参展 / 演讲 / 参会——四条不同的动作线，共享同一套跟进系统；混合角色（赞助＋演讲、参会＋办晚宴）分别规划 |
| **组合优先于执行** | 活动是最贵、最不可测的渠道，杠杆在**选择**而非执行。不是「线下有没有必要」，而是「你的 ICP 在不在那儿」；大不一定好——50–200 人的垂直/区域活动往往单位成本更优 |
| **三类活动三种风险** | 自有活动（最大控制/最大风险）、展会（别人的主场，120 天准备赢过现场 4 天）、社群活动（复利，用「周六测试」衡量） |
| **通用弧线：20% 现场 + 80% 会前会后** | 会前建名单、提前约会议；会中要「合格对话」而不是名片数；会后 24–48 小时窗口跟进并按温度分层 |
| **主办形式选择** | Webinar / 工作坊 / 晚宴（B2B 单位成本最高的会议产出形式）/ 聚会系列 / 虚拟峰会 / 用户大会，各附适用场景与投入量级 |
| **参会玩法** | 零预算、常是全楼 ROI 最高的动作：先列 15–30 位目标人、提前 1–3 周约 15 分钟、办一场 8–12 人的周边晚宴（拿到主办身份但不用赞助价） |
| **内容弧线** | 每个活动都是内容引擎：能录就录、说清可被引用的金句（公司名＋品类＋数字念出来）、切片、每场一篇回顾、社媒引语、销售证明点 |
| **衡量三层** | 虚荣（报名、胸牌、人流、曝光）→ 只追踪、不优化、不当成果；真实（合格对话、预约会议、产生的商机）；决定性（每次合格会议成本、商机成本、影响的成交） |

## 👤 谁应该用

- ✅ 快消 / 消费品品牌负责线下活动、展会、渠道会的市场人
- ✅ B2B 市场人，在跑展会、赞助、Webinar 组合但说不清 ROI
- ✅ 需要向管理层论证「下一次活动要不要做」的市场负责人
- ✅ 想用自有活动（Webinar / 晚宴 / 用户会）建立品类权威的品牌团队
- ✅ 咨询顾问，为客户设计活动组合策略与衡量框架
- ✅ 预算有限、想用「纯参会 + 周边晚宴」撬动高质量对话的创业者
