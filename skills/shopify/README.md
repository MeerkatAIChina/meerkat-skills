# 🛒 Shopify — 让你的电商漏斗每一环都变现

> **流量进来了，但加购率和转化率告诉你：店铺在\"展示\"，不在\"成交\"。**

Shopify 给了你一个能上线的店铺，但没给你一个能赚钱的漏斗。大多数 DTC 品牌的 Shopify 后台都在收集数据却没人解读——转化率卡在 1.8%、移动端跳出率 65%、购物车放弃率 70%，这些问题背后不是\"流量不够\"，而是漏斗的每一环都在漏。这个技能就是你的**Shopify 营销工程全栈顾问**——从追踪基建到转化优化，从产品 Feed 到复购体系，一站式诊断 + 可执行方案。

---

## 🚧 边界

| ✅ 能做的 | ❌ 不做的 |
|-----------|-----------|
| 全链路转化漏斗审计（浏览→加购→结账→购买） | 不直接操作你的 Shopify 后台（你执行，我指导） |
| 营销技术栈选型与配置验证（Pixel/CAPI/GA4/Klaviyo） | 不取代 Shopify Plus 专属功能定制 |
| 产品 Feed 优化（Google Merchant Center / Meta Catalog） | 不代写 Liquid 主题代码 |
| 客户留存与复购策略设计 | 不处理供应链/物流问题 |

---

## ⚡ 核心能力

1. **全量店铺审计（12 步法）** —— 追踪基建 → 漏斗各环节转化率 → 站点速度 → 产品页 → 集合页 → 购物车/结账 → 邮件/SMS → 付费媒体集成 → SEO → 客户留存 → App 栈 → 优先级推荐
2. **关键基准对照** —— 9 项核心指标（转化率、ATC 率、结账完成率、AOV、复购率、移动端转化率、邮件收入占比、LTV:CAC、LCP 加载速度），每项标注 Good/Great/Warning 三档阈值
3. **三级营销技术栈** —— Tier 1 必备（Klaviyo + Meta CAPI + Google Channel + 评论系统 + GA4）→ Tier 2 增长期 → Tier 3 规模化，按阶段匹配
4. **追踪基建专项** —— Meta Pixel + CAPI 事件匹配质量验证、Google Ads Enhanced Conversions 配置、GA4 服务端追踪方案、UTM 一致性审查
5. **产品 Feed 治理** —— Google Merchant Center Feed 属性优化、变体同步、拒登诊断

## 🔗 配合使用

- 追踪落地 → `google-tag-manager` 和 `analytics-tracking` 确保数据采集正确
- 数据分析 → `google-analytics` 从 GA4 提取更深层洞察
- 转化优化 → `page-cro` 和 `ab-testing-framework` 对关键页面做实验
- 邮件/SMS → `klaviyo-analyst` 和 `email-sequence` 搭建自动化流程
- 归因 → `utm-attribution-strategy` 统一流量标签体系

**输出**：按预期营收影响排序的 12 步审计报告 + 每项问题的修复路径
