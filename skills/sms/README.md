# 📲 SMS Marketing — 短信营销全流程（增长与合规双轨）

> **短信是打开率最高、也最容易踩雷的渠道。这个 SKILL 帮你把弃购挽回、售后关怀、会员唤醒做成自动化流程——并且每一步都过合规关。**

---

## 😫 你是否也遇到过这些问题？

- 邮件打开率一路下滑，想上短信渠道，却不知道从哪个流程开始搭
- 弃购短信、售后短信、促销短信全靠手动发，没有一套自动化序列
- 听说过 TCPA / A2P 10DLC 这些合规名词，但完全不知道自己发的短信合不合规
- 短信每条都是真金白银，发多了掉粉、发少了没效果，找不到平衡点

如果这说的就是你——这个 SKILL 就是为你准备的。

## ✅ 能做什么 | ❌ 不做什么

| ✅ 能做 | ❌ 不做 |
|---------|---------|
| SMS/MMS 全序列设计：欢迎流、弃购、浏览挽回、售后、唤醒、促销 | 不能替你发送短信（需配合 Klaviyo/Postscript/Attentive/Twilio 等平台） |
| 合规体系逐条核对：TCPA、A2P 10DLC、GDPR、CASL | 不构成法律意见，重大合规决策仍需法务确认 |
| 「SMS vs Email」渠道决策：什么时候短信优于邮件 | 邮件序列设计交给 `email-sequence` |
| 美国号码类型选择（短代码/长代码/免费电话） | 不提供各国短信通道报价 |
| 单条短信的成本意识与 ROI 设计原则 | 不承诺具体转化数字 |
| 采集手机号的合规 Opt-in 设计 | 弹窗采集方案配合 `popup-cro` |

## 🧰 核心能力

| 模块 | 说明 |
|------|------|
| **开工四问** | 业务类型 → 现状 → 合规姿态 → 目标，先诊断再开方 |
| **合规优先** | 「Compliance — Read First」章节：美国 TCPA、A2P 10DLC 注册、欧盟 GDPR、加拿大 CASL 逐地区覆盖 |
| **六大核心原则** | 每条短信都有成本、Opt-in 是最贵资产、每条消息必须自证价值、短而清晰、单 CTA 单链接、每条署名 |
| **序列模板库** | 附 sequence-templates 参考库：欢迎、弃购（电商 ROI 最高流程）、浏览挽回、售后等场景模板 |
| **平台参考** | platforms 参考库覆盖 Klaviyo SMS、Postscript、Attentive、Twilio 等主流工具选型 |
| **渠道决策框架** | 「When SMS Beats Email」——不是所有消息都值得用短信发 |
