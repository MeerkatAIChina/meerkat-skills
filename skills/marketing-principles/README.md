# 📖 市场营销原理（Marketing Principles）

> **你做了 20 种营销动作，但没有一个在真正奏效。问题不是"不够努力"，而是缺少原则。**

大多数营销人的日常：追热点、试新渠道、学新玩法，但三个月后回头看——花了钱，烧了时间，增长毫无变化。这不是战术问题，是战略真空。Drucker、Ogilvy、Godin、Buffett 这些大师之所以能穿越周期，是因为他们手里握着不变的原则。你需要的不是"下一个增长黑客技巧"，而是一套在你睡不着觉时帮你做出正确决策的思维框架。

---

## 🚧 边界：我们能做什么，不做什么

| ✅ 能做的 | ❌ 不做的 |
|-----------|-----------|
| 用 15 条经典原则剖析你的困境 | 不在了解业务前就输出建议 |
| 给出 48 小时内可执行的具体动作 | 不抛抽象理论就跑 |
| 用"逆向思考"帮你看清风险 | 不跳过失败推演环节 |

---

## ⚡ 核心能力

1. **15 条永恒原则** —— 涵盖战略、创意、执行、决策、分发五大领域
2. **决策引擎** —— 输入你遇到的问题类型，"没人知道我""竞对在抢我""内容不转化"……自动匹配对应的原则和行动
3. **逆向推演（Inversion）**—— 先假设你的计划失败了，找出失败原因，再倒推预防措施
4. **三种模式** —— Quick（原则速查）、Standard（多原则分析 + 建议）、Deep（战略路线图）

---

## 👤 谁在用

- **创始人**：面对重大市场决策时，需要一个不受情绪干扰的"外部大脑"
- **市场 VP**：向团队解释"为什么我们不做 X"时，需要原则支撑
- **增长团队**：在"试什么"和"砍什么"之间摇摆时，需要决策框架

---

## 🔗 配合使用

- 定位模糊 → 先跑 `positioning-basics`，再回来做战略分析
- 缺少客户洞察 → 先跑 `customer-research`，用真实数据驱动原则应用
- 需要落地执行 → 原则输出可作为 `content-strategy`、`launch-strategy` 的上游输入

**输入**：业务阶段 + 具体困境
**输出**：原则匹配 + 48 小时行动清单 + 逆向风险分析 + 成功指标
