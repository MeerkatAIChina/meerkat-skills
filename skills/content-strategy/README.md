# Content Strategy Skill — AI 内容策略规划专家

> 让 AI Agent 具备内容战略规划能力。从商业目标出发，通过客户研究和竞品分析，输出内容支柱、话题集群、编辑日历和分发计划——确定写什么、为谁写、何时发。

---

## 📌 定位

**Content Strategy** 帮团队制定系统化的内容营销战略。每篇内容都必须是\"可搜索的\"或\"可分享的\"（最好是两者兼备），优先以搜索流量为基础，以传播力量放大影响力。

---

## 🎯 核心能力

### 1. 内容支柱与话题集群设计
基于产品定位和客户需求，确定 3-5 个核心内容支柱。每个支柱下孵化子话题集群，形成\"枢纽-辐条\"（Hub & Spoke）内容架构。

### 2. 搜索型 vs 分享型内容规划
- **搜索型内容**：捕获已有需求，面向正在搜索答案的用户
- **分享型内容**：创造新需求，用独到洞察和故事引发传播
- 推荐配比：搜索型:分享型:品牌型 = 6:3:1

### 3. 编辑日历生成
按季度/月度输出可执行的内容排期，含话题、格式、关键词、买家阶段、预期发布时间。

### 4. 话题优先级评分矩阵
用客户影响（40%）+ 内容-市场匹配（30%）+ 搜索潜力（20%）+ 资源需求（10%）四维评分，科学排序。

### 5. 中国市场平台策略
覆盖微信公众号、知乎、小红书、抖音/视频号、B站的差异化内容策略，含百度指数 + 5118 关键词研究、微信搜一搜 SEO、节假日营销日历。

## 📋 适用场景

### ✅ 应该使用
- 从零搭建内容营销体系
- 规划季度/年度内容日历
- 确定\"应该写什么\"以及\"为什么优先写这些\"
- 中国市场的多平台内容分发策略
- 需要基于数据的选题优先级排序

### ❌ 不应该使用
- 撰写具体文章 → 用 `copywriting`
- SEO 技术审计 → 用 `seo-audit`
- 社交媒体具体内容 → 用 `social-content`
- 程序化 SEO 规模化生产 → 用 `programmatic-seo`

## 🔄 工作流程

```
⏸1 确认商业上下文（业务/受众/目标/竞品）
    │
    ▼
⏸2 确定内容方向（3-5 内容支柱 + 话题集群 + 搜索/分享型配比）
    │
    ▼
⏸3 审核编辑日历（优先话题 + 格式 + 时间排期）
    │
    ▼
⏸4 最终审批（策略文档定稿）
```

## 🚀 使用方法

### 安装

```bash
cp -r skills/content-strategy ~/.claude/skills/
```

### 触发方式

- \"帮我规划内容策略\"
- \"我应该写什么话题\"
- \"做一个第三季度的编辑日历\"
- \"分析竞品内容，找到我们的内容缺口\"

### 可处理的数据源

- **关键词数据**（Ahrefs/SEMrush/Google Search Console 导出）
- **销售/客服通话记录** — 提取客户真实问题和语言
- **问卷调研结果** — 挖掘高频需求和内容偏好
- **论坛研究** — Reddit/Quora/知乎上的热门话题
- **竞品分析** — 找到未被覆盖的内容缺口

## ⚠️ 注意事项与局限性

### 局限性
- **不撰写具体文章** — 只做规划，具体执行需配合其他 Skill
- **需要足够的商业输入** — 信息越充分，策略越精准
- **中国市场合规需人工复核** — 平台规则变化快，敏感内容需人工把关
- **搜索数据时效性** — 关键词数据需定期更新，趋势会变化

### 常见陷阱
1. 为了写而写 — 没有明确目标的文章浪费资源
2. 贪多嚼不烂 — 先做深 3-5 个核心话题，再做广
3. 只有搜索型没有分享型 — 有流量没传播
4. 写了不发 — 每篇文章必须有明确的分发计划
