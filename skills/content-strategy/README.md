# Content Strategy Skill — 内容策略规划专家

> 帮 AI Agent 具备内容策略规划能力：确定写什么、为谁写、何时发、怎么分发。

---

## 📌 定位

**Content Strategy** 用于制定内容营销战略。从商业目标出发，通过客户研究和竞品分析，输出内容支柱、话题集群、编辑日历和分发计划。

---

## 🎯 核心能力

1. **内容支柱设计** — 基于产品定位和客户需求，确定 3-5 个核心内容支柱和子话题集群
2. **搜索型 vs 分享型内容规划** — 区分 SEO 驱动内容和传播驱动内容，按 6:3:1 配比
3. **编辑日历生成** — 按季度/月度输出可执行的内容排期
4. **中国市场平台适配** — 微信公众号/知乎/小红书/抖音/B站的内容策略
5. **话题评分矩阵** — 用搜索量、商业价值、竞争度三维评分确定优先级

---

## 📋 适用场景

### ✅ 应该使用
- 从零搭建内容营销体系
- 规划季度/年度内容日历
- 确定"应该写什么"而不是"怎么写"
- 中国市场的多平台内容策略

### ❌ 不应该使用
- 写具体文章 → 用 `copywriting`
- SEO 技术审计 → 用 `seo-audit`
- 社交媒体具体内容 → 用 `social-content`

---

## 🔄 工作流程

```
⏸1 确认商业上下文 → ⏸2 确定内容方向（支柱+集群）
→ ⏸3 审核编辑日历 → ⏸4 最终审批
```

---

## 🚀 使用方法

```bash
cp -r skills/content-strategy ~/.claude/skills/
```

触发：说"帮我规划内容策略""应该写什么话题""做一个编辑日历"

---

## ⚠️ 局限性

- 不撰写具体文章，只做规划
- 需要一定的商业背景输入才能产出有意义的策略
- 中国市场的内容合规性仍需人工最终审核
