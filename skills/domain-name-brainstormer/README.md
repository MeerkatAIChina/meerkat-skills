# 🌐 Domain Name Brainstormer：品牌命名+域名可用性检查，一个 Skill 搞定命名的「创意→验证」闭环

> **一句话定位**：从品牌定位出发，批量生成创意域名提案，并跨 .com / .io / .dev / .ai 等主流 TLD 同步检查可用性——让命名决策不靠拍脑袋。

---

## 你的痛点

你有没有经历过：想了一个绝妙的产品名，打开域名注册商一查——.com 被抢了、.io 要 $3,000、.ai 被人囤着等溢价。然后再想、再查、再失望——反复 10 次，两小时过去了。

更糟的是：团队好不容易定了一个名，没人检查商标冲突、没人验证社交媒体 Handle 是否统一、没人考虑 5 年后这个名还合不合适。

这个 Skill 做的事很简单：**把你从「想名→查域→失望→重来」的死循环里拉出来**。一次对话，输出 10-15 个结构化命名提案，带可用性、定价、品牌分析——你只需要做决策。

---

## ✅ 能做什么 | ❌ 不做什么

| ✅ 能做什么 | ❌ 不做什么 |
|-----------|-----------|
| 基于项目描述生成创意域名提案 | 不替代商标律师做正式商标检索 |
| 跨 TLD（.com/.io/.dev/.ai/.app/.co 等）批量查询可用性 | 不代付域名费用或自动注册域名 |
| 提供品牌洞察——解释为什么某些名字更合适 | 不为已有品牌做完整命名架构 |
| 按行业匹配合适的 TLD 策略 | 不提供 SEO 域名权重分析 |
| 竞争对手域名模式分析 + 差异化建议 | 不做全球商标库深度查询 |
| 多语言命名创意（英文+其他语言） | 不生成 Logo 设计或 VI 系统 |
| 个人品牌命名（名字变体+可用性） | 不涉及公司注册/工商命名合规 |

## 核心能力

| 能力 | 产出 | 你得到的 |
|------|------|---------|
| **项目理解** | AI 分析你的产品+受众+差异化 | 不是随机生成，而是有逻辑的命名方向 |
| **创意生成** | 10-15 个跨风格的域名提案 | 短/记忆点/可读/可品牌化——四项全筛 |
| **可用性批量查询** | .com/.io/.dev/.ai/.app/.co 等多 TLD | 知道什么能用、什么被占、被占的多少钱 |
| **TLD 策略建议** | 基于行业匹配最佳后缀 | .dev 给开发者工具，.ai 给 AI 产品，.com 给大众品牌 |
| **竞品命名分析** | 提取行业域名模式，生成差异化方案 | 不是「更像竞品」，是「和竞品拉开距离」 |
| **品牌评估** | 每个提案附 Why 说明 | 决策有依据，不再凭感觉选名 |
| **定价提示** | 标准域 $10-15/年，溢价 TLD $30-50/年 | 避免看到报价单被吓一跳 |

## 典型工作流

**产品发布命名**：
1. 描述产品定位、目标用户、核心差异化
2. Skill 输出 10-15 个命名提案，标注可用性和定价
3. 选出 Top 3，深入检查商标冲突和社媒 Handle
4. 团队投票→注册→品牌素材对齐

**个人品牌命名**：
1. 提供姓名+职业领域
2. Skill 生成 firstname.com / firstnamelastname.dev 等变体
3. 同步检查 Twitter/LinkedIn/Instagram Handle 一致性
4. 跨平台统一注册，品牌一致性零漏洞

## 谁应该用

- ✅ 创业者/独立开发者——产品/公司起名，一人搞定
- ✅ 品牌策略师/命名顾问——快速产出第一轮提案，聚焦评审而非海搜
- ✅ 市场团队——新产品线命名、品牌重塑
- ✅ 代理商——为客户提供结构化命名方案，提升提案专业度
- ✅ 出海团队——需要同时考虑中文品牌+英文域名
