# 快消品电商价值链（FMCG E-Commerce Value Chain）

## 快消品电商价值链定义

快消品电商价值链更偏"种 + 投 + 店 + 货 + 域"：
- **种**：内容种草（短视频/图文/直播/达人）
- **投**：广告投放（信息流/搜索/达人分发）
- **店**：店铺运营（页面/商品卡/活动报名/客服）
- **货**：库存与履约（库存分配/发货/退换）
- **域**：私域复购（会员/社群/小程序/企微）

## 价值链节点定义

### 种（Content Seeding）
- 内容策划：热点追踪、竞品内容分析、内容日历
- 素材生产：图文/短视频/直播脚本/图文详情页
- 达人合作：选号/Brief/内容审核/效果追踪
- 内容分发：平台算法适配、发布时间优化

### 投（Digital Advertising）
- 投放策略：人群/素材/出价/时段/预算分配
- 素材管理：素材标签化、效果归因、A/B 测试
- 效果优化：ROI/CVR/CPM/UV 价值监控
- 预算管理：日预算/总预算/平台分配

### 店（Store Operations）
- 页面运营：首页/详情页/活动页/商品卡
- 活动管理：平台活动报名/价格策略/促销节奏
- 商品管理：上新/下架/价格监控/库存同步
- 客服管理：咨询响应/投诉处理/差评管理

### 货（Inventory & Fulfillment）
- 库存分配：多仓/多平台库存协同
- 订单履约：发货/时效/退货/换货
- 物流管理：平台仓/品牌仓/前置仓/3PL
- 退换货：逆向物流/二次销售/报废

### 域（Private Domain & Retention）
- 会员管理：分层/权益/积分/等级
- 社群运营：企微/微信群/小程序/内容触达
- 复购激活：老客召回/新品试用/会员日
- 数据洞察：用户画像/购买周期/流失预警

## 快消品电商关键指标
- GMV（成交金额）
- ROI（投入产出比）
- CVR（转化率）
- UV（访客数）
- 客单价（AOV）
- 复购率（Repurchase Rate）
- 内容产出效率（Content Throughput）
- 投放效率（Ad Efficiency）
- 缺货率（Out of Stock Rate）
- 退货率（Return Rate）
